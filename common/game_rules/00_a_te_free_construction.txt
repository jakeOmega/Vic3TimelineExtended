# with the market off (te_direct_construction_ensure_base), none with it on.

# the Modding-Digests 1.12.0 inject_types.md list), so this is a bare copy. A bare copy in the
# other probed folders keeps the first definition read, in ASCII order of file name with
# vanilla's files and the mod's in one list (scripting_best_practices.md, Load Order, facts 1-3),
# so this file's name sorts before vanilla's 00_game_rules.txt ('a' before 'g'). Whether
# game_rules follows that rule is unprobed: the Game Rules screen shows it, one setting if this
# copy won and vanilla's three if it didn't (#1768).

# a save made under Scaled (All) or Maximum loses that setting at load (debug.log: Failed to read
# key reference) and takes this one. The flag keeps vanilla's one script reader,
# ai_strategy_default's wanted_construction_output (00_default_strategy.txt), on the branch the
