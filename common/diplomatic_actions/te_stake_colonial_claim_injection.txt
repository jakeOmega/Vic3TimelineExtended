# claims on decentralized states every month. This closes the front door, so the
# player and the AI cannot pay for a claim (the action's accept_effect also

#

# INJECT that names a vanilla trigger block ANDs with it or replaces it has not
# been read (docs/guides/scripting_best_practices.md, "INJECT: for adding
# *missing* fields is the safest wedge"). Vanilla declares every trigger block
# of this action (selectable, potential, possible, second_state_trigger), so
# there is no empty one to inject into. Tell on the action's tooltip, opened on
# a decentralized state of a strategic region we have interest in:
# - vanilla's cooldown and interest-tier lines AND the "renounced" line: merged,
#   as intended;
# - only the "renounced" line: last wins, so vanilla's gates are gone for every
#   country. Delete this file and REPLACE: the action instead, re-copying its
#   body from the installed game (the mod's te_force_become_subject.txt is the
#   pattern; the parsed vanilla_parsed/ copy loses statement order in effects);
# - only vanilla's lines: first wins, the injection is ignored, and the monthly
#   sweep alone enforces the rule.
# Record the result in that section of the best-practices guide.

	possible = {
		custom_tooltip = {
			text = da_stake_colonial_claim_renounced_tt

		}
	}
