# ============================================================================
# DEMOGRAPHICS PHASE 3 — display gates for the late game's rows on the Demographics tab and subtab
# (gui/te_demographics_widgets.gui; docs/superpowers/archive/specs/2026-10-11-demographics-late-game-design.md §6)
# ============================================================================
# A .gui read of a variable that does not exist logs "Failed to fetch variable" every frame (gui_modding_guide.md
# gotchas #14 and #23), so every late figure is read under a gate that asks script, as te_demog_sguis.txt's are.
# Each is shown-only: none is valid or does anything. Country gates are rooted at the player's country
# (GuiScope.SetRoot( GetPlayer.MakeScope ).End), state gates at the state the subtab shows
# (GuiScope.SetRoot( State.MakeScope ).End). The late figures exist only once a state's late game has started (its
# owner has an ageing carrier, or it holds treated people: te_demog_lx_effects.txt); the country's only while one of
# its census states has them.
# ============================================================================

# The country's late figures (te_demog_lx_country_store): Living to 100, the biological and calendar mean ages,
# eligibility and the public route, written together.
te_demog_lx_ready_sgui = {
	scope = country
	is_shown = {
		has_variable = te_dg_lx_l100
		has_variable = te_dg_lx_l100t
		has_variable = te_dg_lx_l100u
		has_variable = te_dg_lx_bio
		has_variable = te_dg_lx_age
		has_variable = te_dg_elig
		has_variable = te_dg_lx_pub
	}
	ai_is_valid = { always = no }
	is_valid = { always = no }
	effect = { }
}

# A state's late figures, written together by its late step (te_demog_lx_finish, te_demog_lx_begin).
