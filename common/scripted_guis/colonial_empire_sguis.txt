# ============================================================================
# COLONIAL EMPIRE — SCRIPTED GUIS
#
# Backs gui/journal_entry_widgets/colonial_empire_widget.gui, the player-facing
# surface for je_colonial_empire now that the vanilla button grid is AI-only.
#
# Every action handler delegates: `is_valid` calls a colonial_empire_possible_*
# trigger and `effect` a colonial_empire_effect_* effect. Planned Full
# Decolonization's trigger and effect are also its scripted button's `possible`
# and `effect`; a programme's are the gates and steps the AI's monthly review
# uses too; the per-target buttons' are the player's alone, and the
# confirmation events they open read the same gates. Nothing
# here restates a condition or an action, so the AI and the player's widget
# cannot drift apart. Change the shared helper in
# common/scripted_triggers/colonial_empire_triggers.txt or
# common/scripted_effects/decolonization.txt -- never here.
#
# The AI never uses any of these (`ai_is_valid = { always = no }` on all of
# them): its decolonization decisions run through the `ai_chance` blocks on the
# je_colonial_empire scripted buttons, and its programme levels through
# colonial_ai_review_programmes in the entry's monthly pulse.
#
# Read-only handlers carry `is_valid = { always = no }` so nothing can execute
# them; they exist purely so the widget can ask script a question it cannot ask
# itself.
#
# ---------------------------------------------------------------------------
# OP TABLE — colonial_empire_policy_sgui (saved_scopes = { op })
#   0  raise Development Investment      1  lower Development Investment
#   2  raise Military Garrison           3  lower Military Garrison
#   4  raise Cultural Assimilation       5  lower Cultural Assimilation
#
# The table is repeated in the .gui header and in
# docs/systems/journal_entry_systems.md § Colonial Stability Widget. Keep all
# three in step.
#
# PER-TARGET BUTTONS (the Colonial Holdings section): one handler per action,
# each taking its one target as its only saved scope, the shape gm_sguis.txt's
# monument rows use (AddScope( 'gm_state', State.MakeScope )):
#   colonial_empire_release_state_sgui     ce_state    -> decolonization_events.402
#   colonial_empire_free_subject_sgui      ce_capital  -> decolonization_events.403
#   colonial_empire_dominion_subject_sgui  ce_capital  -> decolonization_events.404
# A subject travels as its capital (gotcha #11: the panel reaches a country
# through a stored state), and script takes the capital's owner. Each is_valid
# fails closed on a missing scope. Planned Full Decolonization, which acts on
# the whole empire, is colonial_empire_planned_sgui.
#
# ---------------------------------------------------------------------------
# WHY THE OP CODE DECIDES WHAT A CONTROL *DOES* BUT NEVER WHETHER IT IS *DRAWN*
#
# Passing a saved scope to `IsValid` / `Execute` / the tooltips is proven in this
# mod (st_res_scripted_gui.txt has shipped it). Passing one to `IsShown` is NOT:
# Strategic Reserve hands `AddScope('dir', …)` to IsShown but its `is_shown`
# never reads the scope, vanilla ships no handler whose `is_shown` reads a saved
# scope at all, and the one in-mod case (un_chamber_vote_sgui's veto branch) is
# written fail-open, so it would look fine either way. Vanilla's
# scripted_guis.md only promises saved scopes "in triggers / effects".
#
# With the button grid hidden from humans, a control whose visibility quietly
# evaluated false would leave the player no control at all — the one failure
# this surface cannot afford. So each programme's stepper is always drawn and
# greys out through IsValid, and the overview's lit programme icons take their
# visibility from a SCOPE-FREE read-only handler below
# (colonial_empire_active_*_sgui), which is the shape banking's dashboard has
# been play-tested with. The op code selects the gate, the effect and the
# tooltip text.
# ============================================================================


# ---------------------------------------------------------------------------
# Read-only: has colonial_empire_refresh_display run yet?
#
# Every display variable is written by that one effect, so a single
# has_variable check gates every var read in the widget. This is the guard for
# gui_modding_guide gotcha #14: je_colonial_empire has is_shown_when_inactive, so
# the widget is built for countries whose entry never activated, and an
# unguarded var read there is a "Failed to fetch variable" per frame. The
# widget's root is additionally gated on [JournalEntry.IsActive].
# ---------------------------------------------------------------------------
colonial_empire_display_ready = {
	scope = country
	is_shown = {
		has_variable = colonial_empire_tier
	}
	ai_is_valid = { always = no }
	is_valid = { always = no }
	effect = { }
}

#

# reaches `is_shown` is unproven here — see the note in the file header. This is
# the shape banking's dashboard has been play-tested with.

# Each reads the programme's level (colonial_*_level_value, which is 0 before
# the variable exists), the same value the bar term and the steppers read. The

# ---------------------------------------------------------------------------
# Read-only text: which great powers are pressing on the empire.
#
# Rendered with ScriptedGui.ExecuteTooltip. The great powers are walked LIVE
# here rather than read out of stored slot variables, because
# `Var('x').GetCountry.GetName` is recorded as rendering blank in this mod
# (gui_modding_guide gotcha #11) and because a live walk cannot go stale or name
# an annexed country.
#
# Cost: two every_country walks per frame while the section is open. That is why
# the widget keeps International Pressure COLLAPSED by default and puts this
# textbox inside the collapsed container -- nothing runs until the player asks.
#
# Each entry names its own side (gotcha #18: a header above a script-built
# country list renders above the whole undivided list, not above its own group),
# and no entry adds a flag icon (gotcha #19: a custom_tooltip inside a country
# scope change already gets a bullet and a flag for free).
# ---------------------------------------------------------------------------
colonial_empire_pressure_sgui = {
	scope = country
	is_shown = { always = yes }
	ai_is_valid = { always = no }
	is_valid = { always = no }

	effect = {
		# Cheap short-circuit: `any_country` stops at the first match, where the
		# condemner/supporter script values would walk every country twice.
		if = {
			limit = {
				NOT = {
					any_country = {
						NOT = { THIS = ROOT }
						country_rank >= rank_value:great_power
						OR = {
							has_variable = gp_anti_colonial_stance
							has_variable = gp_pro_colonial_stance
						}
					}
				}
			}
			custom_tooltip = je_colonial_empire_pressure_quiet_tt
		}
		# One line above the whole list (gotcha #18 is about per-group headers;
		# this one describes every entry): each entry below shows its power's
		# prestige, and this line shows ours and how the two combine.
		else = {
			custom_tooltip = je_colonial_empire_pressure_scaling_tt
			# The monthly snapshot, not a live walk. has_variable guards the first
			# month of a save upgraded mid-entry, which has no snapshot yet.
			if = {
				limit = {
					has_variable = colonial_empire_condemner_share
					var:colonial_empire_condemner_share > 0
				}
				custom_tooltip = je_colonial_empire_pressure_share_tt
			}
			# The supporters' share, beside it, with a hover that says it does
			# not offset the escalations (only the condemners' share counts).
			if = {
				limit = {
					has_variable = colonial_empire_supporter_share
					var:colonial_empire_supporter_share > 0
				}
				custom_tooltip = je_colonial_empire_pressure_support_share_tt
			}
		}

		every_country = {
			limit = {
				NOT = { THIS = ROOT }
				country_rank >= rank_value:great_power
				has_variable = gp_anti_colonial_stance
			}
			custom_tooltip = je_colonial_empire_condemner_entry_tt
		}

		every_country = {
			limit = {
				NOT = { THIS = ROOT }
				country_rank >= rank_value:great_power
				has_variable = gp_pro_colonial_stance
			}
			custom_tooltip = je_colonial_empire_supporter_entry_tt
		}
	}
}

# ---------------------------------------------------------------------------
# The three colonial programmes, one level up or down.
#
# `is_valid` delegates to the programme's up or down gate and `effect` to its
# step, selected by op code. Those three paths (IsValid / Execute / the
# tooltips) are the ones `AddScope` is proven on in this mod.
#
# `is_shown` is deliberately unconditional: each programme's minus and plus are
# always drawn, and a step that cannot be taken greys out with the reason in
# its IsValidTooltip. A stray op code cannot produce a live control either way
# -- `is_valid`'s `trigger_else = { always = no }` greys out anything outside
# 0-5, and `effect` has no branch for it.
# ---------------------------------------------------------------------------
colonial_empire_policy_sgui = {
	scope = country
	saved_scopes = { op }

	is_shown = { always = yes }

	ai_is_valid = { always = no }

	is_valid = {
		trigger_if = {
			limit = { exists = scope:op scope:op = 0 }
			colonial_empire_possible_invest_up = yes
		}
		trigger_else_if = {
			limit = { exists = scope:op scope:op = 1 }
			colonial_empire_possible_invest_down = yes
		}
		trigger_else_if = {
			limit = { exists = scope:op scope:op = 2 }
			colonial_empire_possible_garrison_up = yes
		}
		trigger_else_if = {
			limit = { exists = scope:op scope:op = 3 }
			colonial_empire_possible_garrison_down = yes
		}
		trigger_else_if = {
			limit = { exists = scope:op scope:op = 4 }
			colonial_empire_possible_assimilation_up = yes
		}
		trigger_else_if = {
			limit = { exists = scope:op scope:op = 5 }
			colonial_empire_possible_assimilation_down = yes
		}
		trigger_else = { always = no }
	}

	effect = {
		if = {
			limit = { exists = scope:op scope:op = 0 }
			colonial_empire_effect_invest_up = yes
		}
		else_if = {
			limit = { exists = scope:op scope:op = 1 }
			colonial_empire_effect_invest_down = yes
		}
		else_if = {
			limit = { exists = scope:op scope:op = 2 }
			colonial_empire_effect_garrison_up = yes
		}
		else_if = {
			limit = { exists = scope:op scope:op = 3 }
			colonial_empire_effect_garrison_down = yes
		}
		else_if = {
			limit = { exists = scope:op scope:op = 4 }
			colonial_empire_effect_assimilation_up = yes
		}
		else_if = {
			limit = { exists = scope:op scope:op = 5 }
			colonial_empire_effect_assimilation_down = yes
		}
	}
}


# ---------------------------------------------------------------------------
# Planned Full Decolonization: every eligible territory at once.
#
# `is_shown = { always = yes }` deliberately: with nothing to release it stays
# visible and disabled, with the reason in the button's IsValidTooltip. A
# control that vanishes teaches nothing.
#
# Not armed-then-confirmed in the GUI: the effect fires
# decolonization_events.401, which lists every territory and offers a
# Reconsider option that clears every marker. That confirmation is real game
# state: it survives a save and cannot be left half-armed by closing the panel.
# A GetVariableSystem arm flag would be client-side, have no lifetime, and
# greet a returning player still armed. Nothing is released by pressing this.
# ---------------------------------------------------------------------------
colonial_empire_planned_sgui = {
	scope = country

	is_shown = { always = yes }

	ai_is_valid = { always = no }

	is_valid = {
		colonial_empire_possible_planned_decolonization = yes
	}

	effect = {
		colonial_empire_effect_planned_decolonization = yes
	}
}


# ---------------------------------------------------------------------------
# The per-target buttons of the Colonial Holdings section: Release beside a
# territory, Release and Dominion beside a colonial subject. Each opens
# the confirmation event for its one target; nothing is released or changed
# by the click. The gates and effects are the shared helpers in
# colonial_empire_triggers.txt and decolonization.txt (PER-TARGET GATES /
# PER-TARGET DECISIONS).
#
# Always drawn; a target that cannot be acted on greys its button with the
# reason in IsValidTooltip. `exists` first, so a scope that did not arrive
# greys the button instead of acting on nothing.
# ---------------------------------------------------------------------------
colonial_empire_release_state_sgui = {
	scope = country
	saved_scopes = { ce_state }

	is_shown = { always = yes }

	ai_is_valid = { always = no }

	is_valid = {
		exists = scope:ce_state
		colonial_empire_possible_release_state = { STATE = scope:ce_state }
	}

	effect = {
		colonial_empire_effect_release_state = { STATE = scope:ce_state }
	}
}
