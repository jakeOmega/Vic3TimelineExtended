# ============================================================================
# HISTORY STORE — marker tooltips
# ============================================================================
# Read by gui/journal_entry_widgets/te_history_chart.gui. A history chart bar
# hands this handler the sample container for its month and renders whatever
# `custom_tooltip` lines the effect emits — the vanilla "SGUIs to build lists
# in loc" pattern (game/common/scripted_guis/scripted_guis.md).
#
# It is display-only in the strictest sense: the effect body contains nothing
# but `custom_tooltip`, and `is_valid`/`ai_is_valid` are `always = no`, so
# neither a player nor the AI can execute it. Opening the chart cannot change
# simulation state.
#
# The policy branches quote the dashboard's own `banking_dash_tt_<button>`
# keys, so the marker tooltip shows the policy's real name, description and
# `[GetStaticModifier(...).GetDesc]` effect list — no number is retyped here,
# and a rebalance of a policy updates its marker text automatically.
#
# Adding a marker kind = one `te_history_record_marker = { MARK = x }` call
# plus one branch below.
# ============================================================================
