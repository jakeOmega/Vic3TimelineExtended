# level by its bounds instead of setting it. Assumes the bounds run from -3
# (maximum subventions) to 3 (maximum tariffs) before this modifier, so
# max 3 - 2 = 1 and min -3 + 4 = 1: only "low tariffs" stays selectable. The
# Budget's grain buttons show the bounds the engine actually applies; record
