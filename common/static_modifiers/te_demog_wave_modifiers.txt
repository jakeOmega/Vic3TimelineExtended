# ============================================================================
# DEMOGRAPHICS — the event wave (phase 3): the options' modifiers
# Events: events/te_demog_wave_events.txt (docs/superpowers/specs/2026-10-08-demographics-design.md §9). Every one is
# granted in its option, so the option's tooltip shows it. Durations are set where they are added: the event
# frameworks' tiers (normal_modifier_time five years, long_modifier_time ten, very_long_modifier_time twenty).
# Interest groups' lines are an action's reception (vanilla's 5/10/20 for changing a law), so they sit on the option's
# own modifier for its duration rather than on the ±5 laws' scale.
# Women's work sits on phase 2 step 1's women's-work family (state_demog_womens_work_ratio_add), as Parental Leave's,
# never on the engine's working-adult field (test_demographics_registry's TestWorkforceLinesMoved).
# Two lines set a census type (state_sex_ratio_at_birth_add, state_desired_fertility_mult: script-only, read by the
# census at each state's step): a release comments them out (scripts/release/comment_out_census_inputs.py, rule 1), so
# each such modifier keeps a line of its own. The events never fire there (te_demog_wave_runs reads Full).
# Money: one-offs are add_treasury payments (te_demog_wave_cost_*); the Greying's two running reforms are weekly income
# (country_tax_income_add = 1 at a share of the pension bill) mirrored in the Budget Breakdown under Pension Reform
# (scripts/generators/gen_budget_breakdown.py).
# ============================================================================
