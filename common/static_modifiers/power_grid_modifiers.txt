# ============================================================================
# Power Grid: the Grid Transfer Station's flow modifiers
# ============================================================================
# Building scope, on a Grid Transfer Station, re-applied every month by
# te_grid_apply_station_modifiers_effect. Each scales one of
# pm_grid_transfer_base's four 1-unit lines: applied with multiplier Q - 1 the
# line moves Q a week (before throughput, which the order is divided by,
# te_grid_station_throughput_value, and staffing, which
# te_grid_station_factor_value measures and corrects for); applied with
# multiplier -1 it is off.
#
# One line each, so each can take its own multiplier: other modifiers on a
# station's Electricity lines (a state trait such as Niagara Falls'
# goods_output_electricity_mult +0.2) add to the line's multiplier, and the
# Electricity modifiers are applied net of them
# (te_grid_read_other_electricity_effect). Grid Power is the mod's own good,
# and nothing else touches its lines. A Grid Power line's Q is the flow times
# the grid's sending price (te_grid_power_rate), an Electricity line's the
# flow.
# ============================================================================
