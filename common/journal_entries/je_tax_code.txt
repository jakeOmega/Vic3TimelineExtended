# ============================================================================
# The Tax Code journal entry (legislated tax code, plan Task 7)
# ============================================================================
# Exists only under the tax code rule, full or light (te_tax_code_on, written
# positively, so a save from before the rule existed never shows it) and runs
# for a country once its taxation law has been carried over into a code
# (te_tax_entry_unlocked: te_tax_code_in_force, the migration marker
# te_tax_migrated >= 1, or under the light setting te_tax_light_in_force, the
# marker te_tax_light_on >= 1). The engine
# activates it on its next check once both `is_shown_when_inactive` and
# `possible` hold, as it does je_banking_cycle, so the migration flow (te_tax.3)
# is unchanged. Under the light setting a monthly safety net
# (te_tax_light_entry_net, common/on_actions/te_tax_on_actions.txt) adds it to a
# country in force that the engine left without a record of it. It never
# completes, fails or times out: the code is permanent.
#
# It holds no state, writes nothing and has no `immediate`: the code lives in
# the country's te_tax_* variables (docs/systems/tax_code_schema.md), which a
# revolution's winner inherits, and an inherited copy of the entry re-running
# an `immediate` would have nothing to repair. Under the full code it is
# display only. Under the light code it also carries the code's relief and the
# interest groups' reactions to rate changes, as scaling modifiers (below), so
# a country in force must hold it active. It has no scripted buttons and no
# progress bar, so no bars-on-top marker.
#
# Under the full code a save started before this entry existed does not get
# it: auto-activation reaches only new games (scripting_best_practices.md, "JE
# Auto-Activation Requires BOTH"). The rule is new on this branch, so only a
# development save from before Task 7 is affected. Under the light code such a
# save holds no copy of the entry, so te_tax_light_entry_net adds it (an add
# to a country with no copy is untested in game, as for Banking's net).
#
# The widgets (gui/journal_entry_widgets/te_tax_layout_widget.gui) are the
# Budget panel's Tax Code tab's own types: the overview with an Open Budget
# button above the status text, the enacted code below it, the history and How
# Tax Legislation Works at the foot.
