# State-level: a strike's success chance subtracts the defence of the state it
# lands on (nuclear_strike_success_chance). Techs, the NPT guarantee and the
# orbital battlestation grant it nationally, so today every state of a country
# carries the same value; a local grant (a building's state_modifiers) would
# defend one state.
