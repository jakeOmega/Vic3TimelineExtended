# Display only (NUC-6 of the 2026-10-27 GUI audit): what a readiness level or a
# launch authority does that script applies itself, so the posture's hovers can
# print it as the engine's coloured modifier lines rather than prose. The engine
# consumes none of these and no script reads them. They are carried only by the
# display modifiers nd_readiness_terms_* and nd_authority_terms_*
# (nuclear_deterrence_modifiers.txt), which nothing adds to a country: the
# readiness choices', the launch authorities' and the posture rows' hovers print
# them with GetStaticModifier(...).GetDesc. Each figure is the one the script
# uses (nuclear_deterrence_values.txt, nuclear_custody_values.txt); keep them in
# step when a tuning number changes (test_nuclear_deterrence.py pins them).
