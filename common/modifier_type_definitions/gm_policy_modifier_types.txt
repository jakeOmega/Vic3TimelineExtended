# Grand Monuments: the four monument policies as the engine's coloured lines
# (GM-2, the 2026-10-27 GUI audit). Script applies each policy itself
# (gm_policy_set and gm_compute_totals: the policy's factor on the steps, the
# venues' share, each monument's tourism), so these types are script_only:
# they exist to be rendered, through the display-only static modifiers
# gm_policy_*_display (common/static_modifiers/gm_modifiers.txt), on the
# policy buttons and the overview's policy hover. No country carries them.
# Each name starts with country_: the engine files a type by its name's first
# word and logs "Invalid category prefix" for one it can't (these were
# gm_monument_* until 2026-10-29; test_modifier_type_category_prefix.py).
