# ============================================================================
# MODERN ELECTION ISSUES
# Which party owns each side of an issue a modern election event raises.
# Read by me_save_issue_parties (common/scripted_effects/me_election_issue_effects.txt).
#
# me_ig_<issue>_lean (interest group): the group's law stances on the issue,
#   +2 strongly approve / +1 approve / -1 disapprove / -2 strongly disapprove
#   for each law on the issue's side, the reverse for each law against it.
#   law_stance reads the group's ideologies (its leader's included) and
#   ignores which law is in force.
# me_py_<issue>_support (party): its members' leans weighted by clout and
#   summed. Positive: the party is for the issue; negative: against it.
# me_py_<issue>_opposition (party): the same, negated, so ordered_active_party
#   (which sorts descending) can find the party most against it.
# ============================================================================
