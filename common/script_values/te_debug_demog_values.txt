# ============================================================================
# DEMOGRAPHICS TEST CONSOLE — script values for te_debug_demog.1's debug_log lines
# (events/te_debug_demog_events.txt; common/scripted_effects/te_debug_demog_effects.txt)
# ============================================================================
# Console only: nothing else reads these. Each line reads its numbers through
# [THIS.ScriptValue('x')|N] or [THIS.Var('x').GetValue|N], the forms that print the
# current scope's value (docs/guides/scripting_best_practices.md, "debug_log
# Loc-String Templating Limitations"). A people count prints as three groups,
# millions_thousands_units, each under 1000 (te_debug_demog_<name>_g1/_g2/_g3, the
# demographics probe's register form): 2_803_898 is 2,803,898 and a group drops its
# leading zeros (0_490_84 is 490,084). scripts/analysis/demographics_harness.py
# (_ungroup) reads them back. A signed count goes through its absolute value; the
# line writes the sign itself.
# ============================================================================
