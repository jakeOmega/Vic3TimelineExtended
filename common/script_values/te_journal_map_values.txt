# Journal entry map modes (vanilla 1.15; docs/systems/mod_systems/journal_map_modes.md). The Map Room's selector. Each
# map's color scale, its factor 0-1, is generated: te_journal_map_scales_generated.txt, from the table in
# scripts/generators/gen_journal_map_scales.py (one shape per family, so a change to a shape changes every map using it).

# ---------------------------------------------------------------------------
# The selector: which of the Map Room's maps the player picked
# ---------------------------------------------------------------------------
# 1 turmoil, 3 life expectancy, 4 fertility, 5 median age, 6 devastation, 7 natural change, 8 death rate, 9 birth
# rate, 10 infant mortality, 11 leading cause of death, 12 sex balance, 13 net migration, 14 aged 65 and over, 15 urban
# share, 16 Gini coefficient, 17 Dynastic Wealth; 0 none. 2 was literacy, retired because vanilla's own literacy map
# mode shows it (a save holding 2 shows the unpainted map and "Pick a map" until the next pick); 6 was the scope probe
# until the fourth session. A global variable (te_jmap_set_selector), since a state's map_color reaches neither the
# entry nor a country (the scope probe painted blue, 2026-11-05): one player's pick is every player's in multiplayer.
# Root-free, so the Map Room's state roots and the pick buttons' country roots read the same number.
te_jmap_selector = {
	value = 0
	if = {
		limit = { has_global_variable = te_jmap_sel }
		value = global_var:te_jmap_sel
	}
}
