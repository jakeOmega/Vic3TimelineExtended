# ============================================================================
# Space Race — Customizable Localization
# ============================================================================
# The three branching text families the milestone panels
# (gui/journal_entry_widgets/space_race_widget.gui) read. Everything here only
# READS script state; no branch re-derives a rule or a threshold.
#
#   sr_<m>_profile  the mission-profile / approach flavour that used to be 44
#                   triggered_desc branches on the nine journal entries. The
#                   branches and their triggers are carried over unchanged; only
#                   the repeated "Monthly Progress / Risk Modifier" tail was
#                   dropped, because the panel now shows those numbers itself.
#   sr_<m>_pace     one sentence explaining the pace figures beside it. Branches
#                   on sr_<m>_last_status, whose single derivation site is
#                   sr_set_milestone_status_base
#                   (common/scripted_effects/space_race_effects.txt):
#                     (absent) not running · 0 no approach · 1 safe · 2 ambitious
#                     3 safe + post-setback cooldown · 4 ambitious + cooldown
#   sr_prog_<m>     one word for that milestone's row in the programme overview.
#
# EVERY branch is has_variable-guarded and EVERY target key is plain text (game
# concepts aside). Customizable localization is evaluated for countries that
# have never opened the journal entry, so an unguarded `var:` read raises script
# errors, and this repo has no precedent for a scope expression inside a
# custom-loc target key — the numbers all live in the outer widget loc keys,
# which are read in real GUI context where the JournalEntry chain is proven.
# ============================================================================
