# ============================================================================
# The Map Room's options in words (docs/systems/mod_systems/journal_map_modes.md)
# ============================================================================
# The Map Room's Area, Outliers and Scale options are global variables (te_jmap_area, te_jmap_continent,
# te_jmap_trim, te_jmap_scale: common/script_values/te_journal_map_values.txt), and these texts name them: on the Map Options header, in every
# fitted pick's tooltip and in the hover of a state outside the area. Read as [GetPlayer.GetCustom('<key>')]: the
# triggers read only globals, so any country gives the same answer. A market's, a power bloc's and a country's names
# come from the viewer's scopes (global_var:te_jmap_viewer, the player who last clicked), never typed; the names of
# the continents and of the three kinds of area are vanilla's own keys.
#
# Each block ends on the default, the world and the default trim, which also covers an area whose anchor has gone
# (the viewer left its power bloc) until the next marking sends the option back to the world (te_jmap_mark_area):
# the bloc's name is asked for only while the viewer is in one.
# ============================================================================

# What the scale in force does, for a fitted pick's tooltip under any scale but the map's own
# (te_jmap_pick_<map>_scaled, which the pick's button shows in place of its own-curve description). A custom
# localization can't know which button is hovered, so there are three, and each pick's key names the one for its
# kind of map: a straight map, a map already on a doubling scale (where Logarithmic is its own curve), and a map
# with a meaningful midpoint (where Logarithmic and Ranked work on each side of it).
te_jmap_scale_text = {
	type = country
	random_valid = no

	text = {
		trigger = { te_jmap_scale = 1 }
		localization_key = te_jmap_scale_text_linear
	}
	text = {
		trigger = { te_jmap_scale = 2 }
		localization_key = te_jmap_scale_text_log
	}
	text = {
		trigger = { te_jmap_scale = 3 }
		localization_key = te_jmap_scale_text_ranked
	}
	text = {
		localization_key = te_jmap_scale_text_own
	}
}
