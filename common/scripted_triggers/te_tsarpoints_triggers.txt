# ============================================================================
# THE TSAR'S HEIR OF ALEXANDER AGENDA (je_tp_tsar_heir_of_alexander) — Rail
# Transport or better
#
# Vanilla's third button (je_tp_tsar_heir_of_alexander_button_3) asks for 75%
# of the army's battalions on Rail Transport. The mod's Air Transport and
# Space Transport each rule out Rail Transport on the same formation, and Rail
# Transport rules out both (extra_mobilization_options.txt), so a Russia that
# moved its army off rail onto a faster option lost the button (#1796).
# te_vanilla_tsarpoints_buttons.txt reads this trigger instead.
#
# The set is Rail Transport and every transport option the mod adds that rules
# it out. test_tsarpoints_rail_button.py derives the mod's from the option
# files and fails when this trigger leaves one out, so a transport option
# added later must be named here too. Truck Transport is vanilla's own and
# vanilla's button doesn't count it, so it stays out.
# ============================================================================

# Country scope. At least 75% of the army's battalions have Rail, Air or Space
