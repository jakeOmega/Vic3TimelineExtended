# Strategic Reserve — Scripted Triggers

# One unlock trigger per reserve good. This is the SINGLE source of truth for
# "is this good available in the Strategic Reserve UI yet". It is consumed by:
#   - common/scripted_guis/st_res_scripted_gui.txt  (`is_shown` per good)
#   - gui/journal_entry_widgets/strategic_reserve_widget.gui
#     (row visibility, via `ScriptedGui.IsShown`)
# Never duplicate these tech conditions in a GUI expression or a JE trigger —
# add the good here and reference the trigger.
#
# Country scope.
# ============================================================================
