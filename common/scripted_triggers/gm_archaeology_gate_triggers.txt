# Country scope; scope:gm_arch_gate_site is the site container (saved by
# gm_arch_has_gate_for). Whether this country has the technology that opens it.
# A site stores its technology as a flag (gm_site_tech) with the hyphen written as an
# underscore (pan-nationalism is flag:pan_nationalism), so the engine has no
# technology to look up by name: one branch per technology the table uses.
# test_grand_monument_archaeology.py keeps this in step with its ARCH_SITES table.
