# =============================================================================
# Vic3TimelineExtended — modern ship modifications
# =============================================================================
# Every modern ship has its own armor / guns / propulsion / range set, one
# section each below, sized to its hull the way the base game sizes its own.
#
# The rule (design: docs/superpowers/specs/2026-11-03-ship-module-scaling-design.md,
# enforced by test_ship_modules.py): each ship has a base-game class analogue
# (capitals the super dreadnought, cruiser escorts the light cruiser, the ASW
# destroyer and guided missile ship the destroyer, carriers the aircraft
# carrier, submarines the submarine, troop ships the troopship). For hull and
# crew damage, armor and hit points, supply capacity and power projection, the
# ship's total with MEDIUM modules is split between hull and module in the
# analogue's proportion, and light/high follow the analogue's tier ratios. So
# a default (medium) design fights as it did before 2026-11-03, and going from
# light to high modules buys what it does in the base game: about +65% hull
# damage, +150% armor, +35% hit points. Copying the parent's flat values
# instead (the old rule) made a heavy module on a late hull worth a few percent.
# Speed, critical hits, vulnerability, visibility and each set's thematic extras
# are outside the rule.
#
# Vulnerability (#1625): a gun module's ship_vulnerability_add is its analogue's
# gun module of the same tier, at the base game's current (1.15.1) value: super
# dreadnought 6/14/28, destroyer 3/7/14, aircraft carrier 6/14/56, light cruiser
# -/1/1, troopship 10/25/50, and none on the submarines, which the base game
# dropped. test_ship_modules.py checks it. The Swarm Coordination Vessel's high
# guns also screen (+56, its old 100 at the light cruiser's 270 -> 150 ratio).
#
# Ten sets were added on 2026-11-03 for ships that used to borrow another
# ship's set; their names come from that set (or, where it was the base
# game's 19th-century troopship or light cruiser, from a modern mod set) and
# their goods are its goods scaled by the ratio of the two hulls' costs.
#
# Goods (vanilla 1.15): the base game moved its ships' construction goods from
# the hull into the modules (hulls about -39%, modules about 20x, so at medium
# the two weigh about the same) and raised each class's medium total about 20%
# (the aircraft carrier 42%, at the mod's price for aeroplanes).
# Each mod ship followed its analogue: its medium total is the same multiple of
# the analogue's as before, split between hull and each slot's light / medium /
# high module as the analogue splits it, each block keeping its own mix of goods.
# =============================================================================
