# =============================================================================
# Vic3TimelineExtended — modern ship utility modifications
# =============================================================================
# Each is the successor of a base-game utility on the same stat: unlocked later,
# stronger on every stat the two share, and more goods (design:
# docs/superpowers/specs/2026-11-03-ship-module-scaling-design.md;
# test_ship_modules.py checks all three). Vanilla 1.15 raised its utilities' goods
# 21-26x (Large Carronades 9x); each successor's goods rose by the largest factor any of
# its predecessors took, so it keeps its margin. A ship can't fit a successor beside its
# predecessor because every mod ship lists the two in the same utility slot, and
# a slot holds one module (the test checks that too). Don't use incompatible_with
# here: on a ship modification the engine reads the documented bare form
# (incompatible_with = <key>) as an unclosed list, swallows every token up to
# the next closing brace (the modifier block) and logs "Failed to read key
# reference" in debug.log; the module keeps its goods and loses its effects. Effects are percentages wherever every
# ship that mounts the module has a proportional base; screening and detection
# stay flat, because capitals carry 5-15 screening and escorts 140-390. The two
# flat screening values (DEW Point Defense, Aegis Air Defense: 111) and Unmanned
# Aerial Vehicles' +28 follow the light cruiser's 1.14.5 screening rescale
# (270 -> 150) from their old 200 and 50 (#1625; header of extra_ship_types.txt).
# The two vulnerability reducers are sized as a ship's share of vanilla's Torpedo
# Nets ship: a capital with the Close-In Weapon System keeps 80% of the
# vulnerability one with Torpedo Nets keeps, with DEW Point Defense 60%. Vanilla
# 1.15 halved Torpedo Nets (-0.5 -> -0.25), so CIWS went -0.60 -> -0.40 and DEW
# -0.70 -> -0.55 (#1682); test_ship_modules.py pins the ratio to the snapshot.
#
# Roles decide the slot a module goes in on a mod ship (extra_ship_types.txt):
#   protection      hull and crew damage taken (the base game's Extended Sick
#                   Bay too)
#   countermeasures accuracy against the ship, vulnerability, visibility
#   weapons, sensors, support (everything else)
# A one-slot ship lists everything it mounts; a two-slot ship puts protection
# and countermeasures in one slot and the rest in the other; a three-slot ship
# gives protection, countermeasures and the rest a slot each. Each module sits
# in one slot per ship, so no module is fitted twice and no two damage-taken
# reducers stack.
#
# Accuracy against the ship (ship_suffered_accuracy_mult): no single term below
# -0.4, and an attacker's penalty against a type plus the target's built-in
# defense plus its best countermeasure stays above -0.8. The engine's rule for
# combining a target's suffered accuracy with the attacker's own bonuses is
# undocumented; if it adds them and the sum went negative, the attacker would
# miss 90% of the time with no log line. The budget holds in calm water: fog's
# -40% on the attacker can still take the added sum below zero, as it can for
# the base game's capitals against torpedo craft (1 - 0.66 - 0.40).
# =============================================================================
