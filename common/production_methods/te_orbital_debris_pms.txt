# ============================================================================
# ORBITAL DEBRIS REMOVAL — the Space Program's cleanup methods (Global Commons § 6.4)
# ============================================================================
# The production methods of pmg_space_program_debris_removal
# (te_orbital_debris_pmgs.txt), a secondary group on building_space_program.
# Each removes debris through country_orbital_debris_removal_add (points a
# month, workforce-scaled, so a half-staffed programme removes half) and
# carries a little prestige. The removal is summed by the global monthly pulse
# and taken from the high pool first (te_orbital_debris_effects.txt).
#
#   method                  gate                     Launch Capacity/wk  removal/mo  LC per point
#   None (default)          -                        0                   0           -
#   Active Debris Removal   reusable_rocketry        300                 0.05        ~26,000
#   Laser Broom             directed_energy_weapons  300 (+500 power)    0.15        ~8,700
#   Fusion Sweepers         compact_fusion_reactors  150                 0.5         ~1,300
#
# The Space Elevator doubles removal (+10% per fully staffed level, up to
# +100%: pm_space_elevator, te_debris_removal_mult_cap), and its own Launch
# Capacity makes every method cheaper in its market.
#
# The weekly Launch Capacity figures are mirrored by te_debris_units_*
# (te_orbital_debris_values.txt) for the AI's bill; test_orbital_debris.py
# holds them equal. No method employs anyone: the programme's own mission
# method staffs the building, and the debris methods ride on its workforce
# (pm_employment_audit stays clean).
# ============================================================================
