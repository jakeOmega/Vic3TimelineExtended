# ============================================================================
# COLONY MODULE FABRICATION — the Space Program's module methods (colony modules design § 5)
# ============================================================================
# The production methods of pmg_space_program_module_fabrication
# (sr_colony_module_pmgs.txt), a secondary group on building_space_program.
# Each gives module fabrication points a month through
# country_sr_module_fabrication_add (workforce-scaled, so a half-staffed
# programme fabricates at half the rate); every queued colony module costs
# sr_module_points (100) of them (sr_mod_month, sr_colony_module_effects.txt).
# The points do something only under the Simple and Full Colonies settings of
# the Space Race rule; a method can't be gated by a game rule
# (scripting_best_practices.md § Locking Production Methods), so its loc says so.
#
#   method               gate                      Launch Capacity/wk  Adv. Materials/wk  points/mo
#   None (default)       -                         0                   0                  0
#   Orbital Assembly     cislunar_infrastructure   1,500               10                 5
#   Orbital Foundries    space_colonization        2,000               15                 12
#   Fusion Shipyards     compact_fusion_reactors   2,000               10                 25
#
# Orbital Foundries keeps its first name's key, pm_sr_fabrication_lunar_foundries
# (renamed for Mare Imbrium's Mass Driver, lunar colonization design § 15.4).
#
# No method employs anyone: the programme's own mission method staffs the
# building, and these ride on its workforce, as debris removal does
# (pm_employment_audit stays clean).
# ============================================================================
