# AI coverage (#1822): export stances for two of the mod's goods, in vanilla's own style.
#
# Vanilla's administrative strategies say what a kind of economy sells: the agricultural and plantation strategies
# export the luxuries they grow (wine, liquor, coffee, tea, tobacco: `stance = wants_export`), the industrial one the
# chemical goods other economies need (explosives, fertilizer). No strategy did the same for any good the mod adds.
#   - Tourism is a luxury no building uses, sold to households at home and abroad: the two strategies that export
#     vanilla's luxuries export it, from Mass Tourism on (television_broadcasting), so the game before the mod's
#     eras plays as it did.
#   - Consumer Appliances are what an industrial economy sells the world: the industrial strategy exports them once
#     it can make them (personal_appliances unlocks the industry). A strategy's stance overrides the default's
#     (vanilla's comment on goods_stances; it is how vanilla's resource strategy exports the copper and oil its
#     default wants a high supply of), so industrial countries export where the default strategy
#     (edited_default_strategy.txt) wants a high supply.
# Both stances count as "favored" when the AI scores a building or a production method (NAI
# PRODUCTION_BUILDING_FAVORED_GOODS_FACTOR, PRODUCTION_METHOD_FAVORED_GOODS_FACTOR); an export stance also favors
# selling the good abroad over buying it (TRADE_VALUE_*_GOODS_DIRECTION_MULT).
#
# Unread in game: that an INJECT adds a new key to a strategy's goods_stances block. It does for a subsidies block
# (read 2026-10-16, scripting_best_practices.md), which is the same shape, and the default strategy's seven mod
# stances have relied on it since before that read. No trigger reads a stance, so the play-test list carries it
# (docs/testing/ai-economy-playtest.md § AI coverage of the mod's content).
#
# Another AI mod REPLACEs six of the seven vanilla administrative strategies; a REPLACE outlasts every INJECT, so
# with that mod on these stances are lost (the default strategy's are not). That is accepted.
# test_ai_goods_stances.py pins this file.

INJECT:ai_strategy_agricultural_expansion = {
	goods_stances = {
		tourism = {
			stance = wants_export
			trigger = {
				has_technology_researched = television_broadcasting
			}
		}
	}
}

INJECT:ai_strategy_plantation_economy = {
	goods_stances = {
		tourism = {
			stance = wants_export
			trigger = {
				has_technology_researched = television_broadcasting
			}
		}
	}
}

INJECT:ai_strategy_industrial_expansion = {
	goods_stances = {
		consumer_appliances = {
			stance = wants_export
			trigger = {
				has_technology_researched = personal_appliances
			}
		}
	}
}
