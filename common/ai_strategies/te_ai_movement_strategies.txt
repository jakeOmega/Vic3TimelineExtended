# AI coverage (#1822): the mod's four ideological movements on the political agendas' movement lists.
#
# Each vanilla political agenda lists the movements its government sides with (pro_movements) and against
# (anti_movements). No list named movement_environmental, movement_civil_rights, movement_anti_war or
# movement_transhumanist (common/political_movements/new_ideological_movements.txt), so every AI government was
# indifferent to all four. What a list does is not documented; movements can be bolstered and suppressed, and the
# lists are the only place a strategy names a movement.
#
# Placement is by what each movement's ideology wants, set against the interest groups the agenda favors and
# opposes (the mod's own stances; the table and the method are in docs/systems/mod_systems/ai.md § AI Coverage of
# the Mod's Content, and the method puts vanilla's own movements on the side vanilla lists them in 90 cases of 98):
#   - Civil Rights (multicultural citizenship, minority protection, devolution, strong courts): with the
#     progressive and egalitarian agendas, against the conservative, reactionary and nationalist ones.
#   - Anti-War (limited war, no war ministry, a militia, no colonies): with the egalitarian agenda, against the
#     conservative and nationalist ones.
#   - Transhumanist (unrestricted augmentation, open-source patents, algorithmic government, automation): with the
#     progressive agenda, against the conservative and reactionary ones.
#   - Environmental (an environment ministry, a fossil phase-out; against laissez-faire and extraction): with the
#     egalitarian agenda. It leans against the conservative and nationalist agendas' interest groups too, by a
#     smaller margin, and is left off their lists: the conservative agenda is the most common among AI countries,
#     and the climate system's calibration rests on how strong this movement grows.
# A movement near the middle for an agenda is on neither list, as vanilla leaves liberals off the conservative
# agenda's lists.
#
# Each INJECT adds to the list vanilla's agenda already has. Unread in game: that an INJECTed list appends on an AI
# strategy (it does on production method groups and laws). TE_SELF_CHECK ai_movement_lists
# (common/on_actions/te_ai_movement_lists_selfcheck_on_actions.txt) reads the effect.
# edited_political_strategies.txt INJECTs other fields into the same agendas; another AI mod's INJECTs into them
# merge with these. test_ai_movement_lists.py pins this file.

INJECT:ai_strategy_conservative_agenda = {
	anti_movements = {
		movement_civil_rights
		movement_anti_war
		movement_transhumanist
	}
}

INJECT:ai_strategy_reactionary_agenda = {
	anti_movements = {
		movement_civil_rights
		movement_transhumanist
	}
}

INJECT:ai_strategy_progressive_agenda = {
	pro_movements = {
		movement_civil_rights
		movement_transhumanist
	}
}

INJECT:ai_strategy_egalitarian_agenda = {
	pro_movements = {
		movement_environmental
		movement_civil_rights
		movement_anti_war
	}
}

INJECT:ai_strategy_nationalist_agenda = {
	anti_movements = {
		movement_civil_rights
		movement_anti_war
	}
}
