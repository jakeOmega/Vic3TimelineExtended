# The AI doesn't subsidize its coal and oil power plants (#933), its railways
# or its ports (#1050).
#
# Railways and ports: vanilla's default strategy pins both must_have, because a
# loss-making railway that shed workers took the state's infrastructure with
# it. Since #1050 their infrastructure counts per level, not per worker, and
# industry buys its freight as local transportation, so a state short of
# railways has dear transport and they pay their way. Their subsidy bill in
# the late-game saves #1050 read (£24-55M a week on ports, £27-48M on
# railways) came from passenger methods flooding their own state, not from
# freight.
#
# building_power_plant is the coal and oil plant; nuclear, fusion and renewable
# plants are their own buildings, which no strategy subsidizes. Vanilla's
# default strategy pins it must_have, so the AI's treasury paid every plant's
# losses, retooling included, even where cleaner plants had undercut it.
#
# should_remove makes the AI drop the subsidy. No vanilla strategy uses it and
# no engine doc lists the subsidy priorities; it sits beside must_have and
# nice_to_have among the game executable's strings. An INJECT can't change a
# key the default strategy's vanilla subsidies block already holds
# (edited_default_strategy.txt), but a strategy's value overrides the
# default's, so the value goes in every vanilla administrative strategy.
# Read in game 2026-10-16 (owner's late-game save, 2034.9.13 to 2035.1.1): AI
# power plants 1% subsidized in the first three strategies' countries (54
# plants) and 19% in the other four's (257 plants, 99% before), railways 98%
# throughout. docs/testing/ai-economy-playtest.md; the INJECT rules are in
# docs/guides/scripting_best_practices.md.

# No subsidies block in vanilla: each INJECT adds one.
INJECT:ai_strategy_agricultural_expansion = {
	subsidies = {
		building_power_plant = should_remove
		building_railway = should_remove
		building_port = should_remove
	}
}
