# ============================================================================
# DEMOGRAPHICS — the census sets the engine's births and deaths (phase 2 step 4)
# docs/superpowers/archive/plans/2026-10-10-demographics-phase2-engine-rates.md §2
# ============================================================================
# The engine gives every pop curve x max(0, 1 + total) births and deaths, adding every
# term (docs/testing/demographics-growth-probe-results-2026-10-09.md). The census's term M
# (te_demog_rates_refresh) makes a state's events the model's plus the terms added on top of
# the census: a state-level one (in the state read) acting on the census's rate, a pop's own on
# its bare curve (owner, 2026-10-11), and the census's next step scales its own rates to what the engine did
# (te_demog_on_top_scales), so the ring places the births and deaths added on top by age:
# newborns, and deaths by the model's own age pattern (owner, 2026-10-10).
#
# State variables:
#   te_dg_mb, te_dg_md  M for births and deaths (signed), behind the te_demog_census_* pair
#   te_dg_rate_clamped  1 when the last refresh clamped either term
#   te_dg_bz, te_dg_dz  the scales the last step used (te_dg_eb or te_dg_ed over the target,
#                       less 1)
#   te_dg_eb_target, te_dg_ed_target  that target: the births and deaths the model's rates gave
#                       at the step's population (0 when the step took no scales), kept for
#                       console option n, whose line re-derives bz and dz from them
#   te_dg_cbr_model, te_dg_cdr_model, te_dg_tfr_model  the model's own rates (per 1,000 a year;
#                       children per woman): the step's events without the on-top scales
#   te_dg_tb_b, te_dg_tb_d  the target over the bare curve (console option n)
#   te_dg_os_b, te_dg_os_d  the state-level lines on top M scaled to the census's rate (option n)
#   te_dg_rep_b, te_dg_rep_d  the replaced sums over the bare curves: the absorbed lines' share
#                       that M took out (console option n)
#   te_dg_sr_b, te_dg_sr_d  the engine's births and deaths rate per head at the start of the window
#                       that ends at the next step (the trapezoid, te_demog_window_events), a month x
#                       100,000: the walk's rate with the terms the step left in force. Stored by the
#                       refresh, moved by fast mode's term, removed by a seed and outside Full
#   te_dg_sp_d, te_dg_ss_d  the pops' own lines and severe starvation's part of them in that start rate, per head
#                       (the Causes of Death section's split, te_demog_on_top_split): stored, moved and removed with
#                       te_dg_sr_d
#   te_dg_rate_clamp_d  whether the floor bit the last refresh's deaths term: 0 no, 1 yes (the engine's own, -1)
#   te_dg_ed_clamp_d    its copy for the window the step's dz measured (te_demog_on_top_clamp_copy)
#   te_dg_ed_state, te_dg_ed_sev, te_dg_sev_share  the split of the window's deaths (te_demog_on_top_split; Full only)
# The walk's locals the refresh reads (te_demog_walks, same effect): te_dg_w_eb0 and te_dg_w_ed0,
# bare births and deaths a month x 100,000; te_dg_w_ebr and te_dg_w_edr, the replaced sums: each
# pop's bare curves x what the census absorbs for it (te_demog_absorbed_walk_pop, generated);
# te_dg_w_eb and te_dg_w_ed, each pop's bare curves x its own multiplier: the engine's rate.
# ============================================================================

# ---- The window's events: the trapezoid (owner, 2026-10-11; #894; the review of #907) -------------
# The walk is a snapshot: its expected births and deaths (te_dg_eb, te_dg_ed) are the engine's rate on the
# step's day x the window, and the step books the whole window that ends that day. A famine that began in
# early December was booked for all of Hannover's year to February 1898, and the residual read the deaths
# that never happened as immigrants (Germany 1898: +933k). Under Full the walk's tail books the window at
# the mean of the engine's rate at its two ends:
#   ED = (w x rate_start x people + (1 - w) x te_dg_w_ed) x te_demog_step_months / 100,000
# with w = te_demog_k_window_start_weight (0.5, the trapezoid; demographics_model.window_events). The
# rate at the start is the one the last step left in force (te_dg_sr_d, per head): the walk's rate then,
# with the terms the step changed swapped in. M is refitted only at a step, and fast mode's term is set at
# a clock step, so they hold all window and both ends carry them (option k takes the term off between two
# steps; te_demog_fast_clear_rates then drops the start's rate). So the refresh stores
#   rate_start = te_dg_w_ed + te_dg_w_ed0m x (M_new - M_prev - the moved lines' pairs it cleared)
# and fast mode adds te_dg_w_ed0m x (F_new - F_prev). te_dg_w_ed0m is the bare curves of the pops the
# engine doesn't floor at 0, which alone a change in the read reaches: severe starvation's births (-0.9 x
# the starvation value, -0.51 to -0.84 in the walk's steps) floor a pop's births when the rest of its
# total is low (Germany's 1898 famine, M about -0.28 and literacy 0.5: below food security 0.10, 3% of
# its severe people). Counting floored pops' bare curves too put a famine state's start births about a
# tenth high, when the walk took severe starvation flat and floored them whenever M was negative.
# Each end is the engine's whole rate, so every line
# that moved inside the window counts at the engine's own weight: severe starvation, the mild starvation M
# nets, a state line (devastation, pollution, an event) on every pop's bare curve, and the bare curves
# themselves as standard of living moves. The model's rate drifting is not in either end; it stays in dz's
# comparison with the target, as before. Births alike: a famine cuts births too. Both ends cover the same
# months (te_demog_step_months), so fast mode's window needs nothing more, and a switch of speed between
# steps is booked at the months it covered.
# No start rate (the first step after a seed, a new state, an old save, fast mode's first switch, which
# re-seeds) or not Full: the snapshot, as before. The residual (te_demog_flows), the step's scales
# (te_demog_on_top_scales) and console option n read te_dg_eb / te_dg_ed, so they all take the window's
# events. The refresh and fast mode read the walk's locals, today's snapshot, as they should: M and the
# term are fitted to today's lines.
# A refresh that sets no term (a seed) drops the start's rate, so the next window
# takes the snapshot rather than a rate two windows old.
# Second order: a pop the change in M moves across the floor (from just above 0 to below it, or back)
# counts as the walk found it. A second pulse in one year (no step) refits M and stores the start again
# mid-window, as the refit itself already did.

# THIS = a state, the walk's tail (te_demog_walks), straight after te_dg_eb and te_dg_ed: the window's
# events, as the header above says. Never below 0.
te_demog_window_events = {
	if = {
		limit = {
			te_demog_effects_run = yes
			has_variable = te_dg_sr_b
			has_variable = te_dg_sr_d
		}
		set_variable = {
			name = te_dg_eb
			value = {
				value = var:te_dg_sr_b
				multiply = state_population
				subtract = local_var:te_dg_w_eb
				multiply = te_demog_k_window_start_weight
				add = local_var:te_dg_w_eb
				multiply = te_demog_step_months
				divide = 100000
				min = 0
			}
		}
		set_variable = {
			name = te_dg_ed
			value = {
				value = var:te_dg_sr_d
				multiply = state_population
				subtract = local_var:te_dg_w_ed
				multiply = te_demog_k_window_start_weight
				add = local_var:te_dg_w_ed
				multiply = te_demog_step_months
				divide = 100000
				min = 0
			}
		}
	}
}

# THIS = a state, the walk's tail, straight after te_demog_window_events: the Causes of Death section's split of the
# window's deaths (docs/superpowers/archive/plans/2026-10-11-demographics-causes-of-death.md, Task 6). Under Full:
#   te_dg_ed_state  te_dg_ed less the pops' own lines over the window, at least 0: the state-level lines and the moved
#                   lines' on-top family, the absorbed lines M nets, and the census's own lag (M a window old, the
#                   model's rate drifting)
#   te_dg_ed_sev    severe starvation's part of the pops' own lines over the window
#   te_dg_sev_share the share of the state's people in severe starvation at the walk
# Each end as te_demog_window_events weighs it. Today's from the walk: the engine's rate less what it would be without
# any pop's own lines, w_ed - w_edr - (1 + read) x w_ed0 - the wealth read x w_edw (a floored pop's own lines took its
# deaths to 0; the wealth line, which the walk applies per pop since 2026-10-20, is the census's own under Full, so it
# stays in the whole state's part, beside the M that nets it), and te_dg_w_sevd. The start's from the refresh that stored te_dg_sr_d: te_dg_sp_d and te_dg_ss_d, per head. A start
# rate without them (a save from before this build) leaves no split, so the row waits for the next count. Outside
# Full the three go. The split multiplies back to te_dg_ed over the target (te_demog_deaths_whole_state, _severe,
# _other) except where an end's read was below -1. Its whole-state part, which counts every pop unfloored, is then
# negative, the deaths move into the other effects, and further down te_dg_ed_state floors at 0. M keeps the read at
# or above -1 when it is fitted (unless the read without it is already below), so the end alone gets there: state-level
# lines falling inside the window after M was fitted, or the read without M below te_demog_k_rate_total_floor. Rare:
# vanilla's largest negative state line is -0.5. Floor crossings from M's change cancel out of te_dg_ed_state, since
# both of its parts count every pop, and reach the product only through te_dg_ed's own floor at 0. A second walk in a
# year without a step (a state's second yearly pulse) rewrites te_dg_ed and the split but not dz or the target, so
# until the next step the factors multiply to the new te_dg_ed over the old target (#907 notes the same for M).
te_demog_on_top_split = {
	if = {
		limit = { te_demog_effects_run = yes }
		# today's: the pops' own lines in the engine's rate, a month x 100,000
		set_local_variable = {
			name = te_dg_split_own
			value = {
				value = modifier:state_mortality_mult
				add = 1
				multiply = local_var:te_dg_w_ed0
				add = local_var:te_dg_w_edr
				add = { value = modifier:state_mortality_wealth_mult multiply = local_var:te_dg_w_edw }
				multiply = -1
				add = local_var:te_dg_w_ed
			}
		}
		set_local_variable = { name = te_dg_split_sev value = local_var:te_dg_w_sevd }
		set_local_variable = { name = te_dg_split_ok value = 1 }
		# te_demog_window_events' limit: there the window took the start's rate, so the split takes the start's parts
		if = {
			limit = {
				has_variable = te_dg_sr_b
				has_variable = te_dg_sr_d
			}
			if = {
				limit = {
					has_variable = te_dg_sp_d
					has_variable = te_dg_ss_d
				}
				set_local_variable = {
					name = te_dg_split_own
					value = {
						value = var:te_dg_sp_d
						multiply = state_population
						subtract = local_var:te_dg_split_own
						multiply = te_demog_k_window_start_weight
						add = local_var:te_dg_split_own
					}
				}
				set_local_variable = {
					name = te_dg_split_sev
					value = {
						value = var:te_dg_ss_d
						multiply = state_population
						subtract = local_var:te_dg_split_sev
						multiply = te_demog_k_window_start_weight
						add = local_var:te_dg_split_sev
					}
				}
			}
			else = {
				set_local_variable = { name = te_dg_split_ok value = 0 }
			}
		}
		if = {
			limit = { local_var:te_dg_split_ok > 0 }
			set_variable = {
				name = te_dg_ed_state
				value = {
					value = local_var:te_dg_split_own
					multiply = te_demog_step_months
					divide = 100000
					multiply = -1
					add = var:te_dg_ed
					min = 0
				}
			}
			set_variable = {
				name = te_dg_ed_sev
				value = {
					value = local_var:te_dg_split_sev
					multiply = te_demog_step_months
					divide = 100000
					min = 0
				}
			}
			set_variable = {
				name = te_dg_sev_share
				value = {
					value = local_var:te_dg_w_sev
					divide = { value = local_var:te_dg_w_pop min = 1 }
					max = 1
				}
			}
		}
		else = {
			te_demog_on_top_split_clear = yes
		}
	}
	else = {
		te_demog_on_top_split_clear = yes
	}
}

te_demog_on_top_split_clear = {
	if = {
		limit = { has_variable = te_dg_ed_state }
		remove_variable = te_dg_ed_state
	}
	if = {
		limit = { has_variable = te_dg_ed_sev }
		remove_variable = te_dg_ed_sev
	}
	if = {
		limit = { has_variable = te_dg_sev_share }
		remove_variable = te_dg_sev_share
	}
}

# THIS = a state, at the top of te_demog_on_top_scales: the deaths clamp of the refresh whose M the window just
# measured ran on, before this step's refresh writes the next window's (te_dg_rate_clamp_d). With none (not Full, the
# first Full step after a seed or after Display only, an old save), the copy goes and the section's row waits for the
# next count.
te_demog_on_top_clamp_copy = {
	if = {
		limit = {
			te_demog_effects_run = yes
			has_variable = te_dg_rate_clamp_d
		}
		set_variable = { name = te_dg_ed_clamp_d value = var:te_dg_rate_clamp_d }
	}
	else_if = {
		limit = { has_variable = te_dg_ed_clamp_d }
		remove_variable = te_dg_ed_clamp_d
	}
}

# THIS = a state at the start of its step, straight after te_demog_prepare and te_demog_flows:
# the year's rates scaled by how far the engine's expected births and deaths over the window
# (te_dg_eb, te_dg_ed, from this step's walk) ran from the model's rates that M aimed at, at
# today's population. Under Full only, and only once a step has stored the model's rates.
# Each scale is at least -1 (no events) and has no ceiling (owner, 2026-10-20; until then -0.9 and +4): the rates cap
# each age's probability at 1 (te_demog_enter_group's max = 100000). With M free to reach -1, a late-game famine's
# severe starvation (+0.56 to +0.94 at the bare curve's weight, where the census's rate is a fiftieth of it) can take
# dz into the tens. Fixed point: every product a scale enters is the step's own events x at most 100,000 (people x a
# rate per 100,000 x the multipliers), inside 9.2e13 while the events stay under 900 million. The exception is the
# calendar estimate of deaths by cause in a late-game state: calendar ages put an immortal state's deaths fifty times
# too high, so a 300-million state's famine could pass the range. The late sweep's own count replaces that estimate,
# so the step skips it there (te_demog_step_begin).
te_demog_on_top_scales = {
	# the clamp that bit the window this step measures, for the Causes of Death section's hover
	te_demog_on_top_clamp_copy = yes
	set_local_variable = { name = te_dg_bz value = 0 }
	set_local_variable = { name = te_dg_dz value = 0 }
	set_variable = { name = te_dg_eb_target value = 0 }
	set_variable = { name = te_dg_ed_target value = 0 }
	if = {
		limit = {
			te_demog_effects_run = yes
			has_variable = te_dg_cbr_model
			has_variable = te_dg_cdr_model
		}
		set_variable = { name = te_dg_eb_target value = { value = var:te_dg_cbr_model multiply = state_population divide = 1000 } }
		set_variable = { name = te_dg_ed_target value = { value = var:te_dg_cdr_model multiply = state_population divide = 1000 } }
		if = {
			limit = { var:te_dg_cbr_model > 0 }
			set_local_variable = {
				name = te_dg_bz
				value = {
					value = var:te_dg_eb
					multiply = 1000
					divide = { value = var:te_dg_cbr_model multiply = state_population min = 1 }
					subtract = 1
					min = te_demog_k_on_top_scale_min
				}
			}
		}
		if = {
			limit = { var:te_dg_cdr_model > 0 }
			set_local_variable = {
				name = te_dg_dz
				value = {
					value = var:te_dg_ed
					multiply = 1000
					divide = { value = var:te_dg_cdr_model multiply = state_population min = 1 }
					subtract = 1
					min = te_demog_k_on_top_scale_min
				}
			}
		}
	}
	set_variable = { name = te_dg_bz value = local_var:te_dg_bz }
	set_variable = { name = te_dg_dz value = local_var:te_dg_dz }
	# the model's children per woman before the scale, then the year's rates with it
	set_variable = { name = te_dg_tfr_model value = local_var:te_dg_tfr }
	change_local_variable = { name = te_dg_tfr multiply = { value = local_var:te_dg_bz add = 1 } }
	set_variable = { name = te_dg_tfr value = local_var:te_dg_tfr }
	change_local_variable = { name = te_dg_m_inf multiply = { value = local_var:te_dg_dz add = 1 } }
	change_local_variable = { name = te_dg_m_ext multiply = { value = local_var:te_dg_dz add = 1 } }
	change_local_variable = { name = te_dg_m_chr multiply = { value = local_var:te_dg_dz add = 1 } }
	change_local_variable = { name = te_dg_m_work_f multiply = { value = local_var:te_dg_dz add = 1 } }
	change_local_variable = { name = te_dg_m_work_m multiply = { value = local_var:te_dg_dz add = 1 } }
}

# THIS = ROOT = a state, straight after te_demog_state_census in the effect that ran its walks (its
# yearly pulse, or a step of fast mode's clock): the census's births and deaths terms.
#   M = target / bare - 1 - replaced / bare - on_top x (1 - target / bare) + q x target / bare
# q: the moved lines' on-top family (the engine-lines plan, 2026-10-11), script-only, which the census adds at its rate.
# on_top: the state-level lines left on top (the read less the census's and fast mode's terms and
# the moved lines' pairs, floored at te_demog_k_rate_total_floor: past -1 the engine gives none), so each acts on the
# census's rate (owner, 2026-10-11); a pop's own lines on top stay on its bare curve.
# replaced: what the census absorbs per pop (owner amendment, 2026-10-10), at each pop's bare
# curves: literacy's -0.1 and mild starvation's terms. The laws', technologies' and institutions'
# lines are script-only (the engine-lines plan), so under Full the engine never applies the absorbed
# family and nothing needs netting; outside Full their pairs re-apply them. Severe starvation and
# every other term stay on top.
# target = the model's rate (te_dg_cbr_model, per 1,000 a year) x today's people, a month x 100,000,
# the walk's units (te_dg_w_eb0, te_dg_w_ed0). Clamped: the state read without the census's and
# fast mode's own terms ("other") plus M stays at or above te_demog_k_rate_total_floor, the engine's own per-pop floor
# (-1: a plain pop's events reach 0 there; owner, 2026-10-20), and M is never below 0 when other alone is past it. No
# ceiling: target / bare is at most the model's rate over the curves' lowest, so M stays finite. A walk under
# te_demog_k_rate_bare_min (less than one person at the curves' lowest, 80 births or 100 deaths a month per 100,000)
# has nothing to fit M to, and leaves the terms as they are, as a seed does.
# Always leaves two pairs of locals for fast mode, which runs next in the same effect:
#   te_dg_rate_prev_b/_d  the terms the walk's window ran with (read through has_modifier
#                         before anything here touches the modifiers)
#   te_dg_rate_new_b/_d   the terms in force after this refresh: the M it set, 0 when it
#                         clears, the prior terms when it skips. A later read in this effect
#                         takes these, never has_modifier: add_modifier and remove_modifier are
#                         invisible inside the effect that made them (scripting_best_practices.md)
# A seed (te_dg_stepped 0, and no te_dg_cbr_model: te_demog_seed removes it) leaves the terms as
# they are.
te_demog_rates_refresh = {
	set_local_variable = { name = te_dg_rate_prev_b value = te_demog_rate_births_applied }
	set_local_variable = { name = te_dg_rate_prev_d value = te_demog_rate_deaths_applied }
	set_local_variable = { name = te_dg_rate_new_b value = local_var:te_dg_rate_prev_b }
	set_local_variable = { name = te_dg_rate_new_d value = local_var:te_dg_rate_prev_d }
	# the moved lines' pairs this refresh clears (fast mode takes them off the walk's average): 0 unless it does
	set_local_variable = { name = te_dg_rate_lines_b value = 0 }
	set_local_variable = { name = te_dg_rate_lines_d value = 0 }
	# 1 once this refresh stores the next window's start rate (the trapezoid)
	set_local_variable = { name = te_dg_rate_sr value = 0 }
	if = {
		limit = { NOT = { te_demog_effects_run = yes } }
		te_demog_rates_clear = yes
		set_local_variable = { name = te_dg_rate_new_b value = 0 }
		set_local_variable = { name = te_dg_rate_new_d value = 0 }
	}
	else_if = {
		limit = {
			has_variable = te_dg_stepped
			has_variable = te_dg_cbr_model
			has_variable = te_dg_cdr_model
			local_var:te_dg_w_eb0 >= te_demog_k_rate_bare_min
			local_var:te_dg_w_ed0 >= te_demog_k_rate_bare_min
		}
		if = {
			limit = { var:te_dg_stepped > 0 }
			set_local_variable = { name = te_dg_rate_clamped value = 0 }
			# births
			set_local_variable = {
				name = te_dg_rate_tb
				value = {
					value = var:te_dg_cbr_model
					multiply = state_population
					multiply = 100
					divide = 12
					divide = { value = local_var:te_dg_w_eb0 min = 1 }
				}
			}
			# the state-level lines left on top (pollution, devastation, global warming, events): the read
			# without the census's and fast mode's terms and the moved lines' pair, which this step clears
			set_local_variable = {
				name = te_dg_rate_os
				value = {
					value = modifier:state_birth_rate_mult
					subtract = local_var:te_dg_rate_prev_b
					subtract = te_demog_fast_births_applied
					subtract = te_demog_line_births_applied
					min = te_demog_k_rate_total_floor
				}
			}
			# the moved lines' on-top family (the engine-lines plan): script-only, so the census adds it at its rate
			set_local_variable = { name = te_dg_rate_q value = modifier:state_demog_ontop_birth_rate_mult }
			set_local_variable = {
				name = te_dg_rate_m
				value = {
					value = local_var:te_dg_rate_tb
					subtract = 1
					subtract = {
						value = local_var:te_dg_w_ebr
						divide = { value = local_var:te_dg_w_eb0 min = 1 }
					}
					subtract = {
						value = 1
						subtract = local_var:te_dg_rate_tb
						multiply = local_var:te_dg_rate_os
					}
					add = {
						value = local_var:te_dg_rate_q
						multiply = local_var:te_dg_rate_tb
					}
				}
			}
			set_local_variable = {
				name = te_dg_rate_lo
				value = {
					value = te_demog_k_rate_total_floor
					subtract = modifier:state_birth_rate_mult
					add = local_var:te_dg_rate_prev_b
					add = te_demog_fast_births_applied
					add = te_demog_line_births_applied
					max = 0
				}
			}
			te_demog_rate_clamp = yes
			set_variable = { name = te_dg_mb value = local_var:te_dg_rate_m }
			set_variable = { name = te_dg_tb_b value = local_var:te_dg_rate_tb }
			set_variable = { name = te_dg_os_b value = local_var:te_dg_rate_os }
			set_variable = { name = te_dg_q_b value = local_var:te_dg_rate_q }
			# deaths
			set_local_variable = {
				name = te_dg_rate_tb
				value = {
					value = var:te_dg_cdr_model
					multiply = state_population
					multiply = 100
					divide = 12
					divide = { value = local_var:te_dg_w_ed0 min = 1 }
				}
			}
			# the state-level lines left on top (pollution, devastation, global warming, events): the read
			# without the census's and fast mode's terms and the moved lines' pair, which this step clears
			set_local_variable = {
				name = te_dg_rate_os
				value = {
					value = modifier:state_mortality_mult
					subtract = local_var:te_dg_rate_prev_d
					subtract = te_demog_fast_deaths_applied
					subtract = te_demog_line_deaths_applied
					min = te_demog_k_rate_total_floor
				}
			}
			# the moved lines' on-top family (the engine-lines plan): script-only, so the census adds it at its rate
			set_local_variable = { name = te_dg_rate_q value = modifier:state_demog_ontop_mortality_mult }
			# phase 3 (late-game §4.3, call 14): the census's wealth slope in the late game (te_demog_lx_wealth_slope), on
			# the census's rate, the richest pop held at the treated's rate; M nets what it moves (te_demog_lx_rate_slope)
			te_demog_lx_rate_slope = yes
			set_local_variable = {
				name = te_dg_rate_m
				value = {
					value = local_var:te_dg_rate_tb
					subtract = 1
					subtract = {
						value = local_var:te_dg_w_edr
						divide = { value = local_var:te_dg_w_ed0 min = 1 }
					}
					subtract = local_var:te_dg_rate_slope_net
					subtract = {
						value = 1
						subtract = local_var:te_dg_rate_tb
						multiply = local_var:te_dg_rate_os
					}
					add = {
						value = local_var:te_dg_rate_q
						multiply = local_var:te_dg_rate_tb
					}
				}
			}
			set_local_variable = {
				name = te_dg_rate_lo
				value = {
					value = te_demog_k_rate_total_floor
					subtract = modifier:state_mortality_mult
					add = local_var:te_dg_rate_prev_d
					add = te_demog_fast_deaths_applied
					add = te_demog_line_deaths_applied
					max = 0
				}
			}
			te_demog_rate_clamp = yes
			# whether the floor bit deaths, for the next window: 0 no, 1 yes (te_demog_on_top_clamp_copy)
			set_variable = { name = te_dg_rate_clamp_d value = local_var:te_dg_rate_side }
			set_variable = { name = te_dg_md value = local_var:te_dg_rate_m }
			set_variable = { name = te_dg_tb_d value = local_var:te_dg_rate_tb }
			set_variable = { name = te_dg_os_d value = local_var:te_dg_rate_os }
			set_variable = { name = te_dg_q_d value = local_var:te_dg_rate_q }
			# Private Health Insurance's wealth line (the on-top family's wealth field; owner, 2026-10-11, option b):
			# at the census's share of the bare curve, at least te_demog_k_wealth_line_floor a wealth level first
			set_variable = {
				name = te_dg_w
				value = {
					value = modifier:state_demog_ontop_mortality_wealth_mult
					min = te_demog_k_wealth_line_floor
					add = local_var:te_dg_rate_slope
					multiply = var:te_dg_tb_d
				}
			}
			# the census takes over: the moved lines' pairs come off (te_demog_lines_apply no longer holds), and fast
			# mode, next in this effect, takes what they were adding off the walk's average
			set_local_variable = { name = te_dg_rate_lines_b value = te_demog_line_births_applied }
			set_local_variable = { name = te_dg_rate_lines_d value = te_demog_line_deaths_applied }
			te_demog_lines_clear = yes
			set_variable = { name = te_dg_rate_clamped value = local_var:te_dg_rate_clamped }
			set_variable = { name = te_dg_rep_b value = { value = local_var:te_dg_w_ebr divide = { value = local_var:te_dg_w_eb0 min = 1 } } }
			set_variable = { name = te_dg_rep_d value = { value = local_var:te_dg_w_edr divide = { value = local_var:te_dg_w_ed0 min = 1 } } }
			# the engine's rate per head at the start of the window that begins here (the trapezoid,
			# te_demog_window_events): the walk's, with this refresh's M for the last one and without the moved
			# lines' pairs it clears, on the bare curves those reach; deaths swap the wealth line in force (the walk's read)
			# for this refresh's te_dg_w, on the bare deaths x wealth it reaches. Fast mode, next in this effect, moves it by
			# its own term's change
			set_variable = {
				name = te_dg_sr_b
				value = {
					value = var:te_dg_mb
					subtract = local_var:te_dg_rate_prev_b
					subtract = local_var:te_dg_rate_lines_b
					multiply = local_var:te_dg_w_eb0m
					add = local_var:te_dg_w_eb
					divide = { value = state_population min = 1 }
				}
			}
			set_variable = {
				name = te_dg_sr_d
				value = {
					value = var:te_dg_md
					subtract = local_var:te_dg_rate_prev_d
					subtract = local_var:te_dg_rate_lines_d
					multiply = local_var:te_dg_w_ed0m
					add = local_var:te_dg_w_ed
					add = { value = var:te_dg_w subtract = modifier:state_mortality_wealth_mult multiply = local_var:te_dg_w_edw }
					divide = { value = state_population min = 1 }
				}
			}
			# the start's own lines and severe starvation's part, per head (te_demog_on_top_split): today's, less the
			# change in the census's term on the pops the engine floors at 0, which it doesn't reach (te_dg_sr_d moves
			# by it on the others), and less the wealth line, which the split counts in the whole state's part
			set_variable = {
				name = te_dg_sp_d
				value = {
					value = var:te_dg_md
					subtract = local_var:te_dg_rate_prev_d
					subtract = local_var:te_dg_rate_lines_d
					multiply = { value = local_var:te_dg_w_ed0 subtract = local_var:te_dg_w_ed0m }
					multiply = -1
					add = local_var:te_dg_w_ed
					subtract = local_var:te_dg_w_edr
					subtract = { value = modifier:state_mortality_mult add = 1 multiply = local_var:te_dg_w_ed0 }
					subtract = { value = modifier:state_mortality_wealth_mult multiply = local_var:te_dg_w_edw }
					divide = { value = state_population min = 1 }
				}
			}
			set_variable = { name = te_dg_ss_d value = { value = local_var:te_dg_w_sevd divide = { value = state_population min = 1 } } }
			set_local_variable = { name = te_dg_rate_sr value = 1 }
			te_demog_rates_apply = yes
			set_local_variable = { name = te_dg_rate_new_b value = var:te_dg_mb }
			set_local_variable = { name = te_dg_rate_new_d value = var:te_dg_md }
		}
	}
	# no start rate stored (a seed, nobody): the one two windows old goes, and the next
	# window takes the snapshot
	if = {
		limit = { local_var:te_dg_rate_sr = 0 }
		if = {
			limit = { has_variable = te_dg_sr_b }
			remove_variable = te_dg_sr_b
		}
		if = {
			limit = { has_variable = te_dg_sr_d }
			remove_variable = te_dg_sr_d
		}
		if = {
			limit = { has_variable = te_dg_sp_d }
			remove_variable = te_dg_sp_d
		}
		if = {
			limit = { has_variable = te_dg_ss_d }
			remove_variable = te_dg_ss_d
		}
	}
	# the self-check rate_below_measured: arms this step's candidate or drops it
	te_demog_rbm_selfcheck_arm = yes
}

# ---- The self-check rate_below_measured (owner, 2026-10-20) --------------------------------------------------------
# The floor went from -0.8 to the engine's own -1, but the probes measured the engine's per-pop rate as linear only
# down to -0.9 (Q7, the growth probe). The walk assumes that line, so te_dg_ed and dz can't see a bend below -0.9;
# only the residual can. Once a game, under Full and at normal speed, a state whose deaths fall in one census step
# from the measured range (the walk's average multiplier over the bare curve at least 0.1 at both ends of the window
# just measured: an average total at or above -0.9) to -0.95 or below (the new window's start rate at most 0.05 of the
# bare curve), with no war dead, kills or known moves and a residual within a quarter of the new window's deaths, is
# armed; at its next step, if the window's end is at -0.95 or below too and nothing else moved people, the window's
# residual is compared with its expected deaths (the walk applies the census's wealth line per pop, as the engine does:
# te_demog_pop_death_mult). OK within half of them (the low side widened by a month of the old rate: a change of rate
# shows within a month, Q7); BROKEN below that band. A stop at -0.9 only adds deaths, so it pushes the residual down: a
# residual above the band is migration the baseline missed, which drops the arm with no line and leaves the check to a
# later state. The baseline is taken in the measured range on purpose: a residual taken below -0.9 would already hold
# the bend if there were one, and a state with that much migration would never arm. Why -0.95: if the engine stopped at
# -0.9, a window at -0.95 would see twice the deaths the walk expects, a gap the size of its deaths, which half of them
# catches; at -0.91 it would be a tenth. And the arm asks that gap to clear the band's low side (half the deaths and the
# month's lag) by the quarter of the deaths the baseline allows for migration, so a stop at -0.9 can't read OK however
# far the old rate stood above the new: an old window at 0.55 of the bare curve, a late medical leap, has a month's lag
# that would swallow it (the review of #1082). The console's replay (option a) runs the flows with no walk: the hook
# does nothing there. docs/testing/demographics-playtest.md.
# State variables while armed: te_dg_rbm_r0 (the baseline residual; alone, a candidate the refresh resolves),
# te_dg_rbm_s1 (the window's start multiplier) and te_dg_rbm_lag (a month at the old rate less the new, deaths).

# THIS = a state, in te_demog_flows straight after the residual (te_dg_mig, after Internal Resettlement's known moves):
# an armed state's verdict, then a candidate baseline from the window just measured.
te_demog_rbm_selfcheck_flows = {
	# the console's replay (te_debug_demog_replay) runs te_demog_flows with no walk: nothing to read, so nothing here
	if = {
		limit = { has_local_variable = te_dg_w_ed0 }
		if = {
			limit = { has_variable = te_dg_rbm_s1 }
			if = {
				limit = {
					NOT = { has_global_variable = te_demog_rbm_selfcheck_done }
					te_demog_effects_run = yes
					NOT = { te_demog_clock_on = yes }
					has_variable = te_dg_sr_d
					local_var:te_dg_war = 0
					local_var:te_dg_kills = 0
					local_var:te_dg_rk_on = 0
				}
				set_local_variable = { name = te_dg_rbm_s value = { value = local_var:te_dg_w_ed divide = { value = local_var:te_dg_w_ed0 min = 1 } } }
				set_local_variable = { name = te_dg_rbm_hi value = { value = var:te_dg_ed multiply = 0.5 } }
				set_local_variable = { name = te_dg_rbm_lo value = { value = local_var:te_dg_rbm_hi add = var:te_dg_rbm_lag multiply = -1 } }
				# above the band: migration the baseline missed (a stop at -0.9 only pushes the residual down), so no
				# verdict and no flag; a later state can arm
				if = {
					limit = {
						local_var:te_dg_rbm_s <= 0.05
						local_var:te_dg_mig <= local_var:te_dg_rbm_hi
					}
					set_global_variable = te_demog_rbm_selfcheck_done
					set_variable = { name = te_dg_rbm_s2 value = local_var:te_dg_rbm_s }
					set_variable = { name = te_dg_rbm_pop value = state_population }
					set_variable = { name = te_dg_rbm_r value = local_var:te_dg_mig }
					# the deaths the engine would have added had it stopped at -0.9 (the bare curve's tenth, less the expected)
					set_variable = {
						name = te_dg_rbm_gap
						value = { value = local_var:te_dg_w_ed0 multiply = 0.1 multiply = te_demog_step_months divide = 100000 subtract = var:te_dg_ed }
					}
					if = {
						limit = { var:te_dg_rbm_r >= local_var:te_dg_rbm_lo }
						debug_log = "TE_SELF_CHECK OK rate_below_measured state=[THIS.GetState.GetNameNoFormatting] people=[THIS.Var('te_dg_rbm_pop').GetValue|0] start=[THIS.Var('te_dg_rbm_s1').GetValue|3] end=[THIS.Var('te_dg_rbm_s2').GetValue|3] expected_deaths=[THIS.Var('te_dg_ed').GetValue|0] residual=[THIS.Var('te_dg_rbm_r').GetValue|0] baseline=[THIS.Var('te_dg_rbm_r0').GetValue|0] lag=[THIS.Var('te_dg_rbm_lag').GetValue|0] if_stopped_at_0_9=[THIS.Var('te_dg_rbm_gap').GetValue|0] (a year with the deaths total below -0.95 ran as the walk's linear line expects: the residual is within half of the expected deaths, so the engine's per-pop rate holds its line below -0.9 and the census's floor at -1 stands) date=[TimeKeeper.GetCurrentDate.GetString]"
					}
					else = {
						debug_log = "TE_SELF_CHECK BROKEN rate_below_measured state=[THIS.GetState.GetNameNoFormatting] people=[THIS.Var('te_dg_rbm_pop').GetValue|0] start=[THIS.Var('te_dg_rbm_s1').GetValue|3] end=[THIS.Var('te_dg_rbm_s2').GetValue|3] expected_deaths=[THIS.Var('te_dg_ed').GetValue|0] residual=[THIS.Var('te_dg_rbm_r').GetValue|0] baseline=[THIS.Var('te_dg_rbm_r0').GetValue|0] lag=[THIS.Var('te_dg_rbm_lag').GetValue|0] if_stopped_at_0_9=[THIS.Var('te_dg_rbm_gap').GetValue|0] (the residual is below the expected deaths' half and a month's lag: about minus if_stopped_at_0_9 means the engine stops at -0.9, and the census's floor goes back to -0.9; a figure far from it is emigration the baseline missed: see docs/testing/demographics-playtest.md) date=[TimeKeeper.GetCurrentDate.GetString]"
					}
					remove_variable = te_dg_rbm_s2
					remove_variable = te_dg_rbm_pop
					remove_variable = te_dg_rbm_r
					remove_variable = te_dg_rbm_gap
				}
			}
			remove_variable = te_dg_rbm_s1
			remove_variable = te_dg_rbm_lag
			if = {
				limit = { has_variable = te_dg_rbm_r0 }
				remove_variable = te_dg_rbm_r0
			}
		}
		else_if = {
			limit = { has_variable = te_dg_rbm_r0 }
			remove_variable = te_dg_rbm_r0
		}
		# a candidate: the window just measured sat in the measured range at both ends, and nothing but the engine's own
		# migration moved people (the refresh arms it or drops it, te_demog_rbm_selfcheck_arm)
		if = {
			limit = {
				NOT = { has_global_variable = te_demog_rbm_selfcheck_done }
				te_demog_effects_run = yes
				NOT = { te_demog_clock_on = yes }
				local_var:te_dg_war = 0
				local_var:te_dg_kills = 0
				local_var:te_dg_rk_on = 0
				local_var:te_dg_w_ed0 > 0
			}
			set_local_variable = { name = te_dg_rbm_s value = { value = local_var:te_dg_w_ed divide = { value = local_var:te_dg_w_ed0 min = 1 } } }
			if = {
				limit = { has_variable = te_dg_sr_d }
				set_local_variable = {
					name = te_dg_rbm_s
					value = {
						value = var:te_dg_sr_d
						multiply = state_population
						divide = { value = local_var:te_dg_w_ed0 min = 1 }
						max = local_var:te_dg_rbm_s
					}
				}
			}
			if = {
				limit = { local_var:te_dg_rbm_s >= 0.1 }
				set_variable = { name = te_dg_rbm_r0 value = local_var:te_dg_mig }
			}
		}
	}
}

# THIS = ROOT = a state, at the end of te_demog_rates_refresh: a candidate (te_demog_rbm_selfcheck_flows) is armed if this
# refresh stored the next window's start rate (local te_dg_rate_sr), that rate is at -0.95 or below (at most 0.05 of the
# bare curve), the window would hold at least 100 deaths a year, the candidate's residual is within a quarter of them,
# and the deficit a stop at -0.9 would leave (the bare curve's tenth less those deaths) clears the OK band's low side
# (half the deaths and a month's lag) by that quarter; otherwise it goes. A state already armed keeps its arm (a second
# pulse in a year refits M mid-window).
te_demog_rbm_selfcheck_arm = {
	if = {
		limit = {
			has_variable = te_dg_rbm_r0
			NOT = { has_variable = te_dg_rbm_s1 }
		}
		set_local_variable = { name = te_dg_rbm_ok value = 0 }
		if = {
			limit = {
				local_var:te_dg_rate_sr > 0
				has_variable = te_dg_sr_d
			}
			set_local_variable = {
				name = te_dg_rbm_s
				value = { value = var:te_dg_sr_d multiply = state_population divide = { value = local_var:te_dg_w_ed0 min = 1 } }
			}
			set_local_variable = {
				name = te_dg_rbm_e1
				value = { value = var:te_dg_sr_d multiply = state_population multiply = te_demog_step_months divide = 100000 }
			}
			set_local_variable = { name = te_dg_rbm_q value = { value = local_var:te_dg_rbm_e1 multiply = 0.25 } }
			set_local_variable = { name = te_dg_rbm_qn value = { value = local_var:te_dg_rbm_q multiply = -1 } }
			# a month at the old rate less the new (Q7: a change of rate shows within a month), deaths
			set_local_variable = {
				name = te_dg_rbm_lg
				value = {
					value = var:te_dg_sr_d
					multiply = state_population
					multiply = -1
					add = local_var:te_dg_w_ed
					divide = 100000
					min = 0
				}
			}
			# the deficit a stop at -0.9 would leave over the window, less what the OK band's low side and the baseline's
			# migration could take: above 0, a stop at -0.9 reads BROKEN
			set_local_variable = {
				name = te_dg_rbm_room
				value = {
					value = local_var:te_dg_w_ed0
					multiply = 0.1
					multiply = te_demog_step_months
					divide = 100000
					subtract = { value = local_var:te_dg_rbm_e1 multiply = 1.75 }
					subtract = local_var:te_dg_rbm_lg
				}
			}
			if = {
				limit = {
					local_var:te_dg_rbm_s <= 0.05
					local_var:te_dg_rbm_e1 >= 100
					var:te_dg_rbm_r0 <= local_var:te_dg_rbm_q
					var:te_dg_rbm_r0 >= local_var:te_dg_rbm_qn
					local_var:te_dg_rbm_room > 0
				}
				set_local_variable = { name = te_dg_rbm_ok value = 1 }
				set_variable = { name = te_dg_rbm_s1 value = local_var:te_dg_rbm_s }
				set_variable = { name = te_dg_rbm_lag value = local_var:te_dg_rbm_lg }
			}
		}
		if = {
			limit = { local_var:te_dg_rbm_ok = 0 }
			remove_variable = te_dg_rbm_r0
		}
	}
}
