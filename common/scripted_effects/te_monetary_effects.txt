# ============================================================================
# Monetary Policy — the single owner of the country-scope monthly update
# ============================================================================
# Spec: docs/systems/monetary_policy_design.md — §4 (the rate stack), §5 (the
# regime ladder), §6 (delegation, mandates, AI), §7 (risk premium), §8 (the
# hidden neutral rate and the stance band), §14 (alternative economies),
# §16.1-16.2 (the implementation mapping this file follows step for step).
#
# EVERY variable this file owns is documented, with its range, in the header of
# common/script_values/te_monetary_script_values.txt. Two rules from §16.2 hold
# everywhere below:
#
#   * every variable initialises behind `has_variable` (step 0), and
#   * NONE of them is ever removed. te_rate_paid_applied backs a live
#     `add_modifier { multiplier = ... }`, so a remove_variable on it would make
#     every later re-evaluation read 'none' — that is what
#     modifier_multiplier_var_audit exists to catch.
#
# Nothing here is gated on `banking_system_enabled` (§16.1): with the banking
# rule switched off a country still pays reference rate + premium, and vanilla's
# flat 20% base is cancelled in INJECT:base_values either way — so with this
# switched off too, every country would borrow free.
#
# ORDER (§16.2): 0 init -> 1 regime code -> 1b monetisation -> 2 target ->
# 3 drift -> 4 no-dial derived rate -> 5 premium -> 6 inflation -> 6c band
# modifier -> 6d real-wage dividend -> 7 rate paid -> 8 neutral rate + stance ->
# 8b creditor-versus-debtor politics -> 9 re-apply the interest modifier ->
# 10 gold flow, hot money and peg confidence (phase 3, §12). Steps 1b, 6c, 6d
# and 8b are numbered rather than renumbering
# §16.2's list: 1b settles an INPUT the later steps read (§11's monetisation
# level), the way step 1 settles the regime code, 6c and 6d are the engine-write
# half of step 6 (6a is the basket and 6b the inflation loop), and 8b is the
# engine-write half of step 8 — it consumes the band step 8 has just written
# and must not run before it.
#
# THE RATE STACK READS INFLATION (§4, §6, §7.6, §8, §10). Step 6 computes the
# basket, core, headline and expected inflation, and the rest of the stack is
# pointed at them: the mandates react to CORE (step 2), a no-dial country's
# derived rate carries its own expected inflation (step 4), the cyclical
# premium prices unanchored expectations and monetisation (step 5), the rate
# paid is built on the lenders' floor and net of realised inflation (step 7),
# and the stance gap is a REAL rate (step 8).
#
# WHICH FIGURE GOES WHERE. Core is what the mandates steer on — a delegated
# bank looks through a supply shock (§9.1) — while headline is what the real
# rate, the rate paid and the §9.2 bands use, and expected is what lenders
# price. Nothing outside step 6 writes any of them, with the one documented
# exception of the §9.2 hyperinflation crisis (events/te_inflation_events.txt),
# whose two escapes ARE a reset of those figures — see the variable contract.
#
# WORKING VARIABLES. te_mon_work and te_mon_work2 are scratch slots reused by
# every step; te_mon_era_base_now caches the world reference rate for this
# pulse; te_mon_growth_term holds the neutral rate's yearly GDP-growth term
# between yearly snapshots. All four persist (never removed) like the rest.
# ============================================================================


# ----------------------------------------------------------------------------
# WORLD REFERENCE RATE — evaluated once a month for the whole world
# ----------------------------------------------------------------------------
# te_mon_era_base costs two `any_country` scans per evaluation, so calling it
# per country per pulse would be O(N^2) trigger evaluations a month. It is a
# WORLD quantity that changes at most twice per campaign, so it is computed once
# into a global variable and every country reads the global.
#
# Scope: any (the value is world-wide). The `random_country` wrapper exists only
# so the script value is evaluated in country scope, which is what its header
# documents it for; the two `any_country` scans inside it do not depend on which
# country is picked.
te_monetary_refresh_world_era_base = {
	random_country = {
		set_global_variable = {
			name = te_mon_era_base_world
			value = te_mon_era_base
		}
	}
}


# ----------------------------------------------------------------------------
# THE WORLD RATE (§12.1) — evaluated once a month for the whole world
# ----------------------------------------------------------------------------
# global_var:te_world_rate is a REAL rate: the GDP-weighted mean of
# te_policy_rate - te_inflation_expected over the great powers whose rate is
# DISCRETIONARY (te_mon_rate_is_discretionary: a dial, and not on peg defence).
# Whenever no great power qualifies it is the reference rate, te_mon_era_base —
# which is what it is in 1836, where Britain's AI bank is on peg defence and
# France and Austria are on commodity money with no dial at all.
#
# DISCRETIONARY-ONLY IS WHAT KEEPS IT FROM BEING CIRCULAR. A peg defender's
# target IS the world rate and a no-dial rate is world + spread, so averaging
# either would define the world rate in terms of itself and ratchet it up by the
# spread every month. §19 row 3's first exit criterion — "sits at era_base in
# 1836 and does not drift on its own" — is this gate and nothing else.
#
# IT READS WHAT THE COUNTRIES' LAST PULSE LEFT. The relative order of the global
# on_monthly_pulse and on_monthly_pulse_country is unknown (§17 check 7), so the
# inputs may be this month's or last month's, and every consumer reads the
# per-country copy step 0 takes (te_mon_world_rate_now). The policy rate moves a
# third of a point a month and expectations slower, so the lag is immaterial.
#
# TWO ACCUMULATORS, reset here every call: sum of weight x real rate, and sum
# of weight, with weight = GDP in millions (fixed-point headroom, §12.1).
#
# THE DEBUG OFFSET. global_var:te_world_rate_debug_offset is added when it
# exists. Nothing in play sets it; te_debug_monetary.8 does, because §19 row 3's
# third exit criterion ("AI on peg defence survives a 2pp world-rate rise")
# cannot otherwise be staged without waiting for a great power to hike.
#
# Must run AFTER te_monetary_refresh_world_era_base, whose global it falls back
# on. Scope: any.
te_monetary_refresh_world_rate = {
	set_global_variable = { name = te_world_rate_acc_num value = 0 }
	set_global_variable = { name = te_world_rate_acc_den value = 0 }
	# Last month's members forget their share first, so a country that has
	# dropped out of the average (lost rank, gone on to peg defence) does not
	# go on subtracting a contribution it no longer makes — see step 0.
	every_country = {
		limit = {
			has_variable = te_mon_world_own_den
			var:te_mon_world_own_den > 0
		}
		set_variable = { name = te_mon_world_own_num value = 0 }
		set_variable = { name = te_mon_world_own_den value = 0 }
	}
	every_country = {
		limit = {
			country_rank >= rank_value:great_power
			te_mon_rate_is_discretionary = yes
		}
		# Each member keeps the EXACT share it contributed (owner decision H):
		# step 0 subtracts it, so the world rate a great power faces is the
		# REST of the world's. Recorded here rather than recomputed there
		# because the pulse order is unknown (§17 check 7) and a share
		# recomputed a month later would not be the one in the sum.
		set_variable = { name = te_mon_world_own_num value = te_mon_world_rate_weighted_real }
		set_variable = { name = te_mon_world_own_den value = te_mon_world_rate_weight }
		change_global_variable = { name = te_world_rate_acc_num add = var:te_mon_world_own_num }
		change_global_variable = { name = te_world_rate_acc_den add = var:te_mon_world_own_den }
	}
	if = {
		limit = { global_var:te_world_rate_acc_den > 0 }
		set_global_variable = { name = te_world_rate value = global_var:te_world_rate_acc_num }
		change_global_variable = { name = te_world_rate divide = global_var:te_world_rate_acc_den }
	}
	else = {
		set_global_variable = { name = te_world_rate value = global_var:te_mon_era_base_world }
	}
	if = {
		limit = { has_global_variable = te_world_rate_debug_offset }
		change_global_variable = { name = te_world_rate add = global_var:te_world_rate_debug_offset }
	}
	if = {
		limit = { global_var:te_world_rate < te_mon_world_rate_min }
		set_global_variable = { name = te_world_rate value = te_mon_world_rate_min }
	}
	if = {
		limit = { global_var:te_world_rate > te_mon_world_rate_max }
		set_global_variable = { name = te_world_rate value = te_mon_world_rate_max }
	}
}


# ----------------------------------------------------------------------------
# THE MONTHLY UPDATE — country scope
# ----------------------------------------------------------------------------
# Called from on_monthly_pulse_country and on_country_formed directly, and from
# on_game_started and the six country-creation on-actions through the hidden
# dispatch event te_monetary_internal.1 — all of them wired in
# common/on_actions/te_monetary_on_actions.txt. A country that has never run it
# carries no rate modifier and borrows at 0%, because the flat base is cancelled
# in INJECT:base_values — which is the reason the creation hooks exist at all
# (§16.1).
#
# THE CALLER'S ROOT MUST BE THE COUNTRY BEING UPDATED. Step 9 applies its
# modifier with `multiplier = var:...`, which the engine resolves against ROOT
# rather than against the scope this effect is running in. That is why the two
# families of entry point with the wrong ROOT — game start (ROOT `none`) and
# country creation (ROOT the parent) — go through a country event instead of
# calling this effect inside an iterator or a `scope:target = { }` block. Any
# new entry point must satisfy the same rule; step 9's te_rate_paid_rooted
# marker is the net if one does not.
#
# NOT IDEMPOTENT WITHIN A MONTH. Step 3 advances the policy rate toward the
# target by a third of a point per call, step 6 draws the inflation noise walk
# and advances core inflation, its trailing basket average and expectations by
# one month's worth per call, step 8 draws both of the neutral rate's random
# walks per call, and step 1b's AI rule walks the monetisation level one step
# back per call — so calling this twice in one month drifts twice as fast and
# ages the hidden state twice as quickly. Call it ONLY from the pulse and country-creation
# on-actions listed above — never from an event, a scripted button, a scripted
# GUI or a journal entry's on_monthly_pulse. Anything that needs the rate to
# reflect a change it just made should write the input and let the next pulse
# pick it up.
#
# WAITING A MONTH IS CHEAP; THE PULSE ITSELF IS NOT FREE ANY MORE. Step 9 skips
# the remove/re-add when the rate has moved less than 0.05pp, which under phase
# 1 meant an unchanged month cost nothing. Phase 2's cost-push is a fresh
# basket reading every pulse rather than a level that sits still, so the rate
# paid moves every month for most countries with a market and the skip catches
# the becalmed and the market-less rather than the majority. §0.4 checklist 34
# is the in-game read of what that costs in tick time.
# (The sole deliberate exception is the console-only debug event
# events/te_debug_monetary_events.txt, whose entire purpose is stepping the
# system by hand.)
#
# NO STEP OF THIS EFFECT MAY BE CALLED IN ISOLATION. The pulse family calling
# the full update is the whole list. Step 9 (te_monetary_apply_interest_modifiers)
# is the only step that even could be called on its own — it is idempotent,
# recomputing the applied value, comparing, and re-adding the modifier without
# drifting the rate or drawing a walk — and it used to be, from
# `on_acquired_technology`, to close the gap between a vanilla finance tech
# granting its -2pp instantly and the next monthly pulse compensating for it in
# script. The five vanilla finance techs are now cancelled engine-side in
# common/technology/technologies/te_monetary_tech_injections.txt, so there is no
# gap left to close and that hook is gone. Do not reintroduce a second entry
# point without a reason of the same kind.
te_monetary_monthly_update = {
	# --- 0. initialise ------------------------------------------------------
	te_monetary_init_variables = yes

	# --- 1. regime code -----------------------------------------------------
	te_monetary_set_regime = yes

	# --- 1b. monetising the deficit, and the minting it buys ----------------
	# Before the premium and the pressure sum, both of which read the level.
	te_monetary_update_monetisation = yes

	# --- 2/3. the dial: target, then drift toward it ------------------------
	# --- 4. no dial: the rate is derived, never chosen ----------------------
	if = {
		limit = { te_mon_has_dial = yes }
		te_monetary_update_target = yes
		te_monetary_drift_policy_rate = yes
	}
	else = {
		te_monetary_set_derived_rate = yes
	}

	# --- 5. risk premium, structural then cyclical --------------------------
	te_monetary_update_premium = yes

	# --- 6. the basket, core inflation, headline and expectations -----------
	te_monetary_update_inflation = yes

	# --- 6c. the band modifier, and the hyperinflation crisis ---------------
	# Immediately after the band number is written, so the modifier on the
	# country is never a month behind the figure the dashboard shows.
	te_monetary_apply_inflation_band = yes

	# --- 6d. the real-wage dividend the comfort band pays -------------------
	# After 6c, and for the same reason: it keys off the band this month's
	# step 6 just wrote, so the dividend arrives with the band rather than a
	# month behind it.
	te_monetary_apply_wage_dividend = yes

	# --- 7. the rate the government actually pays ---------------------------
	te_monetary_update_rate_paid = yes

	# --- 8. hidden neutral rate, stance gap, displayed band -----------------
	te_monetary_update_stance = yes

	# --- 8b. the politics a sustained stance earns (§13) --------------------
	# After step 8, and for the same reason 6c follows 6: it counts months of
	# the DISPLAYED band, so it has to see the one step 8 has just written
	# rather than last month's.
	te_monetary_apply_stance_politics = yes

	# --- 9. write it into the engine ----------------------------------------
	te_monetary_apply_interest_modifiers = yes

	# --- 10. gold flow, hot money, peg confidence (§12.2-12.3) --------------
	# Last, as §16.2 orders it: it reads the policy rate step 3 settled and
	# writes the flow step 6 will price NEXT month (the same one-month lag
	# ruling P5 accepts for the stance gap).
	te_monetary_update_gold = yes
}


# ----------------------------------------------------------------------------
# STEP 0 — initialise
# ----------------------------------------------------------------------------
# Scope: country.
#
# te_policy_rate and te_neutral_rate are seeded to the world reference rate and
# the target to the nearest integer above/below it, so a country's very first
# pulse produces a sane rate instead of a zero. te_rate_paid_applied seeds to 0
# so step 9's 0.05 threshold always fires on that first pulse.
#
# te_mon_gdp_last_year is seeded here as well as in the yearly snapshot, so the
# first January after the game starts yields a real growth reading rather than a
# 100% one against an empty baseline.
te_monetary_init_variables = {
	# Self-healing read of the world reference rate: this also covers a save
	# made before the system existed (no on_game_started fires for those) and
	# any pulse that happens to run before the month's global refresh.
	if = {
		limit = { NOT = { has_global_variable = te_mon_era_base_world } }
		te_monetary_refresh_world_era_base = yes
	}
	# No has_variable guard on this one, deliberately: it is a per-pulse cache of
	# the world reference rate, not persistent state, and it must be overwritten
	# every pulse or a country would keep reading the era it was created in.
	set_variable = { name = te_mon_era_base_now value = global_var:te_mon_era_base_world }

	# The same per-pulse cache for the phase-3 WORLD rate (§12.1), and the same
	# self-heal: a save from before phase 3, or a pulse that beats the month's
	# first global refresh, reads the reference rate — which is exactly §12.1's
	# stated fallback when has_global_variable is false.
	if = {
		limit = { has_global_variable = te_world_rate }
		set_variable = { name = te_mon_world_rate_now value = global_var:te_world_rate }
	}
	else = {
		set_variable = { name = te_mon_world_rate_now value = var:te_mon_era_base_now }
	}

	# NOBODY FACES A WORLD RATE THAT CONTAINS ITSELF (owner decision H,
	# 2026-09-20). A great power inside the average takes its own recorded
	# share back out, so what it faces is the rest of the world's rate — and the
	# reference rate when there is no rest. Without this a lone discretionary
	# power (a player Britain in 1836) WAS the world rate: its gap was 0 by
	# construction, so it had no gold flows and no peg to defend. Everybody
	# else still sees the full average, hegemon included.
	#
	# The global's debug offset and clamp are re-applied, because this branch
	# rebuilds the figure from the accumulators rather than from the global.
	if = {
		limit = {
			has_variable = te_mon_world_own_den
			var:te_mon_world_own_den > 0
			has_global_variable = te_world_rate_acc_den
		}
		set_variable = { name = te_mon_work2 value = global_var:te_world_rate_acc_den }
		change_variable = { name = te_mon_work2 subtract = var:te_mon_world_own_den }
		if = {
			limit = { var:te_mon_work2 > 0.0005 }
			set_variable = { name = te_mon_world_rate_now value = global_var:te_world_rate_acc_num }
			change_variable = { name = te_mon_world_rate_now subtract = var:te_mon_world_own_num }
			change_variable = { name = te_mon_world_rate_now divide = var:te_mon_work2 }
		}
		else = {
			set_variable = { name = te_mon_world_rate_now value = var:te_mon_era_base_now }
		}
		if = {
			limit = { has_global_variable = te_world_rate_debug_offset }
			change_variable = { name = te_mon_world_rate_now add = global_var:te_world_rate_debug_offset }
		}
		clamp_variable = {
			name = te_mon_world_rate_now
			min = te_mon_world_rate_min
			max = te_mon_world_rate_max
		}
	}

	if = {
		limit = { NOT = { has_variable = te_mon_work } }
		set_variable = { name = te_mon_work value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_work2 } }
		set_variable = { name = te_mon_work2 value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_policy_rate } }
		set_variable = { name = te_policy_rate value = var:te_mon_era_base_now }
	}
	if = {
		limit = { NOT = { has_variable = te_policy_rate_target } }
		set_variable = {
			name = te_policy_rate_target
			value = {
				value = var:te_mon_era_base_now
				round = yes
			}
		}
	}
	if = {
		limit = { NOT = { has_variable = te_mon_delegated } }
		set_variable = { name = te_mon_delegated value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_mandate } }
		set_variable = { name = te_mon_mandate value = 1 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_regime } }
		set_variable = { name = te_mon_regime value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_premium_structural } }
		set_variable = { name = te_premium_structural value = 0.5 }
	}
	if = {
		limit = { NOT = { has_variable = te_premium_cyclical } }
		set_variable = { name = te_premium_cyclical value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_rate_paid_pts } }
		set_variable = { name = te_rate_paid_pts value = 0.5 }
	}
	if = {
		limit = { NOT = { has_variable = te_rate_paid_applied } }
		set_variable = { name = te_rate_paid_applied value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_neutral_rate } }
		set_variable = { name = te_neutral_rate value = var:te_mon_era_base_now }
	}
	if = {
		limit = { NOT = { has_variable = te_neutral_error } }
		set_variable = { name = te_neutral_error value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_neutral_walk } }
		set_variable = { name = te_neutral_walk value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_growth_term } }
		set_variable = { name = te_mon_growth_term value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_gdp_last_year } }
		set_variable = { name = te_mon_gdp_last_year value = te_mon_gdp_current }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_stance_gap } }
		set_variable = { name = te_mon_stance_gap value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_stance_band } }
		set_variable = { name = te_mon_stance_band value = 3 }
	}

	# --- phase 2: inflation (§9) --------------------------------------------
	# Every one of these seeds to a neutral zero, which is exactly what phase 1
	# behaviour is: no inflation, expectations at nothing, no monetisation, no
	# dollarisation. A phase-1 save therefore gains a set of zeroes and keeps
	# paying exactly what it paid, until step 6 starts moving them.
	#
	# THE ZEROES ARE WHAT A PHASE-1 SAVE AND AN UNPULSED 1836 COUNTRY LOOK
	# LIKE — AND ONLY THE FIRST PULSE IS INERT (final-review finding I1; spec
	# §0.4 owner decision G). Every 1836 country starts on commodity money —
	# Britain on gold — and both are metallic, so expectations stay pinned at 0
	# and the regime pull holds core down. That is NOT the same as "phase 2
	# evaluates to zero on a metallic start", which is what this comment used
	# to claim:
	#
	#   * the FIRST pulse is genuinely inert in cost-push, because step 6a
	#     seeds te_basket_avg to that month's index, so index - avg = 0;
	#   * from the SECOND pulse te_cost_push = 0.3 x (index - 36-month avg) x
	#     100, clamped +/-6, for every country with a market, metallic or not.
	#     A basket a few per cent under its own trailing average is an ordinary
	#     reading, and it goes straight onto headline, off the rate paid in
	#     step 7, into the band, and — for a country with a dial — into the
	#     stance gap in step 8;
	#   * core is not pinned either. Metallic money pins EXPECTATIONS and pulls
	#     core toward 0; it does not zero the rest of the pressure sum (deficit,
	#     cycle phase, bubble, the noise walk, any law or event pressure), so
	#     core settles where the pull and that sum balance rather than at 0.
	#
	# So §7.4's anchor figures hold on an 1836 start only +/- the cost-push
	# term, and the band can read Deflation or Elevated for a gold country. The
	# owner's decision was to keep the economics spec-faithful and add the band
	# hysteresis in step 6b; §0.4 decision G names the three one-line levers if
	# play shows it too noisy. The first country to enact fiat is still the
	# first to leave zero in the sense that matters — it is the first with an
	# expectations term of its own.
	#
	# TWO EXCEPTIONS TO THE ZERO. te_inflation_band seeds to 2 (comfort),
	# because 0 is not a band and the band swap has to have something to
	# compare against; te_inflation_band_applied seeds to 0, which means "no
	# band modifier has been applied yet" and is a legal value.
	#
	# te_basket_market_owner is a SCOPE variable, so it cannot hold 0. It seeds
	# to the country's current market owner, and to nothing at all for a
	# country with no market — the one phase-2 variable that can legitimately
	# be absent after init. Read it with `var:te_basket_market_owner = { ... }`
	# behind a has_variable guard, never as a number and never through a
	# GetValue loc accessor.
	if = {
		limit = { NOT = { has_variable = te_inflation } }
		set_variable = { name = te_inflation value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_inflation_core } }
		set_variable = { name = te_inflation_core value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_inflation_expected } }
		set_variable = { name = te_inflation_expected value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_inflation_noise } }
		set_variable = { name = te_inflation_noise value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_cost_push } }
		set_variable = { name = te_cost_push value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_basket_index } }
		set_variable = { name = te_basket_index value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_basket_avg } }
		set_variable = { name = te_basket_avg value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_basket_seeded } }
		set_variable = { name = te_basket_seeded value = 0 }
	}
	if = {
		limit = {
			NOT = { has_variable = te_basket_market_owner }
			exists = market.owner
		}
		market = { owner = { save_scope_as = te_mon_init_market_owner } }
		set_variable = { name = te_basket_market_owner value = scope:te_mon_init_market_owner }
	}
	if = {
		limit = { NOT = { has_variable = te_inflation_band } }
		set_variable = { name = te_inflation_band value = 2 }
	}
	if = {
		limit = { NOT = { has_variable = te_inflation_band_applied } }
		set_variable = { name = te_inflation_band_applied value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_monetisation_level } }
		set_variable = { name = te_monetisation_level value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_monetisation_minting_applied } }
		set_variable = { name = te_monetisation_minting_applied value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_dollarised } }
		set_variable = { name = te_mon_dollarised value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_market_yield } }
		set_variable = { name = te_market_yield value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_deficit_pct } }
		set_variable = { name = te_mon_deficit_pct value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_stance_months } }
		set_variable = { name = te_mon_stance_months value = 0 }
	}
	# 0 means "neither §13 politics modifier is on the country", which is what a
	# fresh country and a save from before this step both are.
	if = {
		limit = { NOT = { has_variable = te_mon_stance_politics_applied } }
		set_variable = { name = te_mon_stance_politics_applied value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_wage_dividend_applied } }
		set_variable = { name = te_mon_wage_dividend_applied value = 0 }
	}
	# 0 means "the hyperinflation crisis may be offered". Step 6c sets it to
	# te_mon_hyper_cooldown_months when the event goes out and ticks it down a
	# month at a time; seeding it to 0 means a country that hyperinflates on its
	# very first pulse is offered the choice at once.
	if = {
		limit = { NOT = { has_variable = te_mon_hyper_cooldown } }
		set_variable = { name = te_mon_hyper_cooldown value = 0 }
	}

	# --- phase 3: gold and the peg (§12) ------------------------------------
	# Zeroes again, and again they are what an earlier save looks like: no flow,
	# no borrowed gold, nothing suspended, nobody defending. Confidence is the
	# exception — a peg nobody has tested is a peg nobody doubts, so it seeds
	# full rather than empty, or every gold country would open in a crisis.
	if = {
		limit = { NOT = { has_variable = te_gold_flow_gap } }
		set_variable = { name = te_gold_flow_gap value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_gold_flow } }
		set_variable = { name = te_gold_flow value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_gold_flow_pct } }
		set_variable = { name = te_gold_flow_pct value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_gold_hot_money } }
		set_variable = { name = te_gold_hot_money value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_gold_carry } }
		set_variable = { name = te_gold_carry value = 0 }
	}
	# Owned by the GLOBAL world-rate refresh, which writes them for the members
	# of the average only; seeded here so every country has a readable zero.
	if = {
		limit = { NOT = { has_variable = te_mon_world_own_den } }
		set_variable = { name = te_mon_world_own_num value = 0 }
		set_variable = { name = te_mon_world_own_den value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_peg_confidence } }
		set_variable = { name = te_peg_confidence value = te_mon_peg_confidence_start }
	}
	if = {
		limit = { NOT = { has_variable = te_peg_crisis_cooldown } }
		set_variable = { name = te_peg_crisis_cooldown value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_peg_defend_months } }
		set_variable = { name = te_peg_defend_months value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_peg_suspended_months } }
		set_variable = { name = te_peg_suspended_months value = 0 }
	}
}

# ----------------------------------------------------------------------------
# STEP 1b — monetising the deficit (§11)
# ----------------------------------------------------------------------------
# Scope: country.
#
# Three things in one place, in this order:
#
#   1. eligibility — a country that may no longer monetise is forced to 0;
#   2. the AI's rule, for AI countries only;
#   3. the GDP-scaled minting modifier, re-applied to match the level.
#
# WHY IT RUNS THIS EARLY. te_monetisation_level is an INPUT to three later
# steps of the same pulse: the cyclical premium charges +0.5pp a level (step 5,
# §7.6), the pressure sum adds +2.5pp a level (step 6, §9.1), and the deficit
# term adds the printed money back into the deficit, because no trigger reads
# minting and money-financed spending would otherwise suppress its own deficit
# term (step 6, ruling P4). Settling the level here means all three see this
# month's number instead of last month's, and the deficit read-out the console
# prints is the one the pressure used.
#
# THE PLAYER'S LEVEL IS NOT TOUCHED except by rule 1. The steppers at the foot
# of this file write it and the next pulse picks it up, exactly like the rate
# target — which is also why this step is the only writer that runs inside the
# update, and why no other step may write the level.
#
# ELIGIBILITY IS RE-ASKED EVERY MONTH, not only on a law change. §14 has
# te_banking_law_change_cleanup zero the level the moment a disqualifying law
# lands, so the player never keeps a level they cannot hold; this is the net
# under it, and it covers every route the on-action cannot see — a save from
# before phase 2, a law set directly by script, dollarisation (ruling P9),
# which is a variable rather than a law.
#
# THE AI RULE (§11 leaves it to the implementer; §6 only says the AI is always
# delegated). At war and already deep in debt, a treasury reaches for the
# printing press; in default or weeks from it, it reaches harder:
#
#   level 1   at war AND scaled_debt >= 0.5
#   level 2   the same, AND in default or inside 20 weeks of insolvency
#   otherwise one step back toward 0 a month
#
# The war-and-debt test is deliberately the SAME pair step 2 switches the AI's
# mandate to growth on, so an AI that has decided this is an emergency treats
# it as one on both dials. Escalation is immediate and retrenchment is one step
# a month, because a war finances itself the week it starts and a government
# that has been printing does not stop in one: it is also what keeps a country
# that dips in and out of `is_at_war` for a month from slamming 2 -> 0 -> 2.
#
# weeks_until_bankruptcy IS READ BEHIND taking_loans, the way vanilla's own
# war_support_from_looming_bankruptcy reads it (war_support_values.txt): the
# figure counts weeks of the CURRENT deficit before the credit limit, which
# means nothing for a country running a surplus.
#
# NO GATE THE PLAYER BRANCH LACKS (scripting_best_practices.md, the orphan-gate
# trap): both branches pass through the same te_mon_can_monetise test above,
# and the AI's own weights are a choice, not a permission.
#
# THE MODIFIER, and why it is not shaped exactly like step 9. Step 9 keeps a
# te_rate_paid_rooted marker so a wrongly-rooted write can be repaired, because
# a multiplier that silently fell back to 1 still looks like a plausible 1%
# interest rate. Here a fallback to 1 is one pound of minting a week, invisible
# on every surface, and step 9's own skip-if-unchanged logic would then never
# correct it. So instead of repairing a bad write this step makes one
# impossible: the re-add happens only when `root ?= this`, and a call with the
# wrong ROOT leaves both the modifier and te_monetisation_minting_applied
# exactly as they were for the next pulse to handle.
#
# THE SKIP THRESHOLD IS NOT THE POINT AT LEVEL > 0. gdp moves every month, so a
# monetising country re-applies almost every pulse — that IS the GDP-scaled
# refresh §11 asks for, and the £1-a-week threshold only stops a rewrite that
# would change nothing. What the skip is really for is the other 1,300 tags:
# the level-0 branch is a variable read and a has_modifier test, and never
# touches a modifier at all.
te_monetary_update_monetisation = {
	# --- 1/2. who monetises, and how much -----------------------------------
	if = {
		limit = { te_mon_can_monetise = no }
		set_variable = { name = te_monetisation_level value = 0 }
	}
	else_if = {
		limit = { is_player = no }
		if = {
			limit = {
				is_at_war = yes
				# The same test step 2 switches the AI mandate to growth on.
				scaled_debt >= 0.5
			}
			if = {
				limit = {
					OR = {
						in_default = yes
						AND = {
							taking_loans = yes
							weeks_until_bankruptcy < te_mon_monetisation_bankruptcy_weeks
						}
					}
				}
				set_variable = { name = te_monetisation_level value = 2 }
			}
			else = {
				set_variable = { name = te_monetisation_level value = 1 }
			}
		}
		else_if = {
			limit = { var:te_monetisation_level > 0 }
			change_variable = { name = te_monetisation_level subtract = 1 }
		}
		clamp_variable = {
			name = te_monetisation_level
			min = 0
			max = te_mon_monetisation_max
		}
	}

	# --- 3. the GDP-scaled minting modifier ---------------------------------
	if = {
		limit = { var:te_monetisation_level = 0 }
		if = {
			limit = { has_modifier = te_monetisation_minting }
			remove_modifier = te_monetisation_minting
		}
		# The applied value follows the modifier off. It is never REMOVED —
		# it backs a live multiplier and a missing variable would make every
		# later re-evaluation read 'none' (modifier_multiplier_var_audit).
		set_variable = { name = te_monetisation_minting_applied value = 0 }
	}
	else_if = {
		limit = { root ?= this }
		set_variable = { name = te_mon_work value = te_mon_monetisation_minting_value }
		set_variable = { name = te_mon_work2 value = var:te_mon_work }
		change_variable = { name = te_mon_work2 subtract = var:te_monetisation_minting_applied }
		if = {
			limit = {
				OR = {
					var:te_mon_work2 >= 1
					var:te_mon_work2 <= -1
					NOT = { has_modifier = te_monetisation_minting }
				}
			}
			if = {
				limit = { has_modifier = te_monetisation_minting }
				remove_modifier = te_monetisation_minting
			}
			set_variable = { name = te_monetisation_minting_applied value = var:te_mon_work }
			add_modifier = {
				name = te_monetisation_minting
				multiplier = var:te_monetisation_minting_applied
			}
		}
	}
}


# ----------------------------------------------------------------------------
# STEP 2 — the target
# ----------------------------------------------------------------------------
# Scope: country, dial countries only.
#
# The target follows the mandate formula when the country is delegated, is run
# by the AI, holds central bank independence, or has a national bank but no
# dashboard (§6). Otherwise it is whatever the player's stepper left in
# te_policy_rate_target and this step only re-clamps it to the regime's range.
#
# AI MANDATE RULE (§6): gold standard -> peg defence; at war or scaled_debt >=
# 0.5 -> growth; otherwise price stability. This is a documented exception to
# mod_systems.md's "do not move AI logic out of the buttons" — the mandate is a
# shared player/AI mechanic, every discrete banking button keeps its ai_chance,
# and no ai_chance is bypassed. Precedent: je_covert_warfare.txt:125-202.
# The AI branch deliberately carries NO gate the player branch lacks
# (scripting_best_practices.md:2953, the orphan-gate trap).
#
# te_mon_delegated is written to 1 only for AI countries, where it is simply
# true (§6: "AI countries are always delegated"). It is NOT written for a CBI or
# dashboard-less player: that variable is the player's own toggle — §14 clears
# it on entering a command economy — and flipping it here would leave a player
# silently delegated after repealing independence.
#
# THE MANDATE FORMULAS (§6), with pi = te_inflation_core — a delegated bank
# looks THROUGH a supply shock and steers on the persistent half (§9.1):
#
#   price stability   r^* + pi + 1.0 x (pi - anchor) + cycle_lean
#   growth            r^* + pi - 1.0 + 0.5 x max(0, pi - 4) + cycle_lean / 2
#   peg defence       the world reference rate (gold only; ignores pi and the cycle)
#
# The second pi term is what makes price stability move MORE than one for one
# with inflation — the Taylor principle, and the reason a delegated bank can
# disinflate where a fixed manual target cannot (§9.1). Growth's zero-gap point
# is pi = 6, so below 4% it simply does not see inflation.
#
# GROWTH IS NEVER MORE HAWKISH THAN PRICE STABILITY. The two formulas cross at
# low inflation under a negative cycle lean: at pi = 0 in a panic (lean -3),
# growth asks for r^* - 2.5 and price stability for r^* - 5, so the "looser"
# mandate would be the tighter one. Both are computed and the LOWER is taken.
#
# Each constant is a named script value (§21): te_mon_mandate_inflation_weight,
# te_mon_mandate_growth_bias, te_mon_mandate_growth_reaction and
# te_mon_mandate_growth_threshold, with the two reaction terms assembled in
# te_mon_mandate_price_reaction / te_mon_mandate_growth_reaction_term because
# both need a max() or a subtraction against the anchor that change_variable
# cannot express. The anchor is te_mon_inflation_anchor rather than a literal
# 2: §9.1 calls it "the mandate target" and gives it as 0 under a metallic
# regime, and a gold bank on price stability would otherwise target r^* - 2
# against its own pinned zero inflation — permanently loose at the bottom of
# its band.
#
# The neutral rate this reads is last month's (step 8 recomputes it later in the
# same pulse), and so is the core inflation (step 6 runs after this one, ruling
# P5). Both lags are the §16.2 order and both are harmless: r* moves by at most
# 0.1pp a month and core by a tenth of its own gap, while the hysteresis below
# only lets the target move in whole points at a 0.75pp margin anyway.
te_monetary_update_target = {
	# --- which mandate? ---
	if = {
		limit = { is_player = no }
		set_variable = { name = te_mon_delegated value = 1 }
		if = {
			# te_mon_is_on_gold, not the law: an AI that suspended convertibility
			# (§12.3) has a free dial for five years and runs it on an ordinary
			# mandate, then goes back to defending the peg when the suspension
			# ends.
			limit = { te_mon_is_on_gold = yes }
			set_variable = { name = te_mon_mandate value = 3 }
		}
		else_if = {
			limit = {
				OR = {
					is_at_war = yes
					scaled_debt >= 0.5
				}
			}
			set_variable = { name = te_mon_mandate value = 2 }
		}
		else = {
			set_variable = { name = te_mon_mandate value = 1 }
		}
	}
	else_if = {
		# A national-bank country without the journal entry has no dashboard to
		# pick a mandate on, so it runs price stability (§6).
		limit = { NOT = { has_journal_entry = je_banking_cycle } }
		set_variable = { name = te_mon_mandate value = 1 }
	}

	# Peg defence is a gold-standard mandate only (§6). A country that leaves
	# gold — or suspends convertibility, which leaves no peg to defend (§12.3) —
	# falls back to price stability rather than keeping a mandate whose formula
	# no longer means anything.
	if = {
		limit = {
			var:te_mon_mandate = 3
			te_mon_is_on_gold = no
		}
		set_variable = { name = te_mon_mandate value = 1 }
	}

	# --- the mandate formula ---
	if = {
		limit = {
			OR = {
				var:te_mon_delegated = 1
				is_player = no
				te_mon_is_cbi = yes
				NOT = { has_journal_entry = je_banking_cycle }
			}
		}
		if = {
			# 3 peg defence (§6): world rate + 0.5 x reserve shortfall, so gold
			# flows net to zero — or run inwards while the vault is empty.
			# Ignores the domestic cycle — and inflation — by design. The world
			# rate is the phase-3 REAL one (§12.1), which a gold country can
			# target directly because its own expected inflation is pinned at 0.
			#
			# ROUNDED UP TO A TENTH, WITH ITS OWN HYSTERESIS (ruling Q5, revised
			# after the first playtest). The shared rule below rounds to the
			# nearest whole point and tolerates a 0.75pp miss, which for every
			# other mandate is noise — but a peg defender parked 0.75pp UNDER
			# the world rate bleeds gold every month by construction. So this
			# mandate moves its target whenever the target is below the
			# formula, takes the next TENTH up (the 0.005 keeps a formula of
			# 3.00001 from costing a step), and comes down only once it is
			# more than 0.35 too high. It was a whole point at first: Britain
			# in 1836, with a vault a quarter full, asked for 3.46 and got 4 —
			# a standing point of gap, borrowing gold it then paid the carry
			# on. The dial has tenths now (the fine step), so the bank uses
			# them. Then it skips the shared rule by handing it the target it
			# has just settled.
			limit = { var:te_mon_mandate = 3 }
			set_variable = { name = te_mon_work value = te_mon_peg_defence_target }
			set_variable = { name = te_mon_work2 value = var:te_policy_rate_target }
			change_variable = { name = te_mon_work2 subtract = var:te_mon_work }
			if = {
				limit = {
					OR = {
						var:te_mon_work2 < -0.005
						var:te_mon_work2 > 0.35
					}
				}
				set_variable = {
					name = te_policy_rate_target
					value = {
						value = var:te_mon_work
						subtract = 0.005
						multiply = 10
						ceiling = yes
						divide = 10
					}
				}
			}
			set_variable = { name = te_mon_work value = var:te_policy_rate_target }
		}
		else = {
			# 1 price stability: r^* + pi + 1.0 x (pi - anchor) + cycle_lean.
			# Computed for the growth mandate as well, as the cap below.
			set_variable = { name = te_mon_work value = var:te_neutral_rate }
			change_variable = { name = te_mon_work add = var:te_neutral_error }
			change_variable = { name = te_mon_work add = var:te_inflation_core }
			change_variable = { name = te_mon_work add = te_mon_mandate_price_reaction }
			change_variable = { name = te_mon_work add = te_mon_cycle_lean }

			if = {
				# 2 growth: r^* + pi - 1.0 + 0.5 x max(0, pi - 4) + lean / 2.
				# Runs a standing point loose, which is the point — more
				# momentum, faster bubbles, more crashes.
				#
				# The lean is halved FIRST because change_variable's divide
				# applies to the whole running total; everything after it is an
				# add, so the written order is the arithmetic.
				limit = { var:te_mon_mandate = 2 }
				set_variable = { name = te_mon_work2 value = te_mon_cycle_lean }
				change_variable = { name = te_mon_work2 divide = 2 }
				change_variable = { name = te_mon_work2 add = var:te_neutral_rate }
				change_variable = { name = te_mon_work2 add = var:te_neutral_error }
				change_variable = { name = te_mon_work2 add = var:te_inflation_core }
				change_variable = { name = te_mon_work2 add = te_mon_mandate_growth_bias }
				change_variable = { name = te_mon_work2 add = te_mon_mandate_growth_reaction_term }

				# Never more hawkish than price stability (§6): the two formulas
				# cross at low inflation under a negative lean, so growth takes
				# whichever of the two is lower.
				if = {
					limit = { var:te_mon_work2 < var:te_mon_work }
					set_variable = { name = te_mon_work value = var:te_mon_work2 }
				}
			}
		}

		# Hysteresis (§4): the delegated target only moves when the formula is
		# at least 0.75pp away from the target it already holds, so a bank does
		# not flap one pp up and down with the cycle's monthly noise.
		set_variable = { name = te_mon_work2 value = var:te_mon_work }
		change_variable = { name = te_mon_work2 subtract = var:te_policy_rate_target }
		if = {
			limit = {
				OR = {
					var:te_mon_work2 >= 0.75
					var:te_mon_work2 <= -0.75
				}
			}
			set_variable = {
				name = te_policy_rate_target
				value = {
					value = var:te_mon_work
					round = yes
				}
			}
		}
	}

	# Clamp in both branches: the regime may have changed under a target that
	# was legal last month.
	te_monetary_clamp_target = yes
}


# ----------------------------------------------------------------------------
# STEP 2b — clamp the target to the regime's range (§5.1)
# ----------------------------------------------------------------------------
# Scope: country, dial countries only.
#
#   gold standard        0-15, and in phase 1 also the reference rate +/-2
#                        (the §19 row-1 interim rule standing in for §12 gold
#                        flows). The interim band is the binding one.
#   fiat currency        0-25
#   digital currency     -3 to 25 (no cash to hoard, so negative rates bite)
#
# The gold band is taken inwards to whole numbers — ceiling on the low side,
# floor on the high side — so the target stays an integer the stepper can move
# without ever sitting outside the band.
#
# The band itself lives in te_mon_target_min / te_mon_target_max
# (common/script_values/te_monetary_script_values.txt), not here, because the
# dashboard's stepper has to grey out at exactly these edges: a second copy of
# the table is how a stepper ends up offering a step this effect silently undoes
# on the next pulse. Fiat is the values' fall-through case and the only dial
# regime left once gold and digital are handled (te_mon_has_dial gates this).
te_monetary_clamp_target = {
	set_variable = { name = te_mon_work value = te_mon_target_min }
	set_variable = { name = te_mon_work2 value = te_mon_target_max }
	if = {
		limit = { var:te_policy_rate_target < var:te_mon_work }
		set_variable = { name = te_policy_rate_target value = var:te_mon_work }
	}
	if = {
		limit = { var:te_policy_rate_target > var:te_mon_work2 }
		set_variable = { name = te_policy_rate_target value = var:te_mon_work2 }
	}
}


# ----------------------------------------------------------------------------
# STEP 3 — drift
# ----------------------------------------------------------------------------
# Scope: country, dial countries only.
#
# 1/3 pp a month, i.e. 1pp a quarter. A 5pp swing therefore takes 15 months —
# reversals are slow by construction (§4). The arithmetic is §16.2's: difference
# into a scratch variable, step if it is bigger than one step, otherwise snap to
# the target so the rate never oscillates around it by a third of a point
# forever.
#
# THE SPEED IS DECLARATIVE. There is no law check here any more: the step comes
# from te_mon_drift_step, which is the baseline third of a point scaled by
# country_policy_rate_drift_speed_mult. law_digital_currency carries +1.0, so a
# digital regime still moves at 2/3 a month — but the rule now reads off that
# law's own tooltip ("Policy Rate Adjustment Speed +100%") instead of out of a
# sentence of localization, and a future law or principle can move it without
# editing this effect.
#
# THE TEST IS AGAINST te_mon_drift_step_THRESHOLD, NOT THE STEP. The old code's
# 0.34 against a 0.3333 step was not sloppiness: closing a 1.0pp gap in thirds
# leaves 0.3334, which is larger than the step, so testing against the step
# itself buys a fourth month that moves the rate 0.3333 to land 0.0001 short. The
# threshold's 0.0067 epsilon reproduces the old 0.34 exactly, and a 1pp move is
# three months at the baseline as it always was. te_mon_work2 carries the step
# (not the threshold) because it is what actually gets added.
te_monetary_drift_policy_rate = {
	set_variable = { name = te_mon_work value = var:te_policy_rate_target }
	change_variable = { name = te_mon_work subtract = var:te_policy_rate }
	set_variable = { name = te_mon_work2 value = te_mon_drift_step }
	if = {
		limit = { var:te_mon_work > te_mon_drift_step_threshold }
		change_variable = { name = te_policy_rate add = var:te_mon_work2 }
	}
	else_if = {
		limit = { var:te_mon_work < te_mon_drift_step_threshold_neg }
		change_variable = { name = te_policy_rate subtract = var:te_mon_work2 }
	}
	else = {
		set_variable = { name = te_policy_rate value = var:te_policy_rate_target }
	}
}


# ----------------------------------------------------------------------------
# STEP 4 — the derived rate, for countries with no dial
# ----------------------------------------------------------------------------
# Scope: country, no-dial countries only.
#
# No national bank, commodity money or crypto: the country pays the reference
# rate, PLUS ITS OWN EXPECTED INFLATION, plus the 1pp bankless spread (§4).
# Command economy: the administered rate, a flat 3% (§5.3). Premium still
# applies to both.
#
# WHY EXPECTED INFLATION IS IN A DERIVED RATE. The reference rate is real (§4);
# a market rate is nominal. Lenders in a bankless country price the inflation
# they expect of it exactly as lenders anywhere else do — which is why ruling
# P6 has these countries run the inflation loop at all despite having no dial
# and no stance. Without the term they would be the one group in the game whose
# nominal rate ignores its own inflation, and step 7 would then subtract a
# realised inflation the rate never contained.
#
# A COMMAND ECONOMY DOES NOT GET THE TERM. §14 holds its inflation, core and
# expectations at 0, so adding it would be adding zero; the administered rate
# is a plan figure, not a price, and it stays the flat 3%.
#
# It is LAST MONTH'S expected inflation: step 6 runs after this one (ruling
# P5). Expectations move by at most alpha x the gap in a month, so the lag is
# well under a tenth of a point.
#
# te_policy_rate_target is deliberately NOT written here. It is the dial's
# setting, and these countries have no dial; leaving it alone means a country
# that enacts a national bank resumes from the target it last held rather than
# from a number it never chose.
te_monetary_set_derived_rate = {
	if = {
		limit = { te_mon_is_command = yes }
		set_variable = { name = te_policy_rate value = 3.0 }
	}
	else = {
		# The WORLD rate since phase 3 (§4, §12.1), no longer the reference
		# rate: a small country is pulled around by the hegemon's central bank.
		# Step 7's lenders' floor still stands on the reference rate, so a
		# world rate under it cannot make a bankless country's debt cheap.
		set_variable = { name = te_policy_rate value = var:te_mon_world_rate_now }
		change_variable = { name = te_policy_rate add = var:te_inflation_expected }
		change_variable = { name = te_policy_rate add = 1.0 }
		# The world rate can be negative (te_mon_world_rate_min); a derived
		# rate cannot. Nothing downstream would break — step 7 floors the rate
		# paid — but the dashboard prints this figure.
		if = {
			limit = { var:te_policy_rate < 0 }
			set_variable = { name = te_policy_rate value = 0 }
		}
	}
}


# ----------------------------------------------------------------------------
# STEP 5 — the risk premium, in two tiers (§7)
# ----------------------------------------------------------------------------
# Scope: country.
#
# STRUCTURAL (credit standing) is what the country *is* — access, rank, techs,
# institutions, laissez-faire, gold and CBI credibility — and it is FLOORED at
# 0.5pp (0.25pp under central bank independence). Standing earned past the floor
# buys nothing: credibility has a lower bound.
#
# CYCLICAL (risk premium) is what is *happening* — cycle phases, tools, crash
# interventions, event outcomes, bankruptcy, debt load — and it is added AFTER
# the floor, so a crisis always bites even for a country sitting well under it.
#
# The two `modifier:` reads are country-scope sums that include JE-scope tool
# modifiers, the same path banking_cycle_advance_variables already uses for
# country_finance_momentum_monthly_add. In phase-1 task 2 they are both still
# zero everywhere — task 3 converts the existing interest sources onto them.
#
# The clamps are the §16.2 contract ranges (structural floor..30, cyclical
# -10..40); the §4 clamp on the rate paid is the final backstop.
te_monetary_update_premium = {
	# --- structural ---
	set_variable = { name = te_premium_structural value = 0 }
	change_variable = { name = te_premium_structural add = "modifier:country_credit_standing_add" }
	change_variable = { name = te_premium_structural multiply = 100 }
	change_variable = { name = te_premium_structural add = te_mon_access_premium }
	# State-owned banking's +0.5pp (§5.2, ruling R2 ships the premium part only)
	# is no longer added here. It rides on law_state_owned_banking as
	# country_credit_standing_add = 0.005, so it arrives through the
	# `modifier:` read above, shows on that law's own tooltip, and appears in the
	# dashboard's Credit Standing breakdown without anything restating it.
	#
	# The floor, likewise, is te_mon_standing_floor: 0.5pp moved by
	# country_credit_standing_floor_add, which law_central_bank_independence
	# carries at -0.0025. That replaces the te_mon_is_cbi branch that used to
	# hard-code 0.25 here.
	if = {
		limit = { var:te_premium_structural < te_mon_standing_floor }
		set_variable = { name = te_premium_structural value = te_mon_standing_floor }
	}
	if = {
		limit = { var:te_premium_structural > 30 }
		set_variable = { name = te_premium_structural value = 30 }
	}

	# --- cyclical ---
	set_variable = { name = te_premium_cyclical value = 0 }
	change_variable = { name = te_premium_cyclical add = "modifier:country_risk_premium_add" }
	change_variable = { name = te_premium_cyclical multiply = 100 }
	# Debt load (§7.6): nothing below scaled_debt 0.25, +4pp at 1.0. Cyclical,
	# so it is added after the floor and always bites.
	change_variable = { name = te_premium_cyclical add = te_mon_scaled_debt_premium }
	# Unanchored expectations (§7.6): +0.25pp per pp that |expected - anchor|
	# exceeds the 3pp tolerance. It is one of the three reasons §10's
	# never-disinflate path stays dearer than the pre-war baseline — already
	# +3.75pp at expected = 20 — and it is what makes a disinflation's hangover
	# cost something while expectations are still coming down.
	#
	# Monetisation (§7.6, §11): +0.5pp per level. Lenders price a government
	# that is printing money to pay them.
	#
	# BOTH READ LAST MONTH'S EXPECTATIONS, because step 6 runs after this one
	# (ruling P5). Step 7's market yield, which runs after step 6, uses this
	# month's — the two are at most alpha x the gap apart, i.e. a few hundredths
	# of a point, and pricing the premium off the figure lenders were quoted
	# last month is if anything the more honest of the two.
	change_variable = { name = te_premium_cyclical add = te_mon_premium_unanchored }
	change_variable = { name = te_premium_cyclical add = te_mon_premium_monetisation }
	if = {
		limit = { var:te_premium_cyclical < -10 }
		set_variable = { name = te_premium_cyclical value = -10 }
	}
	if = {
		limit = { var:te_premium_cyclical > 40 }
		set_variable = { name = te_premium_cyclical value = 40 }
	}
}


# ----------------------------------------------------------------------------
# STEP 6 — inflation: the basket, core, headline, expectations (§9)
# ----------------------------------------------------------------------------
# Scope: country.
#
#   index       = SUM( weight x (price / base - 1) ) over eight goods    §9.3
#   cost_push   = clamp( 0.3 x (index - basket_avg) x 100 , +/-6 )       §9.3
#   basket_avg += (1/36) x (index - basket_avg)
#   pi_core    += 0.10 x ( expected + pressure - pi_core )               §9.1
#   pi_headline = clamp( pi_core + cost_push , -10 , 100 )
#   c_eff       = c x max( 0 , 1 - |headline - anchor| / 10 )
#   expected   += alpha x ( (1 - c_eff) x headline + c_eff x anchor - expected )
#
# EVERY DRIVER IS A LEVEL IN pp, never a per-month increment (§9.1). The whole
# of the pressure sum lives in te_mon_pressure_total and its nine named terms
# (common/script_values/te_monetary_script_values.txt); the arithmetic here is
# only the three integrations — core, the basket average and expectations —
# plus the noise walk, because a random draw cannot live in a script value.
#
# WHERE IT SITS IN THE ORDER (ruling P5). Between the premium and the rate
# paid, so §10's market yield reads THIS month's expectations. Everything
# upstream of it reads last month's — step 2's core, step 4's expected in the
# derived rate, step 5's §7.6 unanchored premium — which is a lag of at most
# alpha x the gap, a few hundredths of a point, and each site says so.
# The stance term therefore reads LAST month's
# te_mon_stance_gap, which step 8 rewrites later in the same pulse: §16.3
# already tolerates a one-month-old gap, and the alternative would define the
# gap in terms of an inflation figure computed from the gap.
#
# WHO RUNS IT (ruling P6). Everyone except a command economy — including
# bankless, commodity-money, crypto and dollarised countries, whose stance gap
# is 0 and who therefore just drop the loose-money term. §14 holds a planned
# economy's pi, core, expected and cost-push at 0 until repressed inflation is
# designed. It is NOT gated on banking_system_enabled: inflation feeds the rate
# every country pays.
#
# THE BASKET RUNS FOR EVERYONE WITH A MARKET, including a command economy. It
# is a price observation, not a policy: a planned economy that leads a customs
# union still has to feed its members an index, and its own trailing average
# has to keep moving or the month it liberalises books three decades of price
# drift as one shock.
#
# HIDDEN STATE (ruling P7). te_inflation_core, te_inflation_noise and the
# pressure sum are never printed outside events/te_debug_monetary_events.txt.
# Headline, expected, cost-push and the player's own wage / inflation pressure
# modifiers are the public half.
te_monetary_update_inflation = {
	# --- 6a. the cost-push basket (§9.3) ------------------------------------
	# Computed once per MARKET and copied by the members. A member may pulse
	# before its market owner does, so the copy can be a month old — the same
	# staleness §16.3 accepts for the stance, and a price index moves by less
	# in a month than the 1/36 average absorbs.
	if = {
		limit = { exists = market.owner }
		market = { owner = { save_scope_as = te_mon_basket_owner } }

		if = {
			limit = {
				# `scope:X ?= this` is vanilla's own arrangement for "am I
				# the one that scope points at" (00_flag_definitions.txt:10050,
				# `NOT = { scope:actor ?= this }`) and the same one step 9's
				# te_rate_paid_rooted marker uses. If it ever evaluated the
				# wrong way round for a market OWNER, that owner would copy
				# its own zero for ever and its cost-push would be silently
				# dead: the tell in te_debug_monetary.1 is "Basket index"
				# disagreeing with "Weighted index as computed".
				NOT = { scope:te_mon_basket_owner ?= this }
				scope:te_mon_basket_owner = { has_variable = te_basket_index }
			}
			set_variable = { name = te_basket_index value = te_mon_basket_index_from_owner }
		}
		else = {
			# The market owner itself, and any member whose owner has not
			# pulsed yet (the first month of a game, or of a new union).
			set_variable = { name = te_basket_index value = te_mon_basket_index_value }
		}

		# SEED, AND RE-SEED ON A CHANGE OF MARKET (§9.3). Without the seed the
		# first month reads the whole price level as a shock; without the
		# re-seed, joining a customs union books the new market's price level
		# as inflation, which is not what happened.
		if = {
			limit = {
				OR = {
					var:te_basket_seeded = 0
					NOT = { has_variable = te_basket_market_owner }
					# The has_variable is restated rather than relied on from
					# the clause above it: an OR is not guaranteed to
					# short-circuit, and an unguarded var: read of a missing
					# variable logs every month it is evaluated.
					AND = {
						has_variable = te_basket_market_owner
						NOT = { var:te_basket_market_owner = scope:te_mon_basket_owner }
					}
				}
			}
			set_variable = { name = te_basket_avg value = var:te_basket_index }
			set_variable = { name = te_basket_seeded value = 1 }
			set_variable = { name = te_basket_market_owner value = scope:te_mon_basket_owner }
			set_variable = { name = te_cost_push value = 0 }
		}
		else = {
			# cost_push first, THEN the average catches up: the month's shock
			# is measured against where the average was, not where it lands.
			set_variable = {
				name = te_cost_push
				value = {
					value = var:te_basket_index
					subtract = var:te_basket_avg
					multiply = te_mon_basket_k
					multiply = 100
					min = te_mon_cost_push_clamp_neg
					max = te_mon_cost_push_clamp
				}
			}
			set_variable = {
				name = te_mon_work
				value = {
					value = var:te_basket_index
					subtract = var:te_basket_avg
					multiply = te_mon_basket_avg_alpha
				}
			}
			change_variable = { name = te_basket_avg add = var:te_mon_work }
		}
	}
	else = {
		# No market at all: no prices to read, so no cost-push. The index and
		# the average are left where they were rather than zeroed, so a country
		# that regains a market re-seeds against the new one instead of
		# differencing against a fabricated zero.
		set_variable = { name = te_cost_push value = 0 }
	}

	# --- 6b. the inflation loop ---------------------------------------------
	if = {
		limit = { te_mon_has_inflation = no }
		# §14: a command economy's prices are administered. Everything is held
		# at zero — including cost-push, which the basket above may just have
		# written — and the band at comfort, so nothing downstream sees a
		# stale number from before the plan.
		set_variable = { name = te_inflation value = 0 }
		set_variable = { name = te_inflation_core value = 0 }
		set_variable = { name = te_inflation_expected value = 0 }
		set_variable = { name = te_cost_push value = 0 }
		set_variable = { name = te_inflation_band value = 2 }
	}
	else = {
		# --- the hidden noise walk (ruling P7) ------------------------------
		# Mean-reverting, +/-0.1 a month, bounded +/-0.75: the same machinery
		# as te_neutral_walk in step 8, and here for the same kind of reason —
		# without a random term the pressure sum is fully determined by public
		# quantities plus -0.4 x the stance gap, so two months of a displayed
		# headline would recover the gap and with it r*.
		#
		# THE DRAW IS ONLY FOR A COUNTRY WITH A DIAL, on the §0.1 precedent
		# that gated step 8's two walks: this effect runs for every country
		# every month, and ~1,330 of ~1,400 tags have no national bank. There
		# is nothing for the noise to hide in those — their stance gap is
		# forced to 0, so te_mon_pressure_stance is 0 and the sum carries no r*
		# to invert.
		#
		# THE DECAY IS OUTSIDE THE GATE, and that is where this parts company
		# with step 8. Step 8's walks are *read* only by countries with a dial,
		# so freezing them costs nothing. This one is different:
		# te_mon_pressure_noise is an UNCONDITIONAL term of
		# te_mon_pressure_total, so a country that loses its dial would carry
		# its last draw — up to +/-0.75pp — as a permanent, deterministic bias
		# on its inflation for the rest of the campaign. Decaying outside the
		# gate bleeds an undrawn walk away instead — 0.95 a month halves it
		# every thirteen months or so, and a worst-case 0.75 is under a tenth
		# of a point inside four years. That is the intended reading of "the
		# noise stops moving": it stops being random, and then it stops being
		# anything. A country that has never had a dial keeps step 0's zero
		# either way, and multiplying zero by 0.95 costs nothing.
		#
		# The clamp stays outside too, so the bound stays true whatever path
		# the value took.
		change_variable = { name = te_inflation_noise multiply = 0.95 }
		if = {
			limit = { te_mon_has_dial = yes }
			random_list = {
				1 = { change_variable = { name = te_inflation_noise add = 0.1 } }
				1 = { }
				1 = { change_variable = { name = te_inflation_noise subtract = 0.1 } }
			}
		}
		clamp_variable = {
			name = te_inflation_noise
			min = -0.75
			max = 0.75
		}

		# --- the deficit read-out (ruling P4) -------------------------------
		# Cached before the pressure terms are summed, because
		# te_mon_pressure_deficit reads the cache rather than recomputing it:
		# the number the console prints is then the number the pressure used.
		set_variable = { name = te_mon_deficit_pct value = te_mon_deficit_pct_value }

		# --- core: a ten-month adjustment toward expected + pressure --------
		set_variable = {
			name = te_mon_work
			value = {
				value = te_mon_pressure_total
				add = var:te_inflation_expected
				subtract = var:te_inflation_core
				multiply = te_mon_core_speed
			}
		}
		change_variable = { name = te_inflation_core add = var:te_mon_work }
		clamp_variable = {
			name = te_inflation_core
			min = -10
			max = 100
		}

		# --- headline = core + cost-push ------------------------------------
		set_variable = { name = te_inflation value = var:te_inflation_core }
		change_variable = { name = te_inflation add = var:te_cost_push }
		clamp_variable = {
			name = te_inflation
			min = -10
			max = 100
		}

		# --- expectations ---------------------------------------------------
		# METALLIC MONEY IS PINNED AT ZERO, not blended (§9.1's table gives it
		# no alpha at all): a promise to redeem in metal is a promise about the
		# price LEVEL, and the two explicit consequences are this pin and the
		# exemption from de-anchoring — c_eff never enters the picture, so
		# convertibility cannot lose credibility the way a target can. The
		# deflation bias that comes with it is the regime pull inside
		# te_mon_pressure_total.
		#
		# A DOLLARISED country IS PINNED TOO, AT THE ANCHOR (owner decision K,
		# 2026-09-20, closing the item ruling T5 left open). It takes the
		# metallic regime PULL because its money is somebody else's, and for
		# the same reason nothing its own government does can move what people
		# expect of that money: imported credibility is the whole of what
		# dollarising buys. Unpinned, a dollarised country running a large
		# deficit drifted its own expectations upward for a currency it does
		# not issue. The pin is te_mon_inflation_anchor (2), not metal's 0 —
		# the money it adopted is somebody's managed currency, not specie. The
		# dollarise option already resets expectations to the anchor, so the
		# pin holds a value rather than jumping to one.
		if = {
			limit = { te_mon_is_metallic = yes }
			set_variable = { name = te_inflation_expected value = 0 }
		}
		else_if = {
			limit = { te_mon_is_dollarised = yes }
			set_variable = { name = te_inflation_expected value = te_mon_inflation_anchor }
		}
		else = {
			set_variable = {
				name = te_mon_work
				value = {
					value = te_mon_expectation_target
					subtract = var:te_inflation_expected
					multiply = te_mon_expectation_alpha
				}
			}
			change_variable = { name = te_inflation_expected add = var:te_mon_work }
			clamp_variable = {
				name = te_inflation_expected
				min = -10
				max = 100
			}
		}

		# --- the displayed band (§9.2) --------------------------------------
		# From HEADLINE, not core: the bands are what the country is living
		# through. This writes the NUMBER; step 6c, immediately after, swaps the
		# te_inflation_band_* modifier off it.
		#
		# THE EDGES ARE HYSTERESISED (final-review finding I2). The ladder tests
		# te_mon_band_test_*, not te_mon_band_edge_*: each test sits
		# te_mon_band_hysteresis (0.25pp) on the far side of the edge FROM
		# WHEREVER THE COUNTRY ALREADY IS, so the live boundary is a quarter
		# point higher than the nominal edge for a country climbing towards it
		# and a quarter point lower for one falling towards it. Without it a
		# headline
		# resting on 3% — well inside te_inflation_noise's own +/-0.75pp walk —
		# would swap the country's band modifier, hand it and take back the
		# step 6d real-wage dividend, and redraw the dashboard row every second
		# or third month for no change in its economy.
		#
		# IT READS LAST MONTH'S BAND, and this chain is why that works: the
		# band is written in the BODY of whichever branch matches, and an
		# else_if evaluates its limit only after the ones above it have failed
		# without running, so every test below sees the value step 6b of the
		# previous pulse left. No new variable, and nothing to keep in step.
		#
		# THE HYPER EDGE IS NOT HYSTERESISED ON THE WAY UP: §9.2 puts the
		# crisis at 50 and te_mon_band_test_hyper keeps the entry there, moving
		# only the exit. See the block above te_mon_band_hysteresis in
		# common/script_values/te_monetary_script_values.txt.
		if = {
			limit = { var:te_inflation < te_mon_band_test_deflation }
			set_variable = { name = te_inflation_band value = 1 }
		}
		else_if = {
			limit = { var:te_inflation < te_mon_band_test_elevated }
			set_variable = { name = te_inflation_band value = 2 }
		}
		else_if = {
			limit = { var:te_inflation < te_mon_band_test_high }
			set_variable = { name = te_inflation_band value = 3 }
		}
		else_if = {
			limit = { var:te_inflation < te_mon_band_test_very_high }
			set_variable = { name = te_inflation_band value = 4 }
		}
		else_if = {
			limit = { var:te_inflation < te_mon_band_test_hyper }
			set_variable = { name = te_inflation_band value = 5 }
		}
		else = {
			set_variable = { name = te_inflation_band value = 6 }
		}
	}
}


# ----------------------------------------------------------------------------
# STEP 6c — the band modifier and the hyperinflation crisis (§9.2)
# ----------------------------------------------------------------------------
# Scope: country. Runs immediately after step 6, so the modifier on the country
# always matches the band number the dashboard shows.
#
# ONE MODIFIER, SEVEN STATES. te_inflation_band_applied says which member of
# the family is on the country right now:
#
#   1-6  te_inflation_band_deflation / _comfort / _elevated / _high /
#        _very_high / _hyper — the §9.2 ladder, keyed off te_inflation_band
#   7    te_mon_dollarised_modifier — the country gave up its own money
#   0    nothing applied yet (a fresh country, or a save from before this task)
#
# DOLLARISATION REPLACES THE BAND, IT DOES NOT STACK WITH IT (ruling P9, and
# the finding parked in task 1's review). te_inflation_band_hyper carries
# country_minting_mult -0.8 and te_mon_dollarised_modifier carries -0.75, and
# dollarisation is chosen from INSIDE the hyperinflation band — so any design
# that can hold both at once puts that field at -1.55 and turns the mint into a
# drain on the budget. Making 7 a value of the SAME bookkeeping variable makes
# that state unreachable rather than merely brief: this effect issues exactly
# one add_modifier a month, and the swap that adds the dollarised modifier is
# the same one that takes the band off.
#
# It is also the right answer in fiction, and the one te_mon_dollarised_modifier's
# own loc already gives: with prices, wages and contracts written in foreign
# money, "inflation is somebody else's problem". The §9.2 ladder prices what it
# costs to hold a currency that is losing its value, and a dollarised country
# does not hold one. What it pays instead is three quarters of its seigniorage,
# for ever — §9.2's "defining cost of dollarisation".
#
# THE PLAYER'S CHOICE IS AN INPUT, NOT A MODIFIER. te_inflation.1's dollarise
# option writes te_mon_dollarised and the inflation reset, and nothing else;
# this step is what puts the modifier on, at most a month later. That is the
# same "write the input and let the pulse pick it up" rule every other control
# in this system follows, and it is what lets one owner keep the family
# exclusive. The option says so in its tooltip, because nothing mechanical
# renders in an option that only sets variables.
#
# DECIDED FROM VARIABLES, NEVER FROM has_modifier — add_modifier and
# remove_modifier results are not visible inside the effect block that issues
# them (scripting_best_practices.md), so a has_modifier read here would be
# asking about state this effect is in the middle of changing. Same rule, and
# the same reason, as banking_cycle_apply_stance_band.
#
# COMFORT IS APPLIED THOUGH IT IS EMPTY, on the banking_stance_band_3 precedent
# and vanilla's own tax_modifier_medium / infamy_reputable: the swap then always
# has exactly one thing to apply, and the modifier list always NAMES the band
# the country is in. Its loc is written for that job — it says the band costs
# nothing and that it is the one band in which the real-wage dividend pays.
#
# NO FIRST-RUN SWEEP. banking_cycle_apply_stance_band removes all five of its
# bands once, because its modifiers live on a can_revolution_inherit journal
# entry and move to a successor tag while the variables do not. These are
# COUNTRY modifiers on the country itself, and a country that has never run this
# step carries the 0 from step 0 and no band modifier — the two agree.
te_monetary_apply_inflation_band = {
	# The crisis cooldown ages first, so the month it reaches 0 is a month the
	# crisis can be offered again rather than the month after.
	if = {
		limit = { var:te_mon_hyper_cooldown > 0 }
		change_variable = { name = te_mon_hyper_cooldown subtract = 1 }
	}

	# What belongs on the country this month: the band, unless it is dollarised,
	# in which case the dollarised modifier and no band.
	if = {
		limit = { var:te_mon_dollarised = 1 }
		set_variable = { name = te_mon_work value = 7 }
	}
	else = {
		set_variable = { name = te_mon_work value = var:te_inflation_band }
	}

	if = {
		limit = { NOT = { var:te_inflation_band_applied = var:te_mon_work } }

		# Take off what we put on last month.
		if = { limit = { var:te_inflation_band_applied = 1 } remove_modifier = te_inflation_band_deflation }
		else_if = { limit = { var:te_inflation_band_applied = 2 } remove_modifier = te_inflation_band_comfort }
		else_if = { limit = { var:te_inflation_band_applied = 3 } remove_modifier = te_inflation_band_elevated }
		else_if = { limit = { var:te_inflation_band_applied = 4 } remove_modifier = te_inflation_band_high }
		else_if = { limit = { var:te_inflation_band_applied = 5 } remove_modifier = te_inflation_band_very_high }
		else_if = { limit = { var:te_inflation_band_applied = 6 } remove_modifier = te_inflation_band_hyper }
		else_if = { limit = { var:te_inflation_band_applied = 7 } remove_modifier = te_mon_dollarised_modifier }

		# Put on this month's.
		if = { limit = { var:te_mon_work = 1 } add_modifier = { name = te_inflation_band_deflation } }
		else_if = { limit = { var:te_mon_work = 2 } add_modifier = { name = te_inflation_band_comfort } }
		else_if = { limit = { var:te_mon_work = 3 } add_modifier = { name = te_inflation_band_elevated } }
		else_if = { limit = { var:te_mon_work = 4 } add_modifier = { name = te_inflation_band_high } }
		else_if = { limit = { var:te_mon_work = 5 } add_modifier = { name = te_inflation_band_very_high } }
		else_if = { limit = { var:te_mon_work = 6 } add_modifier = { name = te_inflation_band_hyper } }
		else_if = { limit = { var:te_mon_work = 7 } add_modifier = { name = te_mon_dollarised_modifier } }

		set_variable = { name = te_inflation_band_applied value = var:te_mon_work }
	}

	# --- the hyperinflation crisis (§9.2) -----------------------------------
	# The band, not a fresh headline read, is the gate. Band 6 is ENTERED at
	# exactly pi >= te_mon_band_edge_hyper — finding I2's hysteresis deliberately
	# leaves that edge plain on the way up — and left again only at 49.75, which
	# is the difference between the two tests and is the intended one: a country
	# riding the crisis out on the boundary should not be re-offered the choice
	# by a tenth of a point of noise. The band is also where §14 already holds a
	# command economy at comfort, so a planned economy is excluded here without
	# anything restating why.
	#
	# A DOLLARISED COUNTRY IS NOT OFFERED IT. Its modelled inflation can still
	# read above the threshold for a month or two after the switch — the loop
	# keeps running because §10's lenders price its expectations — but it has no
	# currency of its own left to reform or abandon, and the choice it is being
	# offered is the one it already made.
	#
	# THE COOLDOWN IS SET HERE, not in the event, so that a player who leaves
	# the event unanswered is not handed a second copy of it at the next pulse.
	# The two options that RESOLVE the crisis clear it again themselves: it is
	# an anti-nag device for riding it out, not a lock-out, and a country that
	# reformed its currency and then hyperinflated the new one all over again
	# has to be offered the choice a second time. So this effect owns the
	# countdown — setting it and ageing it — and te_inflation.1's reform and
	# dollarise options own the one write that zeroes it.
	if = {
		limit = {
			var:te_inflation_band = 6
			var:te_mon_dollarised = 0
			var:te_mon_hyper_cooldown = 0
		}
		set_variable = { name = te_mon_hyper_cooldown value = te_mon_hyper_cooldown_months }
		trigger_event = { id = te_inflation.1 }
	}
}


# ----------------------------------------------------------------------------
# STEP 6d — the real-wage dividend (§9.4)
# ----------------------------------------------------------------------------
# Scope: country. Runs immediately after 6c, off the band number step 6 wrote.
#
# WHAT IT IS. Wage pressure would otherwise be a pure tax on progressive labour
# law: the law raises inflation, the player tightens to answer it, and growth
# pays for both. §9.4's compensation is the other half of wage-led demand —
# workers whose pay holds its value spend it — and it is deliberately
# CONDITIONAL on price stability. Inside the comfort band the same laws take
# part of the lower-strata expectations headwind they themselves carry back off
# again, and pay financial momentum; outside it they pay nothing, because wages
# rising into rising prices buy nothing. That is
# what makes credible monetary management the precondition for strong labour
# laws rather than their enemy (§9.4's arithmetic: under a CBI's c = 0.7
# factory councils cost +0.7pp and stay inside the band, so the dividend is
# pure gain; on a manual c = 0.25 target they cost +2pp and the player has to
# hold a tighter stance to keep it).
#
# WHO IS EXCLUDED, and why the band alone is not the test:
#
#   * A COMMAND ECONOMY has no inflation of its own (§14, ruling P6) — step 6
#     holds pi at 0 and pins te_inflation_band at 2, so the band would read
#     comfort for a country whose prices are administered rather than stable.
#     Paying a dividend for "price stability" the plan simply decrees is
#     paying for nothing, so te_mon_has_inflation gates it out.
#   * A DOLLARISED country has no band of its own that means anything. Its
#     modelled headline keeps running because §10's lenders price its
#     expectations, and it can read comfort — but it is holding somebody
#     else's money, that country's central bank earned the stability, and step
#     6c has already replaced its band modifier with te_mon_dollarised_modifier
#     (te_inflation_band_applied = 7). It pays three quarters of its
#     seigniorage instead; it does not also collect a dividend.
#
# ONLY POSITIVE PRESSURE EARNS IT (te_mon_wage_pressure_positive). A country
# on anti-strike laws is not paid for holding wages down — it simply has no
# dividend, the same as a country with no labour law at all.
#
# THE ROOT-SAFE SCALED PATTERN, verbatim from step 1b: `multiplier = var:X`
# resolves against ROOT, not against the scope this effect runs in, so the
# re-apply is gated on `root ?= this` and the value is carried in a persistent
# variable. te_mon_wage_dividend_applied is never REMOVED — it backs a live
# multiplier and a missing variable would make every later re-evaluation read
# 'none' (modifier_multiplier_var_audit). The 0.05-unit skip threshold means an
# unchanged month costs nothing: wage pressure only moves when a law changes,
# so for almost every country this step does nothing after the first pulse.
#
# The `NOT = { has_modifier }` clause in the skip test is the self-heal: if the
# modifier is ever lost while the variable persists (a save-game migration, a
# tag change), the next pulse puts it back rather than waiting for the units to
# move.
te_monetary_apply_wage_dividend = {
	# --- what is earned this month, in units of +0.1pp ----------------------
	if = {
		limit = {
			var:te_inflation_band = 2
			te_mon_has_inflation = yes
			var:te_mon_dollarised = 0
		}
		set_variable = { name = te_mon_work value = te_mon_wage_dividend_units }
	}
	else = {
		set_variable = { name = te_mon_work value = 0 }
	}

	# --- apply, or take it off ----------------------------------------------
	if = {
		limit = { var:te_mon_work < 0.05 }
		if = {
			limit = { has_modifier = te_mon_real_wage_dividend }
			remove_modifier = te_mon_real_wage_dividend
		}
		# The applied value follows the modifier off, but the variable stays.
		set_variable = { name = te_mon_wage_dividend_applied value = 0 }
	}
	else_if = {
		limit = { root ?= this }
		set_variable = { name = te_mon_work2 value = var:te_mon_work }
		change_variable = { name = te_mon_work2 subtract = var:te_mon_wage_dividend_applied }
		if = {
			limit = {
				OR = {
					var:te_mon_work2 >= 0.05
					var:te_mon_work2 <= -0.05
					NOT = { has_modifier = te_mon_real_wage_dividend }
				}
			}
			if = {
				limit = { has_modifier = te_mon_real_wage_dividend }
				remove_modifier = te_mon_real_wage_dividend
			}
			set_variable = { name = te_mon_wage_dividend_applied value = var:te_mon_work }
			add_modifier = {
				name = te_mon_real_wage_dividend
				multiplier = var:te_mon_wage_dividend_applied
			}
		}
	}
}


# ----------------------------------------------------------------------------
# STEP 7 — the rate the government pays (§4, §10)
# ----------------------------------------------------------------------------
# Scope: country.
#
#   market_yield  = max( policy_rate , era_base + expected_inflation )
#   rate_paid_pts = clamp( market_yield + structural + cyclical
#                          - headline_inflation , 0.5 , 60 )
#
# THE LENDERS' FLOOR (§10). The policy rate is NOMINAL — it already contains
# the central bank's allowance for inflation — so expected inflation is not
# added on top of it. What lenders add is a FLOOR: they will not hold
# government paper yielding less than a normal real return over the inflation
# they expect, whatever the bank's rate is. The floor is built on era_base, the
# public long-run real rate, and NOT on the hidden neutral rate: rate paid is an
# exact dashboard number, and building it on r* would print r* (§8, §10).
#
# ALL DEBT IS REAL, so the treasury's cost is the nominal yield minus the
# inflation that actually OCCURS — headline, not expected (§9.1). Three
# consequences the design wants: tight policy costs the treasury pp for pp,
# loose policy saves it only down to the floor, and only SURPRISES erode debt —
# once expectations catch up the floor binds and the country pays
# era_base + premium in real terms again. Financial repression has a shelf life.
#
# THE 0.5 FLOOR STILL HOLDS, and it is why a negative policy rate never reaches
# the rate paid: under digital currency a target of -3 acts only through the
# stimulus channel (§8), which is intended. It is now also what stops a
# monetised war from paying the government to borrow, and it DOES bite on §10's
# war path: simulated, it binds for three months in the middle of a level-3
# monetisation (while headline is climbing faster than expectations are lifting
# the yield floor) and again for the single month the monetisation ends, when
# the +1.5pp monetisation premium comes off before headline starts falling.
# Cyclical negatives (relief tools) can pull the total under the structural
# floor the same way; this clamp is the final backstop for all of it.
te_monetary_update_rate_paid = {
	# --- the lenders' floor -------------------------------------------------
	# te_market_yield is a displayed figure with no hidden state in it: the
	# reference rate and expected inflation are both shown exactly.
	set_variable = { name = te_market_yield value = var:te_mon_era_base_now }
	change_variable = { name = te_market_yield add = var:te_inflation_expected }
	if = {
		limit = { var:te_market_yield < var:te_policy_rate }
		set_variable = { name = te_market_yield value = var:te_policy_rate }
	}

	set_variable = { name = te_rate_paid_pts value = var:te_market_yield }
	change_variable = { name = te_rate_paid_pts add = var:te_premium_structural }
	change_variable = { name = te_rate_paid_pts add = var:te_premium_cyclical }
	change_variable = { name = te_rate_paid_pts subtract = var:te_inflation }
	if = {
		limit = { var:te_rate_paid_pts < 0.5 }
		set_variable = { name = te_rate_paid_pts value = 0.5 }
	}
	if = {
		limit = { var:te_rate_paid_pts > 60 }
		set_variable = { name = te_rate_paid_pts value = 60 }
	}
}


# ----------------------------------------------------------------------------
# STEP 8 — the hidden neutral rate, the stance gap and the displayed band (§8)
# ----------------------------------------------------------------------------
# Scope: country.
#
#   real_rate    = policy_rate - headline_inflation
#   neutral_rate = clamp( era_base + growth_term + walk , 1 , 6 )
#   stance_gap   = clamp( real_rate - neutral_rate , -10 , +10 )   [0 if no dial]
#
# THE GAP IS REAL, NOT NOMINAL (§8). The neutral rate is a real rate, so the
# policy rate has to be deflated before the two can be compared; phase 1
# compared them directly only because inflation was identically zero. HEADLINE
# is the deflator, not core: §9.1 gives the real rate, the rate paid and the
# bands to headline and only the mandates to core. The consequence is the
# Taylor principle in one line — holding a nominal target while inflation rises
# eases policy, which adds pressure, which raises inflation again (§9.1). That
# loop is closed through step 6, which reads this variable a month later.
#
# HIDDEN STATE. te_neutral_rate, te_neutral_error, te_neutral_walk and
# te_mon_stance_gap are never printed in any tooltip, loc string or visible
# modifier. Nobody knows r*, and hiding it keeps judgement in the loop; the
# displayed band is the only window onto the gap. The band is computed from the
# BANK'S ESTIMATE of the gap, not the true one, so a player cannot recover r* by
# stepping the dial and watching the band flip.
#
# The estimate is r^* = te_neutral_rate + te_neutral_error (§8: "the stance band
# shown to the player, and the mandate formulas, use neutral_rate +
# estimation_error, never the true value"), so the estimated gap is
# policy - (neutral + error) = stance_gap - error. That subtraction is the same
# sign convention the mandate formulas above use for r^*.
#
# WHO FEELS THE STANCE: only countries with a dial (§8). A market rate clears at
# neutral by definition, so bankless, commodity-money, crypto and command-economy
# countries get a gap of exactly 0 and read Neutral — applying the channel to
# them would leave every law_no_national_bank country permanently tight, a hidden
# penalty nobody chose.
te_monetary_update_stance = {
	# --- the two random walks, for countries with a dial only ----------------
	# WHY THE GATE. Neither walk is read by a country without a dial: its stance
	# gap is forced to 0, its band to 3, and it never runs a mandate formula. So
	# the two draws below would be pure cost for the ~95% of tags that have no
	# national bank, and this effect runs for every country every month.
	#
	# The accepted consequence (controller ruling, fix round 1) is that a
	# no-dial country's hidden state FREEZES rather than drifting: the walk keeps
	# whatever value it last held and resumes from there — not from zero — if the
	# country later enacts a national bank. The decay is inside the gate with its
	# own draw for exactly that reason; leaving the decay outside would quietly
	# bleed the walk to zero instead of freezing it, which is a different
	# behaviour, not an optimisation. The clamps stay outside so the bounds stay
	# true even for a frozen value — and so enacting central bank independence
	# narrows an already-wide error on the very next pulse, dial or no dial.
	if = {
		limit = { te_mon_has_dial = yes }

		# The walk: mean-reverting, +/-0.1 a month. The 0.95 decay is the mean
		# reversion; with +/-0.1 steps two months in three the walk settles
		# around a standard deviation of roughly a quarter point, well inside
		# the 1-6 clamp on the neutral rate below.
		change_variable = { name = te_neutral_walk multiply = 0.95 }
		random_list = {
			1 = { change_variable = { name = te_neutral_walk add = 0.1 } }
			1 = { }
			1 = { change_variable = { name = te_neutral_walk subtract = 0.1 } }
		}

		# The bank's estimation error: a slow random walk, bounded below at
		# +/-1.5pp or +/-0.5pp under central bank independence — one of the
		# things markets and the mandate get in exchange for the commitment (§6).
		random_list = {
			1 = { change_variable = { name = te_neutral_error add = 0.1 } }
			4 = { }
			1 = { change_variable = { name = te_neutral_error subtract = 0.1 } }
		}
	}

	if = {
		limit = { var:te_neutral_walk > 1 }
		set_variable = { name = te_neutral_walk value = 1 }
	}
	if = {
		limit = { var:te_neutral_walk < -1 }
		set_variable = { name = te_neutral_walk value = -1 }
	}

	# --- the neutral rate ---------------------------------------------------
	# te_mon_growth_term is 0.25 x (trailing yearly GDP growth % - 2), clamped
	# to +/-1.5, refreshed once a year by te_monetary_yearly_growth_snapshot.
	set_variable = { name = te_neutral_rate value = var:te_mon_era_base_now }
	change_variable = { name = te_neutral_rate add = var:te_mon_growth_term }
	change_variable = { name = te_neutral_rate add = var:te_neutral_walk }
	if = {
		# Cooperative ownership runs the full system, but mutual credit puts its
		# natural rate half a point lower (§5.3). This is the spec's term, and it
		# binds over the brief's step-8 enumeration, which omitted it.
		limit = { has_law_or_variant = law_type:law_cooperative_ownership }
		change_variable = { name = te_neutral_rate subtract = 0.5 }
	}
	if = {
		limit = { var:te_neutral_rate < 1 }
		set_variable = { name = te_neutral_rate value = 1 }
	}
	if = {
		limit = { var:te_neutral_rate > 6 }
		set_variable = { name = te_neutral_rate value = 6 }
	}

	# --- the estimation error's bound ---------------------------------------
	# Re-applied every month whether or not the walk advanced, so a country that
	# enacts independence narrows an already-wide error on the next pulse.
	#
	# The bound is te_mon_forecast_error_bound: 1.5pp moved by
	# country_bank_forecast_error_add, which law_central_bank_independence
	# carries at -0.01 (-1.0pp, leaving +/-0.5). That grant replaces the
	# te_mon_is_cbi branch that used to hard-code the two pairs of literals here,
	# and it is the only one of these four rules that is readable on a law
	# tooltip *and* touches hidden state — the bound may be shown, the error
	# inside it may not (§8).
	if = {
		limit = { var:te_neutral_error > te_mon_forecast_error_bound }
		set_variable = { name = te_neutral_error value = te_mon_forecast_error_bound }
	}
	if = {
		limit = { var:te_neutral_error < te_mon_forecast_error_bound_neg }
		set_variable = { name = te_neutral_error value = te_mon_forecast_error_bound_neg }
	}

	# --- the gap and the band -----------------------------------------------
	if = {
		limit = { te_mon_has_dial = yes }
		set_variable = { name = te_mon_stance_gap value = var:te_policy_rate }
		change_variable = { name = te_mon_stance_gap subtract = var:te_inflation }
		change_variable = { name = te_mon_stance_gap subtract = var:te_neutral_rate }
		if = {
			limit = { var:te_mon_stance_gap > 10 }
			set_variable = { name = te_mon_stance_gap value = 10 }
		}
		if = {
			limit = { var:te_mon_stance_gap < -10 }
			set_variable = { name = te_mon_stance_gap value = -10 }
		}

		set_variable = { name = te_mon_work value = var:te_mon_stance_gap }
		change_variable = { name = te_mon_work subtract = var:te_neutral_error }
		if = {
			limit = { var:te_mon_work <= -2 }
			set_variable = { name = te_mon_stance_band value = 1 }
		}
		else_if = {
			limit = { var:te_mon_work <= -0.75 }
			set_variable = { name = te_mon_stance_band value = 2 }
		}
		else_if = {
			limit = { var:te_mon_work < 0.75 }
			set_variable = { name = te_mon_stance_band value = 3 }
		}
		else_if = {
			limit = { var:te_mon_work < 2 }
			set_variable = { name = te_mon_stance_band value = 4 }
		}
		else = {
			set_variable = { name = te_mon_stance_band value = 5 }
		}
	}
	else = {
		set_variable = { name = te_mon_stance_gap value = 0 }
		set_variable = { name = te_mon_stance_band value = 3 }
	}
}


# ----------------------------------------------------------------------------
# STEP 8b — creditor-versus-debtor politics (§13)
# ----------------------------------------------------------------------------
# Scope: country. Runs immediately after step 8, off the band step 8 wrote.
#
# WHAT IT IS. A rate decision has winners and losers, and §13 says they should
# eventually notice. te_mon_stance_months counts months of the same stance;
# once six of them have accumulated on one side, the country carries
# te_mon_stance_politics_tight or te_mon_stance_politics_loose (defined, with
# the §13 table and the sizing, in common/static_modifiers/extra_modifiers.txt).
# One month's tightening buys nothing: this is the politics of a POLICY, not of
# a meeting.
#
# IT COUNTS THE DISPLAYED BAND, NEVER THE GAP (ruling P8). te_mon_stance_gap is
# hidden state (§8), and §13's literal test — |gap| >= 1 — would put a modifier
# on the country exactly when the gap crossed 1, which inverts to the neutral
# rate to within the estimation error. te_mon_stance_band is what the bank
# itself reads (gap - error) and what the dashboard already shows: bands 4 and
# 5 are its tight half, 1 and 2 its loose half, 3 the middle. So the politics
# are keyed to a number the player can already see, and the two modifiers' loc
# says "as the bank reads it" for the same reason.
#
# THE COUNTER, in three cases:
#
#   band >= 4   count up, after zeroing a counter that was counting DOWN
#   band <= 2   count down, after zeroing a counter that was counting UP
#   band 3      walk one step back toward 0, whichever side it is on
#
# A REVERSAL IS INSTANT, A LULL IS SLOW. Crossing from tight to loose zeroes the
# counter in one month, because the stance the politics were about is not merely
# paused — it has been replaced by its opposite, and nobody is still angry about
# dear money in the month the bank starts giving it away. Drifting back to the
# middle band is the other case: the stance has stopped, the consequences have
# not, and te_mon_stance_months_cap (11 — five months past the threshold, so the
# longest fade is exactly as long as the climb) bounds it at six months however
# long the stance ran. Six is the MAXIMUM, not the figure: a country that only
# just earned the politics is sitting at exactly 6 and loses them again after
# one month in the middle band. Without the cap a decade of tight money would
# take a decade to unwind; the loc says "within six months" for the same reason.
#
# ONLY A COUNTRY WITH A DIAL. Step 8 forces a no-dial country's band to 3, so a
# bankless, dollarised or command-economy country would already decay to 0 on
# its own — but slowly, and while still carrying a modifier it can no longer
# do anything about. Losing the dial is not a stance, so the counter is zeroed
# outright and the modifier comes off on the same pulse.
#
# DECIDED FROM VARIABLES, NEVER FROM has_modifier, and for the reason written
# out at length on step 6c: add_modifier and remove_modifier results are not
# visible inside the effect block that issues them, so a has_modifier read here
# would be asking about state this effect is in the middle of changing.
# te_mon_stance_politics_applied is the bookkeeping — 0 neither, 1 tight,
# 2 loose — and the swap issues at most one remove and one add a month.
#
# NO FIRST-RUN SWEEP, on step 6c's reasoning: these are COUNTRY modifiers on the
# country itself, and a country that has never run this step carries the 0 from
# step 0 and no politics modifier — the two agree.
te_monetary_apply_stance_politics = {
	# --- the counter --------------------------------------------------------
	if = {
		limit = { te_mon_has_dial = no }
		set_variable = { name = te_mon_stance_months value = 0 }
	}
	else_if = {
		limit = { var:te_mon_stance_band >= 4 }
		if = {
			limit = { var:te_mon_stance_months < 0 }
			set_variable = { name = te_mon_stance_months value = 0 }
		}
		change_variable = { name = te_mon_stance_months add = 1 }
		if = {
			limit = { var:te_mon_stance_months > te_mon_stance_months_cap }
			set_variable = { name = te_mon_stance_months value = te_mon_stance_months_cap }
		}
	}
	else_if = {
		limit = { var:te_mon_stance_band <= 2 }
		if = {
			limit = { var:te_mon_stance_months > 0 }
			set_variable = { name = te_mon_stance_months value = 0 }
		}
		change_variable = { name = te_mon_stance_months subtract = 1 }
		if = {
			limit = { var:te_mon_stance_months < te_mon_stance_months_cap_neg }
			set_variable = { name = te_mon_stance_months value = te_mon_stance_months_cap_neg }
		}
	}
	else = {
		# Band 3 — the stance has stopped. Fade, one month per month.
		if = {
			limit = { var:te_mon_stance_months > 0 }
			change_variable = { name = te_mon_stance_months subtract = 1 }
		}
		else_if = {
			limit = { var:te_mon_stance_months < 0 }
			change_variable = { name = te_mon_stance_months add = 1 }
		}
	}

	# --- what belongs on the country this month -----------------------------
	if = {
		limit = { var:te_mon_stance_months >= te_mon_stance_politics_months }
		set_variable = { name = te_mon_work value = 1 }
	}
	else_if = {
		limit = { var:te_mon_stance_months <= te_mon_stance_politics_months_neg }
		set_variable = { name = te_mon_work value = 2 }
	}
	else = {
		set_variable = { name = te_mon_work value = 0 }
	}

	if = {
		limit = { NOT = { var:te_mon_stance_politics_applied = var:te_mon_work } }

		# Take off what we put on last month.
		if = { limit = { var:te_mon_stance_politics_applied = 1 } remove_modifier = te_mon_stance_politics_tight }
		else_if = { limit = { var:te_mon_stance_politics_applied = 2 } remove_modifier = te_mon_stance_politics_loose }

		# Put on this month's, if there is one.
		if = { limit = { var:te_mon_work = 1 } add_modifier = { name = te_mon_stance_politics_tight } }
		else_if = { limit = { var:te_mon_work = 2 } add_modifier = { name = te_mon_stance_politics_loose } }

		set_variable = { name = te_mon_stance_politics_applied value = var:te_mon_work }
	}
}


# ----------------------------------------------------------------------------
# STEP 9 — write the rate into the engine (§16.1)
# ----------------------------------------------------------------------------
# Scope: country.
#
# ONE static modifier:
#
#   te_monetary_rate_paid    country_loan_interest_rate_add = 0.01
#                            multiplier = var:te_rate_paid_applied
#
# Vanilla's flat 20% base is not cancelled here. It is cancelled on the entity
# that grants it, by `country_loan_interest_rate_add = -0.2` in the mod's
# INJECT:base_values block (common/static_modifiers/extra_modifiers.txt), the
# same treatment the country ranks and the vanilla finance techs get. The player
# therefore sees one interest line rather than a +20% base with a -20% modifier
# beside it. A country that has never pulsed carries no rate modifier at all and
# borrows at 0% until its first update — the owner has confirmed in game that a
# non-positive total simply reads 0.0% with no ill effect — which is why game
# start and all seven country-creation hooks run the update immediately.
#
# te_rate_paid_applied IS te_rate_paid_pts. It stays a separate variable because
# it records what was last written into the multiplier, which is what the 0.05
# comparison below needs; nothing is added to it. Vanilla's five finance techs
# used to be compensated here (plan ruling R3), but they are now cancelled
# engine-side in common/technology/technologies/te_monetary_tech_injections.txt,
# so no vanilla interest source survives for this write to net against.
#
# The re-apply is skipped when the applied value has moved by less than 0.05
# (§16.1), unless the modifier is missing — which is how a country that has just
# been released, formed or loaded from an older save gets it on the first
# pulse even though nothing moved. A save written before the tech cancel landed
# carries an applied value up to 2.0pp per researched finance tech above pts; the
# first pulse after loading sees that whole gap at once, far over the threshold,
# and corrects it in one step.
#
# CALLED FROM ONE PLACE — te_monetary_monthly_update. This step, alone in this
# file, is idempotent: it reads its inputs, compares against what is applied, and
# either does nothing or replaces the modifier, never drifting the rate
# and never drawing a walk. That makes it the only step an extra entry point
# would be safe on, and it had one until the tech cancels removed the reason for
# it. Anything that wants the modifier refreshed writes its input and waits for
# the pulse.
#
# ROOT MUST BE THIS COUNTRY. `multiplier = var:te_rate_paid_applied` is resolved
# by the engine against ROOT, not against the scope this effect runs in. Run from
# a context whose ROOT is `none` (on_game_started) the read finds nothing and the
# engine silently substitutes 1.0; run from a context whose ROOT is another
# country (the country-creation hooks, where ROOT is the parent) it writes that
# country's rate. Both were live bugs, fixed by dispatching those entry points
# through te_monetary_internal.1 — see common/on_actions/te_monetary_on_actions.txt
# and scripting_best_practices.md § "Scope Chain Issues with add_modifier +
# Script Values".
#
# te_rate_paid_rooted IS THE BELT. It is set only here, and only when `root ?= this`
# says the write really did have this country in ROOT for the multiplier to
# resolve against. It is the one monetary variable deliberately NOT initialised
# in step 0: its ABSENCE is the signal. A country whose modifier was written
# root-less — from a save made before this fix, or from any future call site that
# gets ROOT wrong — lacks the marker, so the condition below fires on its first
# monthly pulse (ROOT = country there) and rewrites the modifier correctly.
# Without it, such a country is stuck forever: the applied value already equals
# the target, so the 0.05 threshold never trips and the wrong multiplier survives
# the whole campaign. That is exactly how the game-start bug went unnoticed for a
# whole play-test. It is only ever read through `has_variable`, so it can never
# return 'none', and it is never removed.
#
# The degradation is graceful in both directions. If `root ?= this` somehow never
# holds, the marker never sets and this step simply re-writes the modifier every
# month from the monthly pulse — where ROOT *is* the country — so the rate stays
# correct and the only cost is a redundant remove-and-add. If a future call site
# gets ROOT wrong, the marker stays unset and the next pulse repairs it.
#
# te_rate_paid_applied is never removed either: the engine re-evaluates the
# multiplier expression on later ticks, and a missing variable would make every
# one of them read 'none' (modifier_multiplier_var_audit).
te_monetary_apply_interest_modifiers = {
	set_variable = { name = te_mon_work value = var:te_rate_paid_pts }
	set_variable = { name = te_mon_work2 value = var:te_mon_work }
	change_variable = { name = te_mon_work2 subtract = var:te_rate_paid_applied }
	if = {
		limit = {
			OR = {
				var:te_mon_work2 >= 0.05
				var:te_mon_work2 <= -0.05
				NOT = { has_modifier = te_monetary_rate_paid }
				NOT = { has_variable = te_rate_paid_rooted }
			}
		}
		if = {
			limit = { has_modifier = te_monetary_rate_paid }
			remove_modifier = te_monetary_rate_paid
		}
		set_variable = { name = te_rate_paid_applied value = var:te_mon_work }
		add_modifier = {
			name = te_monetary_rate_paid
			multiplier = var:te_rate_paid_applied
		}
		# Only a write whose ROOT was this country counts as a good one — that is
		# the whole meaning of the marker.
		if = {
			limit = { root ?= this }
			set_variable = { name = te_rate_paid_rooted value = 1 }
		}
	}
}


# ----------------------------------------------------------------------------
# STEP 10 — gold flow, hot money and peg confidence (§12.2, §12.3)
# ----------------------------------------------------------------------------
# Scope: country. Rulings Q6-Q10 (monetary_policy_design.md §0.5).
#
#   gap  = clamp( policy_rate - world_rate , -5 , +5 )
#   flow = gap x 0.002 x gdp     a month; positive = inflow
#
# WHO. te_mon_has_gold_flows — on gold (the law AND convertibility) with a
# national bank. A gold country without a bank pays the world rate, so its gap
# and its drain are zero by construction (§12.2). Everyone else takes the `else`
# at the foot of this effect, which is a handful of variable writes.
#
# add_treasury, NOT A SCALED EXPENSE MODIFIER (§12.2's sign argument): an
# expense modifier feeds total_expenses, which the fiscal-stimulus reader and
# the §9.1 deficit term both read, so an OUTFLOW would register as deficit
# spending — stimulus and inflation, the wrong sign twice. It never appears in
# the budget ledger, which is why the dashboard prints the flow.
#
# INFLOWS ARE HOT MONEY, NOT INCOME. Every pound that comes in is recorded in
# te_gold_hot_money, and:
#
#   * it comes in only while the country is out of debt (ruling Q6 — gold that
#     arrives into a debt pays the debt down, and could then never be asked
#     back, because outflows stop for a country in debt), while reserves are
#     under the engine's limit, and while the hot-money balance is itself under
#     one reserve limit (ruling Q8) — te_mon_gold_inflow_room is both caps;
#   * when the gap falls to <= 0 it leaves FIRST, at twice the ordinary speed
#     and never slower than a half-point gap would give (ruling Q7), before any
#     ordinary drain starts;
#   * it adds nothing to peg confidence — and while it is queueing to leave a
#     country that cannot pay it, it is what empties confidence fastest.
#
# UNDER PRESSURE (te_mon_peg_under_pressure: reserves under a tenth of the
# limit, or any debt) the OUTFLOW stops — a negative add_treasury would only
# deepen the debt — and te_peg_confidence moves instead, by
# te_mon_peg_confidence_move. Out from under it, confidence heals a point a
# month while the gap is >= 0 and no borrowed gold is waiting to leave, and
# otherwise holds (ruling Q10, revised after the first playtest; §12.3 is silent, and without it an episode would scar a
# country for the rest of the campaign).
#
# NO OUTFLOW EVER EXCEEDS THE RESERVES. The drain is capped at gold_reserves, so
# this step can empty a treasury and can never put a country into debt.
#
# THE CRISIS. At confidence <= te_mon_peg_crisis_threshold the convertibility
# crisis te_peg.1 goes out (events/te_peg_events.txt), with the same
# cooldown-set-here shape as step 6c's hyperinflation crisis and for the same
# reason: an unanswered event must not be handed out again next month.
#
# THE THREE CLOCKS tick here, once a pulse, AFTER everything that reads them:
# te_peg_crisis_cooldown, te_peg_defend_months (the Defend option's year at
# world + 4 — te_mon_target_min reads it) and te_peg_suspended_months (the
# Suspend option's five years as fiat — te_mon_is_on_gold reads it). When the
# suspension runs out convertibility resumes at te_mon_peg_devalue_confidence
# (50): a peg that has been broken once is not trusted like one that never was.
#
# LEAVING GOLD WITH BORROWED GOLD ON THE BOOKS PAYS IT BACK AT ONCE (ruling Q9).
# A country that is no longer on gold at all — the law changed, or the national
# bank went — has its whole hot-money balance leave in one payment, debt or no
# debt; otherwise "pull gold in, then enact fiat" is the free money §20 risk 7
# exists to prevent. A SUSPENSION is different and deliberately so: suspending
# convertibility IS refusing to pay gold out, so the balance is frozen, not
# paid, and is waiting when the peg resumes.
te_monetary_update_gold = {
	if = {
		limit = { te_mon_has_gold_flows = yes }

		set_variable = { name = te_gold_flow_gap value = te_mon_gold_gap_value }
		set_variable = { name = te_gold_flow value = 0 }

		# --- inflow ---------------------------------------------------------
		if = {
			limit = {
				var:te_gold_flow_gap > 0
				scaled_debt <= 0
			}
			set_variable = { name = te_gold_flow value = te_mon_gold_flow_unit }
			change_variable = { name = te_gold_flow multiply = var:te_gold_flow_gap }
			set_variable = { name = te_mon_work value = te_mon_gold_inflow_room }
			if = {
				limit = { var:te_gold_flow > var:te_mon_work }
				set_variable = { name = te_gold_flow value = var:te_mon_work }
			}
			change_variable = { name = te_gold_hot_money add = var:te_gold_flow }
		}
		# --- outflow: hot money first, then the ordinary drain --------------
		else_if = {
			limit = {
				var:te_gold_flow_gap <= 0
				te_mon_peg_under_pressure = no
			}
			# te_mon_work = the pp of gap this month's outflow is worth.
			set_variable = { name = te_mon_work value = var:te_gold_flow_gap }
			change_variable = { name = te_mon_work multiply = -1 }
			if = {
				limit = { var:te_gold_hot_money > 0 }
				if = {
					limit = { var:te_mon_work < te_mon_gold_hot_exit_gap_floor }
					set_variable = { name = te_mon_work value = te_mon_gold_hot_exit_gap_floor }
				}
				change_variable = { name = te_mon_work multiply = te_mon_gold_hot_exit_speed }
			}
			change_variable = { name = te_mon_work multiply = te_mon_gold_flow_unit }
			# Hot money leaves no faster than there is hot money...
			if = {
				limit = {
					var:te_gold_hot_money > 0
					var:te_mon_work > var:te_gold_hot_money
				}
				set_variable = { name = te_mon_work value = var:te_gold_hot_money }
			}
			# ...and nothing leaves faster than there is gold.
			set_variable = { name = te_mon_work2 value = te_mon_gold_reserves_now }
			if = {
				limit = { var:te_mon_work > var:te_mon_work2 }
				set_variable = { name = te_mon_work value = var:te_mon_work2 }
			}
			if = {
				limit = { var:te_gold_hot_money > 0 }
				change_variable = { name = te_gold_hot_money subtract = var:te_mon_work }
				if = {
					limit = { var:te_gold_hot_money < 0 }
					set_variable = { name = te_gold_hot_money value = 0 }
				}
			}
			set_variable = { name = te_gold_flow value = var:te_mon_work }
			change_variable = { name = te_gold_flow multiply = -1 }
		}

		# INSTRUMENTATION (first playtest: "the flow says -167k and my reserves
		# are not falling"). The engine's gold_reserves read immediately before
		# and immediately after the payment, printed by te_debug_monetary.8 and
		# nowhere else. after - before = the flow means add_treasury landed and
		# anything else moving the treasury is the weekly budget; after = before
		# means it did not. Two set_variables a month for gold countries only.
		set_variable = { name = te_gold_debug_before value = te_mon_gold_reserves_now }
		if = {
			limit = { NOT = { var:te_gold_flow = 0 } }
			add_treasury = te_mon_gold_flow_signed
		}
		set_variable = { name = te_gold_debug_after value = te_mon_gold_reserves_now }
		set_variable = { name = te_gold_flow_pct value = te_mon_gold_flow_pct_value }

		# --- the carry: borrowed gold is paid for (owner decision I) ---------
		# What stopped real central banks pulling gold in for the money: it
		# came as short-term balances EARNING the rate that attracted them,
		# while the gold it bought sat in a vault earning nothing. So the
		# balance costs the policy rate, a twelfth of it a month — which makes
		# hot money strictly dearer than ordinary borrowing for any country
		# whose credit is good, and leaves it what it historically was: a way
		# to refill a vault or defend a peg, never a way to raise funds.
		#
		# Paid from the treasury while there is one; CAPITALISED into the
		# balance when there is not (in debt, or an empty vault), on the same
		# argument that stops the outflow there — a negative add_treasury would
		# only deepen the debt — and so that not paying is never free either:
		# the unpaid interest is more gold queueing to leave.
		#
		# Not part of te_gold_flow, so the price-specie term prices the
		# principal that moved and not the coupon on it.
		set_variable = { name = te_gold_carry value = 0 }
		if = {
			limit = {
				var:te_gold_hot_money > 0
				var:te_policy_rate > 0
			}
			set_variable = { name = te_gold_carry value = var:te_gold_hot_money }
			change_variable = { name = te_gold_carry multiply = var:te_policy_rate }
			change_variable = { name = te_gold_carry divide = 1200 }
			set_variable = { name = te_mon_work2 value = te_mon_gold_reserves_now }
			if = {
				limit = {
					scaled_debt <= 0
					var:te_mon_work2 >= var:te_gold_carry
				}
				add_treasury = te_mon_gold_carry_payment
			}
			else = {
				change_variable = { name = te_gold_hot_money add = var:te_gold_carry }
			}
		}

		# --- peg confidence -------------------------------------------------
		if = {
			limit = { te_mon_peg_under_pressure = yes }
			change_variable = { name = te_peg_confidence add = te_mon_peg_confidence_move }
		}
		else_if = {
			# Out from under pressure confidence HEALS — but only while the bank
			# is not visibly losing gold. First playtest: a country at a gap of
			# -3 with a healthy vault was GAINING a point a month while its
			# reserves drained, which read as the peg applauding its own
			# undoing. With a negative gap (or borrowed gold still queueing to
			# leave) confidence now simply holds: the vault is paying, which is
			# the cost §12.2 intends at that stage, and the fall starts when the
			# vault cannot.
			limit = {
				var:te_gold_flow_gap >= 0
				var:te_gold_hot_money <= 0
			}
			change_variable = { name = te_peg_confidence add = 1 }
		}
		if = {
			limit = { var:te_peg_confidence > 100 }
			set_variable = { name = te_peg_confidence value = 100 }
		}
		if = {
			limit = { var:te_peg_confidence < 0 }
			set_variable = { name = te_peg_confidence value = 0 }
		}

		# --- the convertibility crisis --------------------------------------
		if = {
			limit = {
				var:te_peg_confidence <= te_mon_peg_crisis_threshold
				var:te_peg_crisis_cooldown = 0
			}
			set_variable = { name = te_peg_crisis_cooldown value = te_mon_peg_crisis_cooldown_months }
			trigger_event = { id = te_peg.1 }
		}
	}
	else = {
		set_variable = { name = te_gold_flow_gap value = 0 }
		set_variable = { name = te_gold_flow value = 0 }
		set_variable = { name = te_gold_flow_pct value = 0 }
		set_variable = { name = te_gold_carry value = 0 }

		# Off gold altogether: borrowed gold goes home, and the next peg this
		# country enters starts trusted. Suspended: frozen, both of them.
		if = {
			limit = { te_mon_peg_is_suspended = no }
			if = {
				limit = { var:te_gold_hot_money > 0 }
				add_treasury = te_mon_gold_hot_money_payout
				set_variable = { name = te_gold_hot_money value = 0 }
			}
			set_variable = { name = te_peg_confidence value = te_mon_peg_confidence_start }
		}
		# The LAW itself gone: a suspension or a defence of a peg that no
		# longer exists is nothing, and must not be waiting for a country that
		# enacts the gold standard again twenty years later.
		if = {
			limit = { NOT = { has_law_or_variant = law_type:law_gold_standard } }
			set_variable = { name = te_peg_suspended_months value = 0 }
			set_variable = { name = te_peg_defend_months value = 0 }
		}
	}

	# --- the three clocks ---------------------------------------------------
	if = {
		limit = { var:te_peg_crisis_cooldown > 0 }
		change_variable = { name = te_peg_crisis_cooldown subtract = 1 }
	}
	if = {
		limit = { var:te_peg_defend_months > 0 }
		change_variable = { name = te_peg_defend_months subtract = 1 }
	}
	if = {
		limit = { var:te_peg_suspended_months > 0 }
		change_variable = { name = te_peg_suspended_months subtract = 1 }
		if = {
			limit = { var:te_peg_suspended_months <= 0 }
			set_variable = { name = te_peg_suspended_months value = 0 }
			set_variable = { name = te_peg_confidence value = te_mon_peg_devalue_confidence }
		}
	}
}


# ----------------------------------------------------------------------------
# YEARLY — the neutral rate's growth term (§8)
# ----------------------------------------------------------------------------
# Scope: country. Called from on_yearly_pulse_country.
#
#   growth_term = clamp( 0.25 x (trailing GDP growth % - 2) , -1.5 , +1.5 )
#
# A country growing at 2% a year sits exactly on the reference rate; a 8%
# boom pushes the neutral rate 1.5pp higher, a contraction 1.5pp lower. The
# comparison needs last year's GDP, which is what te_mon_gdp_last_year caches —
# `gdp` is a trigger-dispatched read and cannot go in a change_variable op slot,
# hence te_mon_gdp_current (scripting_best_practices.md:1622-1624).
te_monetary_yearly_growth_snapshot = {
	if = {
		limit = { NOT = { has_variable = te_mon_growth_term } }
		set_variable = { name = te_mon_growth_term value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_work } }
		set_variable = { name = te_mon_work value = 0 }
	}
	if = {
		limit = { NOT = { has_variable = te_mon_gdp_last_year } }
		set_variable = { name = te_mon_gdp_last_year value = te_mon_gdp_current }
	}
	if = {
		# A zero baseline would divide by zero; leave the term where it was.
		limit = { var:te_mon_gdp_last_year > 0 }
		set_variable = { name = te_mon_work value = te_mon_gdp_current }
		change_variable = { name = te_mon_work subtract = var:te_mon_gdp_last_year }
		change_variable = { name = te_mon_work divide = var:te_mon_gdp_last_year }
		change_variable = { name = te_mon_work multiply = 100 }
		change_variable = { name = te_mon_work subtract = 2 }
		change_variable = { name = te_mon_work multiply = 0.25 }
		if = {
			limit = { var:te_mon_work > 1.5 }
			set_variable = { name = te_mon_work value = 1.5 }
		}
		if = {
			limit = { var:te_mon_work < -1.5 }
			set_variable = { name = te_mon_work value = -1.5 }
		}
		set_variable = { name = te_mon_growth_term value = var:te_mon_work }
	}
	set_variable = { name = te_mon_gdp_last_year value = te_mon_gdp_current }
}


# ----------------------------------------------------------------------------
# PLAYER CONTROLS — what the dashboard's monetary block writes (§3, §16.4)
# ----------------------------------------------------------------------------
# Scope: country (the journal entry's owner).
#
# These are the ONLY writers of te_policy_rate_target, te_mon_delegated,
# te_mon_mandate and te_monetisation_level outside the monthly update, and they
# live here rather than in the scripted-GUI file for the same reason everything
# else in this file does: one owner per variable, one place to look. The one
# exception is the console-only §19 harness (te_debug_monetary.5 and .7 in
# events/te_debug_monetary_events.txt), which pins those same four by hand
# because an AI country is always delegated and no player-facing control can
# put a country where §10's worked example starts.
#
# They deliberately do NOT call te_monetary_monthly_update. That effect is not
# idempotent within a month (step 3 drifts the rate, step 8 draws two random
# walks), so a button that ran it would age the hidden state every click. Each
# control writes its input and the next monthly pulse picks it up — which is
# also why the target stepper's tooltip says the rate closes on the target over
# a quarter rather than moving now.
#
# Eligibility lives in common/scripted_triggers/te_monetary_triggers.txt and is
# asked by the scripted GUI's `is_valid`, so the tooltip and the effect can
# never disagree. Each effect still clamps: a click and the monthly re-clamp can
# race across a law change, and clamping twice is free.
#
# The `hidden_effect` + one `custom_tooltip` shape is the funding stepper's
# (common/scripted_effects/cultural_hegemony_effects.txt:139): the raw variable
# writes would otherwise be spelled out in the button's ExecuteTooltip.

te_mon_effect_target_step_down = {
	hidden_effect = {
		change_variable = { name = te_policy_rate_target subtract = 1 }
		clamp_variable = {
			name = te_policy_rate_target
			min = te_mon_target_min

# Parameters: $MANDATE$ = 1 price stability, 2 growth, 3 peg defence (§6).

# $TT$ exists because peg defence is the one mandate whose rule is about
# something outside your own country — it parks the target on the world
# reference rate — and a button that says only "changes the rule your central
# bank follows" leaves the player to go looking for which rule. A `$MANDATE$ = 3`
# test is not available here: a parameter is substituted as text, not compared.

# MONETISING THE DEFICIT (§11). The same stepper shape as the rate target, and
# for the same reason: the pair writes te_monetisation_level and nothing else,
# and step 1b of the next monthly pulse turns the number into minting, into a
# risk premium and into inflation pressure. Calling the update from here would
# age a month of hidden state per click.
#
# ELIGIBILITY is te_mon_can_monetise (fiat or digital, a national bank, not
# independent, not a command economy, not dollarised), which the dashboard asks
# in its `is_valid` so the greyed-out tooltip and the effect can never
# disagree — and which step 1b re-asks every month, so a level held through a
# law change is taken away on the next pulse rather than lingering.
#
# The clamp is here as well as in step 1b because a click and the monthly pass
# can race across a law change, and clamping twice is free.

		clamp_variable = {
			name = te_monetisation_level
			min = 0
			max = te_mon_monetisation_max
		}
	}
	custom_tooltip = banking_mon_monetise_step_tt
}

# ----------------------------------------------------------------------------
# THE NEW-CURRENCY RESET (§9.2) — what a country pays for money it has just
# issued
# ----------------------------------------------------------------------------
# Scope: country. Two call sites, and they are the only ones:
#
#   * te_inflation.1's CURRENCY REFORM option (events/te_inflation_events.txt) —
#     the old notes called in and reissued at a new value; and
#   * the P9 DOLLARISATION EXIT in te_banking_law_change_cleanup
#     (common/on_actions/extra_on_actions.txt) — a dollarised country enacting a
#     monetary-policy law, which IS the act of putting a currency of its own
#     back into people's hands.
#
# The same economic event from two directions, so it carries the same
# credibility price: inflation and expectations start at
# te_mon_currency_reform_reset rather than at the target, and lenders charge the
# ten-year premium. What the two do NOT share is the one-off wreckage — the
# reform wipes out the investment pool and radicalises the savers who held the
# old notes; the exit does neither, because the months of lost seigniorage under
# dollarisation were that half of the price.
#
# WHY THE EXIT PAYS ANYTHING AT ALL. Dollarising resets expectations to the
# anchor, so without this the sequence dollarise -> wait out one law enactment
# -> re-enact fiat would be a currency reform with no pool wipe, no radicals and
# no premium: strictly the cheapest way out of a hyperinflation, and free.
#
# IT WRITES INFLATION STATE, which nothing but the monthly update otherwise
# does. Both call sites are listed as documented exceptions in the variable
# contract (header of common/script_values/te_monetary_script_values.txt). It
# must never call te_monetary_monthly_update: that effect is not idempotent
# within a month.
#
# te_cost_push GOES TO 0 WITH THE REST, so the headline written here is
# consistent with core until the next pulse recomputes the basket term. It is a
# level, not a stock, so the pulse simply re-derives it from the same prices.
#
# THE WRITES ARE HIDDEN AND THE MODIFIER IS NOT, on the player-controls
# convention above: raw set_variable lines would otherwise be spelled out in
# the option's tooltip, while the ten-year premium is exactly what the player
# should see there.
te_mon_effect_new_currency = {
	hidden_effect = {
		set_variable = { name = te_inflation value = te_mon_currency_reform_reset }
		set_variable = { name = te_inflation_core value = te_mon_currency_reform_reset }
		set_variable = { name = te_inflation_expected value = te_mon_currency_reform_reset }
		set_variable = { name = te_cost_push value = 0 }
	}

	add_modifier = {
		name = te_mon_currency_reform_premium
		days = 3650
	}
}
