# Rules of War (lawgroup_rules_of_war, common/laws/extra_laws.txt).

# The world's reading of a new law: a one-time infamy change when a Rules of
# War law takes effect. Each law's on_activate passes its infamy standing
# (STANDING: Total War +25, Traditional 0, War Crimes Forbidden -10,
# Humanitarian Regulations -15, Limited War -20), and infamy moves by the new
# standing minus the one already charged, so the change is path-independent:
# Traditional to Total War is +25, Total War back to Traditional -25, Total
# War to Limited War -45. A round trip nets zero (less whatever the floor at 0
# infamy swallowed), so cycling between restrictive laws can't wipe infamy.
#
# te_row_infamy_standing holds the standing charged so far, 0 when unset: the
# start law (every country starts on Traditional, extra_history.txt), and a
# country from a save made before this effect, which was charged nothing. No
# pulse resyncs it to the law in force, since that would hand such a country a
# refund for infamy it never paid. Revolutionaries start with no variables,
# so if their movement wins them a different Rules of War law, the winner may
# keep the loser's standing for a law it never paid for; rare, at most 45.
#
# The change renders in the enactment preview, computed from the standing
# before enactment. Country scope.
te_row_charge_infamy = {
	change_infamy = {
		value = $STANDING$
		if = {
			limit = { has_variable = te_row_infamy_standing }
			subtract = var:te_row_infamy_standing
		}
	}
	hidden_effect = {
		set_variable = { name = te_row_infamy_standing value = $STANDING$ }
	}
}
