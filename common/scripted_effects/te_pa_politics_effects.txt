# Private Actors, politics at home (docs/systems/mod_systems/private_actors.md § Politics at Home; spec §§ 8.2, 8.3,
# 8.5, 8.7, 6.4; plan Task 5). Sides on the law being enacted and their settlement; stalling (te_pa_do_stall, in
# te_pa_trust_effects.txt) and speeding the law; campaign money in its two forms, momentum for a party in a campaign
# and patronage for an interest group otherwise, under each Electoral Finance law, open or secret; the wager on the
# side it backed; the press; the government's Close the Press. Numbers in te_pa_politics_values.txt, triggers in
# te_pa_politics_triggers.txt; the patronage modifiers, one an interest group type, and the per-group dispatch are
# generated (te_pa_gen_modifiers.txt, te_pa_gen_effects.txt; gen_private_actors.py).
#
# On the firm (company variables, unset while unused; te_pa_politics_clear drops them with the firm):
#   te_pa_stake_law (the law table's number of its law at stake), te_pa_stake_sign (1 for it, -1 against it),
#     te_pa_stake_trade (1: the stake is the trade policy, sign 1 toward Free Trade) | te_pa_stake_pick writes them
#   te_pa_side_of (the law its side spending is on), te_pa_side_sign, te_pa_side_spent (pounds)
#   te_pa_speed_month (its last speed) | te_pa_campaign_total (its campaign money in all, pounds: the Electoral
#     Finance stances read it) | te_pa_cm_want, _open, _hidden, _paid, _units, _mom (a spend, staged)
#   te_pa_cm_secret (secret money still at risk, pounds), te_pa_cm_secret_units (what it bought, patronage units),
#     te_pa_cm_secret_ig (the group it went to, for patronage)
#   te_pa_bet_ig (the group backed: a party's largest member, or the group patronized), te_pa_bet_form (1 momentum,
#     2 patronage), te_pa_bet_out (1: the group was out of government), te_pa_bet_until (a patronage wager's month)
#   te_pa_press 0-100, te_pa_press_again (no new press before this month)
# On the country:
#   te_pa_side_law (the law the sides are on), te_pa_side_for / _against (pounds), te_pa_side_top_<for|against>_<1-3>
#     (the three largest firms each side) and te_pa_side_amt_<side>_<n> (theirs), te_pa_side_n_for / _against
#   te_pa_stall_law and _month, te_pa_speed_law and _month: the last firm setback and progress, a law a year
#   te_pa_pat_<group> (patronage, units), te_pa_pm_<group> (its modifier's multiplier), te_pa_cmp_<group> (campaign
#     money to the party the group leads this election, pounds), te_pa_cmm_<group> (the momentum it bought),
#     te_pa_cmn_<group> (the campaign's notice posted) | te_pa_elect_end (the month a campaign ended, until settled)
#   te_pa_pol_secret (secret money at risk, all firms, pounds) | te_pa_pol_campaign (1 in a campaign, for the tab)
#   the lists te_pa_presses (the firms with a press) and te_pa_pol_view (the Politics section's rows), rebuilt
#
#   Task 5b, the petition for a law or a tariff (kind law, 3, on te_pa_moves_effects.txt's frame):
#   on the firm: te_pa_move_ask (1 a law, 2 a tariff on its output, 3 a lower tariff on its input, 4 Antitrust
#     Enforcement for a buyer, 5 Task 6's labor law), te_pa_move_law, te_pa_move_good, te_pa_move_level (what it
#     asks for, written by te_pa_pt_pick at its nomination; the frame copies them onto the move's ledger entries)
#   | te_pa_law_again (no new petition before this month) | te_pa_pt_spent_amt, te_pa_pt_spent_sign (what it put
#     for or against the country's petition) | the pledge: te_pa_pl_kind (1 a law, 2 a tariff), te_pa_pl_law,
#     te_pa_pl_good, te_pa_pl_level, te_pa_pl_dir (1 raise, -1 lower), te_pa_pl_until, te_pa_pl_begun,
#     te_pa_pl_started, te_pa_pl_speed_month, te_pa_pl_reminded, te_pa_pl_set_month | te_pa_pl_back, te_pa_pl_back_until (it backs the
#     government at the next election) | te_pa_cm_gov (staged: this spend backs the government)
#   on the country: the petition's record, te_pa_pt_firm, te_pa_pt_ask, te_pa_pt_law, te_pa_pt_good, te_pa_pt_level,
#     te_pa_pt_end (its answer's month), te_pa_pt_for / _against (Connections), te_pa_pt_n_for / _against,
#     te_pa_pt_top_<for|against>_<1-3> and te_pa_pt_amt_<side>_<n> | te_pa_tf_law, te_pa_tf_good, te_pa_tf_level
#     (a pledge's, staged for the generated readers)
#
# Ledger verbs (Task 5a's 40-49; 5b's are 50-59), each a predicate after the firm's name:
#   40 speeds <law>                                      41 was on the winning side of <law> (size: its side's money)
#   42 was on the losing side of <law> (size: likewise)  43 gives <size> to the campaign of the party of <group>
#   44 gives <size> in patronage to <group>              45 is exposed as the author of secret campaign money
#   46 founds a press                                    47 its press is discredited
#   48 no longer keeps a press                           49 has its press closed by the government
# 43 and 44 carry KNOWN 0 for the secret part, whose lines get their author when it is exposed.
#   50 spends <size> Connections against <target>'s petition   51 spends <size> Connections for <target>'s petition
#   52 the government begins enacting <law>, as it pledged     53 the government has held the tariff on <good> for
#      (or the law is in force)                                   the five years it pledged
#   54 the government breaks its pledge to enact <law>         55 the government breaks its pledge on the tariff
#      (counted as a refusal: Grievance +1, Connections -10)      on <good> (likewise)
#   56 speeds <law> at no cost, on the government's pledge     57 the pledge on the tariff on <good> lapses: the Tax
#                                                                 Code legislates tariffs, or the market is not ours
# The petition's own lines are the frame's (30-33, kind 3), with its ask on the entry (te_pa_l_ask, _law, _good,
# _level).

# ---------------------------------------------------------------------------
# The turn (te_pa_turn, after the goal is chosen and before te_pa_act)
# ---------------------------------------------------------------------------

# Company scope (scope:te_pa_home its country). The country's sides are settled if their law has ended and opened on
# a new one (te_pa_sides_check), and the firm's law at stake is read.
te_pa_politics_turn = {
	scope:te_pa_home = { te_pa_sides_check = yes }
	te_pa_stake_pick = yes
	# Task 5b: an ask left from a nomination that lost goes, unless its move is the one under way, so no later move's
	# ledger entry carries it (te_pa_move_note_ask).
	if = {
		limit = {
			has_variable = te_pa_move_ask
			te_pa_is_move_firm = no
		}
		te_pa_move_ask_clear = yes
	}
}

# Company scope, after te_pa_gen_law_pick and the trade stance. The law it has most at stake, the side campaign money
# goes to: the law being enacted where it has a stance; else the law in force that burdens it most (against it); else
# the law it could move to that favors it most (for it); else the trade policy where it burdens it. A firm seeking
# Cheaper Inputs looks first at a tariff on an input the market imports (§ 8.3: "a tariff on its input", Task 5b's
# readings: te_pa_tariff_on_inputs), one seeking A Protected Market at the missing tariff on its imported output
# (te_pa_p_market_tariff's case). A tariff's stake is written as the trade's (te_pa_stake_trade 1, sign 1 toward
# Free Trade, -1 toward protection), since an interest group's stance on a tariff is its stance on Free Trade
# (te_pa_ig_side_value). None: its executive's interest group is the side (§ 5.3, te_pa_cm_pick).
te_pa_stake_pick = {
	set_variable = { name = te_pa_stake_law value = 0 }
	set_variable = { name = te_pa_stake_sign value = 0 }
	set_variable = { name = te_pa_stake_trade value = 0 }
	if = {
		limit = {
			var:te_pa_goal ?= 1
			te_pa_tariff_on_inputs > 0
		}
		set_variable = { name = te_pa_stake_trade value = 1 }
		set_variable = { name = te_pa_stake_sign value = 1 }
	}
	else_if = {
		limit = {
			var:te_pa_goal ?= 2
			te_pa_wants_output_tariff = yes
			te_pa_v_out_tariff <= 0
		}
		set_variable = { name = te_pa_stake_trade value = 1 }
		set_variable = { name = te_pa_stake_sign value = -1 }
	}
	else_if = {
		limit = {
			has_variable = te_pa_g_law_enacting_law
			var:te_pa_g_law_enacting_law > 0
			OR = {
				te_pa_v_law_enacting > 0
				te_pa_v_law_enacting < 0
			}
		}
		set_variable = { name = te_pa_stake_law value = var:te_pa_g_law_enacting_law }
		set_variable = { name = te_pa_stake_sign value = 1 }
		if = {
			limit = { te_pa_v_law_enacting < 0 }
			set_variable = { name = te_pa_stake_sign value = -1 }
		}
	}
	else_if = {
		limit = {
			te_pa_v_law_worst < 0
			has_variable = te_pa_g_law_worst_law
			var:te_pa_g_law_worst_law > 0
		}
		set_variable = { name = te_pa_stake_law value = var:te_pa_g_law_worst_law }
		set_variable = { name = te_pa_stake_sign value = -1 }
	}
	else_if = {
		limit = {
			te_pa_v_law_best > 0
			has_variable = te_pa_g_law_best_law
			var:te_pa_g_law_best_law > 0
		}
		set_variable = { name = te_pa_stake_law value = var:te_pa_g_law_best_law }
		set_variable = { name = te_pa_stake_sign value = 1 }
	}
	else_if = {
		limit = { te_pa_trade_burden_value > 0 }
		set_variable = { name = te_pa_stake_trade value = 1 }
		set_variable = { name = te_pa_stake_sign value = 1 }
		if = {
			limit = { te_pa_v_trade > 0 }
			set_variable = { name = te_pa_stake_sign value = -1 }
		}
	}
}

# A Friendly Law (§ 8.3): set back the law being enacted that it is against, push the one it is for, petition the
# government for the law it could move to that favors it most (§ 8.4, a declared move: Task 5b), or put money on
# its law at stake.
te_pa_act_law = {
	if = {
		limit = { te_pa_can_stall = yes }
		te_pa_do_stall = yes
	}
	else_if = {
		limit = { te_pa_can_speed = yes }
		te_pa_do_speed = yes
	}
	else_if = {
		limit = { te_pa_can_declare_law = yes }
		te_pa_do_declare_law = yes
	}
	else_if = {
		limit = { te_pa_can_campaign = yes }
		te_pa_do_campaign = yes
	}
}

# ---------------------------------------------------------------------------
# Speeding the law (§ 8.3)
# ---------------------------------------------------------------------------

# Company scope (scope:te_pa_home its country). Twenty Connections for ten points of the current checkpoint
# (add_law_progress, a fraction of it), logged with the law named. The law_progress self-check (probe 10) reads the
# enactment a month later. Fallback, if it is BROKEN: a timed country_law_enactment_success_add modifier in its place,
# as vanilla's strike events use.
te_pa_do_speed = {
	set_variable = { name = te_pa_conn value = te_pa_conn_after_speed }
	set_variable = { name = te_pa_speed_month value = te_history_month_index }
	scope:te_pa_home = {
		set_variable = { name = te_pa_speed_law value = te_pa_gen_enacting_law_index }
		set_variable = { name = te_pa_speed_law_month value = te_history_month_index }
		te_pa_debug_progress_arm = yes
		add_law_progress = te_pa_speed_progress
	}
	save_scope_as = te_pa_l_actor
	scope:te_pa_home = { te_pa_ledger_add = { VERB = 40 KNOWN = 1 } }
	if = {
		limit = { exists = scope:te_pa_l_new }
		scope:te_pa_l_new = {
			set_variable = { name = te_pa_l_law value = scope:te_pa_home.var:te_pa_speed_law }
		}
	}
}

# Company scope, the turn. A goal's campaign money on its law at stake, in full.
te_pa_do_campaign = {
	te_pa_campaign_spend = { SIZE = full }
}

# Company scope, the turn, after the goal's verb (§ 8.2). Its money on its side of the law being enacted: its stake
# is that law, with its stance's sign; in full for a firm seeking A Friendly Law or defending its cartel, at half
# otherwise. What it spends adds to its side's, and its country's three largest each side are ranked again.
te_pa_do_back_side = {
	set_variable = { name = te_pa_stake_law value = te_pa_enacting_law_firm }
	set_variable = { name = te_pa_stake_trade value = 0 }
	set_variable = { name = te_pa_stake_sign value = 1 }
	if = {
		limit = { te_pa_gen_stance_enacting < 0 }
		set_variable = { name = te_pa_stake_sign value = -1 }
	}
	if = {
		limit = { te_pa_back_side_full = yes }
		te_pa_campaign_spend = { SIZE = full }
	}
	else = {
		te_pa_campaign_spend = { SIZE = half }
	}
	if = {
		limit = { var:te_pa_spent ?= 1 }
		set_variable = { name = te_pa_side_of value = te_pa_side_law_now }
		set_variable = { name = te_pa_side_sign value = var:te_pa_stake_sign }
		set_variable = { name = te_pa_side_spent value = te_pa_side_spent_after }
		save_scope_as = te_pa_side_firm
		scope:te_pa_home = {
			if = {
				limit = { scope:te_pa_side_firm = { var:te_pa_side_sign ?= 1 } }
				change_variable = { name = te_pa_side_for add = scope:te_pa_side_firm.var:te_pa_cm_paid }
			}
			else = {
				change_variable = { name = te_pa_side_against add = scope:te_pa_side_firm.var:te_pa_cm_paid }
			}
			te_pa_sides_top = yes
		}
	}
}

# Company scope (scope:te_pa_home its country). The one place campaign money is spent: SIZE full or half of
# te_pa_cm_cost_<SIZE>_value, through te_pa_spend_funds (out of the investment pool). The Electoral Finance law splits
# it into what goes openly and what goes in secret (te_pa_cm_open_value, _hidden_value); what it buys, in units, goes
# to a party's momentum in a campaign or to an interest group's patronage otherwise (te_pa_cm_pick), and the firm
# wagers on that side (te_pa_bet_place). Its secret part is at risk of exposure at its yearly roll. Sets te_pa_spent.
te_pa_campaign_spend = {
	save_scope_as = te_pa_stake_firm
	set_variable = { name = te_pa_cm_want value = te_pa_cm_cost_$SIZE$_value }
	set_variable = { name = te_pa_cm_open value = te_pa_cm_open_value }
	set_variable = { name = te_pa_cm_hidden value = te_pa_cm_hidden_value }
	te_pa_spend_funds = { AMOUNT = te_pa_cm_spend_value }
	if = {
		limit = { var:te_pa_spent ?= 1 }
		set_variable = { name = te_pa_cm_paid value = te_pa_cm_spend_value }
		set_variable = { name = te_pa_cm_units value = te_pa_cm_units_value }
		set_variable = { name = te_pa_cm_mom value = te_pa_cm_momentum_value }
		set_variable = { name = te_pa_campaign_total value = te_pa_campaign_total_after }
		te_pa_cm_pick = yes
		if = {
			limit = { exists = scope:te_pa_cm_party }
			te_pa_debug_momentum_arm = yes
			scope:te_pa_cm_party = {
				save_scope_as = te_pa_note_party
				add_momentum = te_pa_cm_momentum_value
			}
			te_pa_debug_momentum_after = yes
			scope:te_pa_home = {
				set_variable = { name = te_pa_cm_stage_paid value = scope:te_pa_stake_firm.var:te_pa_cm_paid }
				set_variable = { name = te_pa_cm_stage_mom value = scope:te_pa_stake_firm.var:te_pa_cm_mom }
				te_pa_gen_cmp_add = yes
				remove_variable = te_pa_cm_stage_paid
				remove_variable = te_pa_cm_stage_mom
			}
			te_pa_bet_place = { FORM = 1 }
			te_pa_cm_lines = { OPEN = 43 }
		}
		else_if = {
			limit = { exists = scope:te_pa_cm_ig }
			scope:te_pa_home = {
				set_variable = { name = te_pa_cm_stage value = scope:te_pa_stake_firm.var:te_pa_cm_units }
				te_pa_gen_pat_add = yes
				remove_variable = te_pa_cm_stage
			}
			if = {
				limit = { var:te_pa_cm_hidden > 0 }
				set_variable = { name = te_pa_cm_secret_units value = te_pa_cm_secret_units_after_spend }
				set_variable = { name = te_pa_cm_secret_ig value = scope:te_pa_cm_ig }
			}
			te_pa_bet_place = { FORM = 2 }
			te_pa_cm_lines = { OPEN = 44 }
		}
		if = {
			limit = { var:te_pa_cm_hidden > 0 }
			set_variable = { name = te_pa_cm_secret value = te_pa_cm_secret_after_spend }
		}
		scope:te_pa_home = { te_pa_pol_refresh = yes }
	}
}

# Company scope. Who the money goes to (§ 8.3): in a campaign (te_pa_cm_momentum_form), the party whose members stand
# best on its side, weighed by clout (te_pa_party_side_value), or its executive's interest group's party (§ 5.3) when
# none stands for it, the wager on the party's largest member; otherwise, or with no party to back, the interest
# group that stands best on its side, or its executive's. Saves scope:te_pa_cm_party (momentum) or scope:te_pa_cm_ig
# (patronage), and scope:te_pa_cm_bet_ig, the group the wager is on.
te_pa_cm_pick = {
	clear_saved_scope = te_pa_cm_party
	clear_saved_scope = te_pa_cm_ig
	clear_saved_scope = te_pa_cm_bet_ig
	# Task 5b: a firm whose petition the government took up backs the government's side at the next election
	# (te_pa_cm_gov staged by te_pa_pledge_back_monthly).
	if = {
		limit = { var:te_pa_cm_gov ?= 1 }
		te_pa_cm_pick_gov = yes
	}
	if = {
		limit = {
			owner = { te_pa_cm_momentum_form = yes }
			NOT = { exists = scope:te_pa_cm_party }
			NOT = { exists = scope:te_pa_cm_ig }
		}
		scope:te_pa_home = {
			if = {
				limit = { any_active_party = { te_pa_party_side_value > 0 } }
				ordered_active_party = {
					limit = { te_pa_party_side_value > 0 }
					order_by = te_pa_party_side_value
					position = 0
					check_range_bounds = no
					save_scope_as = te_pa_cm_party
				}
			}
		}
		if = {
			limit = { NOT = { exists = scope:te_pa_cm_party } }
			executive ?= { interest_group ?= { party ?= { save_scope_as = te_pa_cm_party } } }
		}
		scope:te_pa_cm_party ?= {
			ordered_member = {
				order_by = ig_clout
				position = 0
				check_range_bounds = no
				save_scope_as = te_pa_cm_bet_ig
			}
		}
		if = {
			limit = { NOT = { exists = scope:te_pa_cm_bet_ig } }
			clear_saved_scope = te_pa_cm_party
		}
	}
	if = {
		limit = {
			NOT = { exists = scope:te_pa_cm_party }
			NOT = { exists = scope:te_pa_cm_ig }
		}
		scope:te_pa_home = {
			if = {
				limit = { any_interest_group = { te_pa_ig_side_value > 0 } }
				ordered_interest_group = {
					limit = { te_pa_ig_side_value > 0 }
					order_by = te_pa_ig_side_value
					position = 0
					check_range_bounds = no
					save_scope_as = te_pa_cm_ig
				}
			}
		}
		if = {
			limit = { NOT = { exists = scope:te_pa_cm_ig } }
			executive ?= { interest_group ?= { save_scope_as = te_pa_cm_ig } }
		}
		scope:te_pa_cm_ig ?= { save_scope_as = te_pa_cm_bet_ig }
	}
}

# Company scope, a spend made (scope:te_pa_cm_bet_ig the group). The ledger's lines: the open part (verb OPEN, 43 a
# campaign or 44 patronage), and the secret part with its author unknown, each with its sum and the group.
te_pa_cm_lines = {
	clear_saved_scope = te_pa_cm_n
	scope:te_pa_cm_bet_ig ?= { save_scope_value_as = { name = te_pa_cm_n value = te_pa_gen_ig_n } }
	if = {
		limit = { var:te_pa_cm_open > 0 }
		te_pa_cm_line = { VERB = $OPEN$ KNOWN = 1 SIZE = te_pa_cm_open }
	}
	if = {
		limit = { var:te_pa_cm_hidden > 0 }
		te_pa_cm_line = { VERB = $OPEN$ KNOWN = 0 SIZE = te_pa_cm_hidden }
	}
}

te_pa_cm_line = {
	save_scope_as = te_pa_l_actor
	save_scope_value_as = { name = te_pa_l_size value = var:$SIZE$ }
	scope:te_pa_home = { te_pa_ledger_add = { VERB = $VERB$ KNOWN = $KNOWN$ } }
	if = {
		limit = {
			exists = scope:te_pa_l_new
			exists = scope:te_pa_cm_n
		}
		scope:te_pa_l_new = { set_variable = { name = te_pa_l_ig value = scope:te_pa_cm_n } }
	}
}

# Company scope (scope:te_pa_cm_bet_ig the group). The wager (§ 8.3): FORM 1, the party it backed in a campaign, read
# when the election is settled; FORM 2, the group it patronized, read when the group enters government or, if it is
# in government already, after te_pa_bet_months. A newer wager replaces an older one.
te_pa_bet_place = {
	if = {
		limit = { exists = scope:te_pa_cm_bet_ig }
		set_variable = { name = te_pa_bet_ig value = scope:te_pa_cm_bet_ig }
		set_variable = { name = te_pa_bet_form value = $FORM$ }
		set_variable = { name = te_pa_bet_until value = te_pa_bet_until_value }
		set_variable = { name = te_pa_bet_out value = 1 }
		if = {
			limit = { scope:te_pa_cm_bet_ig = { is_in_government = yes } }
			set_variable = { name = te_pa_bet_out value = 0 }
		}
	}
}

# Company scope, the quarter. A patronage wager is settled when its group enters government, or when its time is up.
te_pa_bet_quarter = {
	if = {
		limit = { var:te_pa_bet_form ?= 2 }
		if = {
			limit = {
				OR = {
					AND = {
						var:te_pa_bet_out ?= 1
						var:te_pa_bet_ig ?= { is_in_government = yes }
					}
					te_pa_wait_over = { VAR = te_pa_bet_until }
				}
			}
			te_pa_bet_settle = yes
		}
	}
}

# Company scope. The side it backed is in government: Connections +10; it is not: -5 (§ 8.3, § 4.3: backing the loser
# of an election costs Connections). The wager goes.
te_pa_bet_settle = {
	if = {
		limit = { var:te_pa_bet_ig ?= { is_in_government = yes } }
		set_variable = { name = te_pa_conn value = te_pa_conn_after_bet_win }
	}
	else = {
		set_variable = { name = te_pa_conn value = te_pa_conn_after_bet_lose }
	}
	te_pa_drop = { VAR = te_pa_bet_ig }
	te_pa_drop = { VAR = te_pa_bet_form }

# The sides' law has ended: settle them. A covered law is being enacted and no sides are open: open them on it.
te_pa_sides_check = {

		}

	}

		}
		set_variable = { name = te_pa_side_law value = te_pa_gen_enacting_law_index }
		set_variable = { name = te_pa_side_for value = 0 }
		set_variable = { name = te_pa_side_against value = 0 }
	}
}

# The enactment the sides were on has ended. Whether it passed is read first (te_pa_gen_law_n_in_force); then
# te_pa_side_law goes, before anything is paid, so the settlement runs once for an ended law (a second check finds no
# sides). Each firm that spent on the winning side gains te_pa_side_conn_win Connections, each on the losing side
# loses te_pa_side_conn_lose; the largest on each side gets the ledger's line (verbs 41 and 42); the sides go.
te_pa_sides_settle = {
	save_scope_as = te_pa_side_home
	set_variable = { name = te_pa_side_passed value = 0 }
	if = {
		limit = { te_pa_gen_law_n_in_force = { VAR = te_pa_side_law } }
		set_variable = { name = te_pa_side_passed value = 1 }
	}
	set_variable = { name = te_pa_side_done value = var:te_pa_side_law }
	remove_variable = te_pa_side_law
	every_company = {
		limit = { has_variable = te_pa_side_of }
		if = {
			limit = { te_pa_side_won = yes }
			set_variable = { name = te_pa_conn value = te_pa_conn_after_side_win }
		}
		else = {
			set_variable = { name = te_pa_conn value = te_pa_conn_after_side_lose }
		}
		te_pa_drop = { VAR = te_pa_side_of }
		te_pa_drop = { VAR = te_pa_side_sign }
		te_pa_drop = { VAR = te_pa_side_spent }
	}
	if = {
		limit = { var:te_pa_side_passed ?= 1 }
		te_pa_side_line = { TOP = te_pa_side_top_for_1 TOTAL = te_pa_side_for VERB = 41 }
		te_pa_side_line = { TOP = te_pa_side_top_against_1 TOTAL = te_pa_side_against VERB = 42 }
	}
	else = {
		te_pa_side_line = { TOP = te_pa_side_top_against_1 TOTAL = te_pa_side_against VERB = 41 }
		te_pa_side_line = { TOP = te_pa_side_top_for_1 TOTAL = te_pa_side_for VERB = 42 }
	}
	te_pa_sides_clear = yes
	te_pa_drop = { VAR = te_pa_side_passed }
	te_pa_drop = { VAR = te_pa_side_done }
}

# A settled side's line, from its largest firm (TOP), with the side's money (TOTAL) and the law, while it spent.
te_pa_side_line = {

			has_variable = $TOTAL$

		save_scope_value_as = { name = te_pa_l_size value = var:$TOTAL$ }

		if = {
			limit = { exists = scope:te_pa_l_new }
			scope:te_pa_l_new = { set_variable = { name = te_pa_l_law value = scope:te_pa_side_home.var:te_pa_side_done } }
		}
	}
}

# and its law (the law table's number) or its good (by index) and the import tariff level it asks for.
te_pa_pt_pick = {

		}
		set_variable = { name = te_pa_move_ask value = 3 }

				te_pa_v_in1_tariff > 0
			}

			set_variable = { name = te_pa_move_level value = te_pa_pt_ask_in1_level }
		}
		else = {
			set_variable = { name = te_pa_move_good value = var:te_pa_g_in2_good }
			set_variable = { name = te_pa_move_level value = te_pa_pt_ask_in2_level }
		}
	}
	else_if = {

			var:te_pa_goal ?= 1

		set_variable = { name = te_pa_move_ask value = 4 }
		set_variable = { name = te_pa_move_law value = te_pa_gen_law_index_law_trust_busting }
	}
	else_if = {
		limit = {
			var:te_pa_goal ?= 2

			var:te_pa_goal ?= 4
			te_pa_pt_ask_law = yes
		}
		set_variable = { name = te_pa_move_ask value = 1 }
		set_variable = { name = te_pa_move_law value = var:te_pa_g_law_best_law }

	# Task 6: Labor Peace's labor law, ask 5, goes here (with its te_pa_pt_can_ask branch).

te_pa_pledge_monthly = {
	save_scope_as = te_pa_pl_firm
	scope:te_pa_home = {
		te_pa_tf_clear = yes
		if = {
			limit = { scope:te_pa_pl_firm = { has_variable = te_pa_pl_law } }
			set_variable = { name = te_pa_tf_law value = scope:te_pa_pl_firm.var:te_pa_pl_law }
		}
		if = {
			limit = { scope:te_pa_pl_firm = { has_variable = te_pa_pl_good } }
			set_variable = { name = te_pa_tf_good value = scope:te_pa_pl_firm.var:te_pa_pl_good }
		}
		if = {
			limit = { scope:te_pa_pl_firm = { has_variable = te_pa_pl_level } }
			set_variable = { name = te_pa_tf_level value = scope:te_pa_pl_firm.var:te_pa_pl_level }
		}
	}
	if = {
		limit = { var:te_pa_pl_kind ?= 1 }
		te_pa_pledge_law_monthly = yes
	}
	else_if = {
		limit = { var:te_pa_pl_kind ?= 2 }
		te_pa_pledge_tariff_monthly = yes
	}
	scope:te_pa_home = { te_pa_tf_clear = yes }
	te_pa_row_sync = yes
}

# A law: begun (enacted now, or in force: a line, 52, and the free speed), started by an AI government enacting
# nothing, broken at the deadline, or a player reminded six months before it. Once begun, the firm speeds it for
# nothing once a year (its own count) while it is enacted; when the enactment ends, passed or not, the pledge is
# kept and done.
te_pa_pledge_law_monthly = {
	if = {
		limit = { NOT = { has_variable = te_pa_pl_begun } }
		if = {
			limit = { scope:te_pa_home = { te_pa_pl_law_enacting = yes } }
			set_variable = { name = te_pa_pl_begun value = 1 }
			te_pa_pledge_line = { VERB = 52 }
			te_pa_pledge_speed = yes
		}
		else_if = {
			limit = { scope:te_pa_home = { te_pa_gen_law_n_in_force = { VAR = te_pa_tf_law } } }
			te_pa_pledge_line = { VERB = 52 }
			te_pa_pledge_drop = yes
		}
		else_if = {
			limit = {
				NOT = { has_variable = te_pa_pl_started }
				scope:te_pa_home = {
					is_ai = yes
					NOT = { enacting_any_law = yes }
					te_pa_gen_law_n_open = { VAR = te_pa_tf_law }
				}
			}
			te_pa_pledge_start = { VAR = te_pa_tf_law }
		}
		else_if = {
			limit = { te_history_month_index >= var:te_pa_pl_until }
			te_pa_pledge_break = { VERB = 54 }
		}
		else_if = {
			limit = {
				NOT = { has_variable = te_pa_pl_reminded }
				te_pa_pl_left_value <= te_pa_pl_due_months
				scope:te_pa_home = { is_ai = no }
			}
			set_variable = { name = te_pa_pl_reminded value = 1 }
			save_scope_as = te_pa_note_firm
			scope:te_pa_home = { post_notification = te_pa_pledge_due }
		}
	}
	else_if = {
		limit = { scope:te_pa_home = { te_pa_pl_law_enacting = yes } }
		if = {
			limit = { te_pa_pl_speed_due = yes }
			te_pa_pledge_speed = yes
		}
	}
	else = {
		te_pa_pledge_drop = yes
	}
}

# A tariff: the Tax Code's customs option or the loss of the market makes the pledge lapse (57); a level that no
# longer holds is set again by an AI government, or by anyone in the month after the set (te_pa_pl_tariff_reassert:
# a set the engine kept back is tried again once before it counts), and otherwise breaks the pledge (55); five
# years held, it is kept (53) and done.
te_pa_pledge_tariff_monthly = {
	if = {
		limit = { scope:te_pa_home = { te_pa_tariffs_settable = no } }
		te_pa_pledge_line = { VERB = 57 }
		te_pa_pledge_drop = yes
	}
	else_if = {
		limit = { te_pa_pl_tariff_held = no }
		if = {
			limit = { te_pa_pl_tariff_reassert = yes }
			scope:te_pa_home = { te_pa_gen_tariff_set = { VAR = te_pa_tf_good LEVEL = te_pa_tf_level } }
		}
		else = {
			te_pa_pledge_break = { VERB = 55 }
		}
	}
	else_if = {
		limit = { te_history_month_index >= var:te_pa_pl_until }
		te_pa_pledge_line = { VERB = 53 }
		te_pa_pledge_drop = yes
	}
}

# A pledge broken counts as a refusal (§ 8.4): the pledge goes first, so the check runs once a pledge; then
# Grievance +1, Connections -10, the line (VERB 54 a law, 55 a tariff) and a player's notice.
te_pa_pledge_break = {
	te_pa_pledge_drop = yes
	change_variable = { name = te_pa_griev add = 1 }
	set_variable = { name = te_pa_conn value = te_pa_conn_after_pt_refuse }
	te_pa_pledge_line = { VERB = $VERB$ }
	if = {
		limit = { scope:te_pa_home = { is_ai = no } }
		save_scope_as = te_pa_note_firm
		scope:te_pa_home = { post_notification = te_pa_pledge_broken }
	}
}

# A pledge's line (52-57), with its law or good from the staging (te_pa_tf_law, te_pa_tf_good).
te_pa_pledge_line = {
	save_scope_as = te_pa_l_actor
	scope:te_pa_home = { te_pa_ledger_add = { VERB = $VERB$ KNOWN = 1 } }
	if = {
		limit = { exists = scope:te_pa_l_new }
		scope:te_pa_l_new = {
			if = {
				limit = { scope:te_pa_home = { has_variable = te_pa_tf_law } }
				set_variable = { name = te_pa_l_law value = scope:te_pa_home.var:te_pa_tf_law }
			}
			if = {
				limit = { scope:te_pa_home = { has_variable = te_pa_tf_good } }
				set_variable = { name = te_pa_l_good value = scope:te_pa_home.var:te_pa_tf_good }
			}
		}
	}
}

# The free speed on a pledged law (§ 8.4: Task 5a's speed without its cost): progress on the law being enacted,
# once a year a pledge on its own count, which neither the firm's yearly speed nor the law's (te_pa_can_speed)
# counts.
te_pa_pledge_speed = {
	set_variable = { name = te_pa_pl_speed_month value = te_history_month_index }
	scope:te_pa_home = { add_law_progress = te_pa_speed_progress }
	te_pa_pledge_line = { VERB = 56 }
}

# The pledge's variables go (kept, broken, lapsed, the firm disbanded, the teardown). The backing at the next
# election (te_pa_pl_back) is apart from it and stays.
te_pa_pledge_drop = {
	te_pa_drop = { VAR = te_pa_pl_kind }
	te_pa_drop = { VAR = te_pa_pl_law }
	te_pa_drop = { VAR = te_pa_pl_good }
	te_pa_drop = { VAR = te_pa_pl_level }
	te_pa_drop = { VAR = te_pa_pl_dir }
	te_pa_drop = { VAR = te_pa_pl_until }
	te_pa_drop = { VAR = te_pa_pl_begun }
	te_pa_drop = { VAR = te_pa_pl_started }
	te_pa_drop = { VAR = te_pa_pl_speed_month }
	te_pa_drop = { VAR = te_pa_pl_reminded }
	te_pa_drop = { VAR = te_pa_pl_set_month }
}

# Country scope. The pledge's staging goes.
te_pa_tf_clear = {
	te_pa_drop = { VAR = te_pa_tf_law }
	te_pa_drop = { VAR = te_pa_tf_good }
	te_pa_drop = { VAR = te_pa_tf_level }
}

# Company scope (scope:te_pa_home its country). At the next election campaign after a petition was taken up, the
# firm puts campaign money behind the government's side, in full, once (te_pa_campaign_spend, the one spend site,
# with te_pa_cm_gov staged for te_pa_cm_pick); with no campaign in te_pa_pl_back_months, the mark goes.
te_pa_pledge_back_monthly = {
	if = {
		limit = { te_pa_wait_over = { VAR = te_pa_pl_back_until } }
		te_pa_drop = { VAR = te_pa_pl_back }
		te_pa_drop = { VAR = te_pa_pl_back_until }
	}
	else_if = {
		limit = {
			owner = { te_pa_cm_momentum_form = yes }
			te_pa_cm_allowed = yes
			te_pa_can_afford = { AMOUNT = te_pa_cm_cost_full_value }
		}
		set_variable = { name = te_pa_cm_gov value = 1 }
		te_pa_campaign_spend = { SIZE = full }
		remove_variable = te_pa_cm_gov
		if = {
			limit = { var:te_pa_spent ?= 1 }
			te_pa_drop = { VAR = te_pa_pl_back }
			te_pa_drop = { VAR = te_pa_pl_back_until }
			te_pa_row_sync = yes
		}
	}
}

# Company scope, inside te_pa_cm_pick. The government's side: in a campaign, the active party whose members in
# government hold the most clout, the wager on its largest member; otherwise the governing group with most clout.
te_pa_cm_pick_gov = {
	if = {
		limit = { owner = { te_pa_cm_momentum_form = yes } }
		scope:te_pa_home = {
			if = {
				limit = { any_active_party = { any_member = { is_in_government = yes } } }
				ordered_active_party = {
					limit = { any_member = { is_in_government = yes } }
					order_by = te_pa_party_gov_clout
					position = 0
					check_range_bounds = no
					save_scope_as = te_pa_cm_party
				}
			}
		}
		scope:te_pa_cm_party ?= {
			ordered_member = {
				order_by = ig_clout
				position = 0
				check_range_bounds = no
				save_scope_as = te_pa_cm_bet_ig
			}
		}
		if = {
			limit = { NOT = { exists = scope:te_pa_cm_bet_ig } }
			clear_saved_scope = te_pa_cm_party
		}
	}
	if = {
		limit = { NOT = { exists = scope:te_pa_cm_party } }
		scope:te_pa_home = {
			if = {
				limit = { any_interest_group = { is_in_government = yes } }
				ordered_interest_group = {
					limit = { is_in_government = yes }
					order_by = ig_clout
					position = 0
					check_range_bounds = no
					save_scope_as = te_pa_cm_ig
				}
			}
		}
		scope:te_pa_cm_ig ?= { save_scope_as = te_pa_cm_bet_ig }
	}
}

# Country scope, the event (scope:te_pa_mv_firm the petitioner). The record's three largest on each side, saved for
# the event's tooltips (te_pa_pt_sides_tt).
te_pa_pt_save_sides = {
	var:te_pa_pt_top_for_1 ?= { save_scope_as = te_pa_pt_f1 }
	var:te_pa_pt_top_for_2 ?= { save_scope_as = te_pa_pt_f2 }
	var:te_pa_pt_top_for_3 ?= { save_scope_as = te_pa_pt_f3 }
	var:te_pa_pt_top_against_1 ?= { save_scope_as = te_pa_pt_a1 }
	var:te_pa_pt_top_against_2 ?= { save_scope_as = te_pa_pt_a2 }
	var:te_pa_pt_top_against_3 ?= { save_scope_as = te_pa_pt_a3 }
}

# Country scope, an option of the end event (te_pa_pt_save_sides run in its immediate). Who stood for and against
# the petition and what each spent, a line a firm: § 8.4's "a player sees who is for and who is against before
# answering", in the tooltip.
te_pa_pt_sides_tt = {
	if = {
		limit = { te_pa_v_pt_for > 0 }
		custom_tooltip = te_pa_pt_for_tt
		if = { limit = { exists = scope:te_pa_pt_f1 } custom_tooltip = te_pa_pt_f1_tt }
		if = { limit = { exists = scope:te_pa_pt_f2 } custom_tooltip = te_pa_pt_f2_tt }
		if = { limit = { exists = scope:te_pa_pt_f3 } custom_tooltip = te_pa_pt_f3_tt }
	}
	if = {
		limit = { te_pa_v_pt_against > 0 }
		custom_tooltip = te_pa_pt_against_tt
		if = { limit = { exists = scope:te_pa_pt_a1 } custom_tooltip = te_pa_pt_a1_tt }
		if = { limit = { exists = scope:te_pa_pt_a2 } custom_tooltip = te_pa_pt_a2_tt }
		if = { limit = { exists = scope:te_pa_pt_a3 } custom_tooltip = te_pa_pt_a3_tt }
	}
	if = {
		limit = {
			te_pa_v_pt_for <= 0
			te_pa_v_pt_against <= 0
		}
		custom_tooltip = te_pa_pt_no_sides_tt
	}
}

# Country scope. The hand-written half of the generated te_pa_gen_tariff_set: the good GOOD gets the import tariff
# level LEVEL (a country variable, 0 to 3), the way the Tax Code's customs sync sets one (set_import_tariff_level),
# unless a treaty bars a tariff on the good (a level of 0, none, every treaty allows). Reached only behind
# te_pa_tariffs_settable, which defers to the Tax Code's customs option.
te_pa_tariff_set_good = {
	if = {
		limit = { var:$LEVEL$ ?= 0 }
		set_import_tariff_level = { goods = g:$GOOD$ level = no_tariffs_or_subventions }
	}
	else_if = {
		limit = { NOT = { te_bulk_tariff_barred = { GOOD = $GOOD$ ARTICLE = no_tariffs } } }
		if = {
			limit = { var:$LEVEL$ ?= 1 }
			set_import_tariff_level = { goods = g:$GOOD$ level = low_tariffs }
		}
		else_if = {
			limit = { var:$LEVEL$ ?= 2 }
			set_import_tariff_level = { goods = g:$GOOD$ level = high_tariffs }
		}
		else_if = {
			limit = { var:$LEVEL$ ?= 3 }
			set_import_tariff_level = { goods = g:$GOOD$ level = max_tariffs }
		}
	}
}
