# State Panel and Nation Tab

Part of the [mod systems reference](../mod_systems.md), which indexes every system.

## State Panel GUI Enhancements

Custom `state_panel_status_item_small` tiles added to `gui/states_panel.gui` for mod-specific state info. Each tile's name is the concept alone; its readings are aligned label/value rows in the tile's `extra_widget`, and the detail is in the tooltip:

| Widget | Icon | Concept | Rows | Tooltip |
|---|---|---|---|---|
| **Homeland Dynamics** | `state_homelands.dds` | `concept_homeland_dynamics` | Creation / removal sections, each shown only when it applies: per-culture progress bars and live status; one pause line, or one line when nothing here can change | Effective thresholds, annual progress, speed modifiers, pause/reset rules and what enables homeland changes (also the hover on the unlock pause line) |
| **Arable Land** | `wheat_farm.dds` | `concept_arable_land` | Total, regional additions, multiplier % | Geographic base, `GetValueWithBreakdownFor('state_arable_land_mult')` |
| **Migration Crowding** | `population.dds` | `concept_migration_crowding` | Population, threshold, ratio (+ a bar to the 10x knee), pull penalty | Threshold breakdown (arable land, Urban Engineering, tolerance), curve explanation |
| **Local Climate** | `state_status_icons/local_climate.dds` | `concept_local_climate` | Hot days (°C), Humidity, Winter (°C), Water, Malaria, and Comfort, read from the region's climate record (`te_climate_*`, `local_climate_generated.txt`) in `te_state_climate_row`s; a region with no record says so | What each reading measures ([Local Climate](local_climate.md)) |
| **Solar Collector** | `space_elevator.dds` | `concept_solar_collector_array` | Available, generated | Active / reserved / queued |

Both modifier rows hide the six | What the score and the inheritance law give a state |
| **Seabed Licences** | `building_ocean_mine.dds` | `concept_seabed_licence` | This state's: its basin, the licences on its Deep-Sea Mine levels, long-haul ones (when any), our unused claims in its basin, and what it adds to our claim weight there (`te_seabed_state_weight_disp`, `te_seabed_compute_weights`' terms for one state, × the policy factor); the basin, claims and weight rows wait for a state's first basin. - **Widget library: `gui/te_state_panel_widgets.gui`.** `states_panel.gui` is a full-file override re-merged on every vanilla patch, so the mod's own types live there and the override holds only instances.
  - `te_state_stat_row`: a fixed-width label column plus a fixed-width value column with its text anchored right, so a stack of rows ends at one x.
  - `te_state_tile_row` sizes it for a tile's 160 px text column (96 + 60); `te_state_tile_word_row` for a word value such as a basin's name (60 + 96); `te_state_wide_row` drops the icon slot for headers and footers.
  - `te_state_stat_bar`: a 4 px headroom bar, a bare `progressbar` fed by a 0–100 `*_fill_pct` script value that carries its own cap.
- **Tourism card** (`te_state_tourism_card`): a 530 px card between the population block and the status grid.
  - It sits outside the grid because the grid is `wrap_count = 2` over 260 px tiles, and anything that isn't exactly one tile breaks its rows.
  - Output column: base appeal (net of the monuments' share; its tooltip names it), cities (with world rank), monuments. Throughput column: excess infrastructure, art, parks, Skyscraper. Each capped source has a bar toward its cap (excess infrastructure toward its +100% ceiling, half full at 30,000); the caps are in the `tourism_fill_*_pct` values at the end of `common/script_values/tourism.txt`.
  - Footer "All modifiers": `State.GetModifier.GetValueWithBreakdownFor('goods_output_tourism_mult')` and `('building_tourism_industry_throughput_add')`. These also carry airports (+0.15 per level on `pm_airport`/`pm_spaceport`), highways (+0.05 on the civil, electric civil and autonomous methods, +0.025 on the industrial and electric industrial ones, all in `state_modifiers`), decrees, pollution, grand monuments and so on, and lag the scripted sources by up to a month.
  - Per-source tooltips `te_state_tourism_*_tt` state each tier schedule.
- **Loc keys:** `TE_STATE_*_STATUS` (tile title), `TE_STATE_*_ROW_*` / `TE_STATE_POINTS_ROW_*` (row labels), `TE_STATE_*_TT` (tooltip) and `te_state_tourism_*` in `localization/english/te_miscellaneous_l_english.yml`.
- **Script values for GUI:** `arable_land_total`, `arable_land_base`, `arable_land_from_modifiers`, `arable_land_mult_pct`, `migration_crowding_pull_pct`, `migration_crowding_threshold_pop`, `migration_crowding_fill_pct`, `te_homeland_annual_progress`, `solar_*`, `antimatter_*` in `common/script_values/extra_script_values.txt`; `tourism_fill_*_pct` in `common/script_values/tourism.txt`; the seabed tile's `te_seabed_state_*` reads (the tile's state rows, after `te_seabed_tile_shown`) in `common/script_values/te_global_commons_seabed_values.txt`; `gui_state_wealth_modifier_count` beside `gui_state_hidden_modifier_count` in `common/script_values/gui_chart_script_values.txt`.
- **Concepts:** Defined in `common/game_concepts/extra_concepts.txt`, with textures for hoverable tooltip links. The tourism rows label with `concept_tourism_*` and reuse those concept textures as row icons.
- **Pattern:** Use `[concept_X]` for hoverable concept links, `[State.GetModifier.GetValueWithBreakdownFor('modifier_key')]` for modifier breakdowns, and `[State.MakeScope.ScriptValue('sv_name')]` for computed values. A value cell that shows one expression inlines it as `raw_text = "#v [...]#!"`.

## Nation Tab

Spec: `docs/superpowers/archive/specs/2026-10-17-national-modifiers-tab-design.md`. The first tab of the Timeline Extended window (`gui/te_systems_window.gui`), always open: no journal entry, no game rule, so the window's launcher has no rule gate either. Everything reads the player's country through `GetPlayer`.

- **What it shows** (`gui/te_nation_tab.gui`): five overview boxes (Override Capacity's strongest Forceful Legislation option, Wealth Concentration and its target, Construction Cost, Global Technology, Judicial Independence and its ceiling), then five open sections, Governance, Society, Economy, Science and Space, International, each its score rows and then its type rows, then Where These Come From, collapsed, and How the Nation Works, a link to the Help page (`te_nation_help_popup`; 2026-11-02; the tab has no header, so no "?"). Rows: Legislative Override Capacity (`GetValueWithBreakdownFor('country_legislative_override_capacity_add')`, a bar from 0 to +30 with lines at 0, 2 and 4 (every value below 0 plays the same, so the bar starts there and the figure carries a negative value; 30 is about the most a country holds at once; `te_nation_override_bar`), and the strongest Forceful Legislation option open, which `te_nation_override_tier` reads from the capacity and the authority produced, as the event's triggers do), Judicial Independence once the score is seeded (`te_jud_display` heading for `te_jud_ceiling`, the ceiling's two sources by breakdown, and the courts' four scaled modifiers under it; the Court Overhaul is timed and stays in the list), the Algorithmic Mandate under Algorithmic Governance, Wealth Concentration, Construction Cost (`te_cc_scaling_factor` − 1, the scaling's own effect; its tooltip breaks a point's cost into factors, § Construction Cost Scaling), Private Construction while either of its modifiers is in force, Global Technological Development (`var:te_global_tech_spread_applied`, which `tech_spread_on_action` sets beside the modifier, so the GUI never reruns the 54-technology sweep). The rows' values are in `common/script_values/te_nation_values.txt`.
- **The type rows** (#1030): one per modifier type the tab's modifiers carry, "Arable Land: +45%", the type's own name and `GetValueWithBreakdownFor`, so the hover lists every source (technologies, laws, institutions, principles, timed modifiers and the tab's own, a scaled one with its multiplier), and the type's `_desc` on the row's hover. Grouped under subheadings, and sectioned by what a type affects, not which system grants it: one national total can't repeat in four sections, so Prestige is International's even where a space milestone grants it. A row shows while the country holds one of the tab's modifiers that carries it (`te_nation_type_<type>_count`), not whenever the total is non-zero, which would make the tab a copy of the country panel's Modifiers tab. A `state_`, `building_`, `interest_group_` or `character_` row is the country's contribution, and its hover says the scope's own sources are in its panel (the owner, 2026-10-17: the country's modifier holds those fields). `_bool` types are status lines ("In force", `GetFullEntryDescFor` on hover). 35 types get no row: a score row, the Banking tab or their own modifier shows them (`NOT_A_ROW`).
- **The lists** are the player's own timed modifiers, filtered by name (gotcha #40 of `gui_modding_guide.md`): icon, name, the modifier's own tooltip, so the engine renders the effects at their current scale. A score row's own ("what it gives now") sit under it; the sections' lists sit in Where These Come From, collapsed, under each section's name. A section with nothing to show draws nothing.
- **The registry** (`scripts/generators/gen_nation_tab.py`) places every static modifier script adds without a duration, parameterized names expanded from their callers (700 on 2026-10-17; a duration of `-1` is forever, so `days = -1` counts as permanent): `SECTIONS` (a section's list), `ROWS` (shown under a row), `KEEP_IN_LIST` (overrides, each with its reason: `nuclear_power` until it moves to its entry, the covert operations' effects on a target, debug modifiers), `NOT_ON_COUNTRY` (lands on an entry, a state, a building, an interest group or a power bloc). A second registry places the types those modifiers carry: `TYPE_ROWS` (section, group, types), `STATUS_ROWS` (bools) and `NOT_A_ROW` (with what shows it). The budget breakdown's sources (`gen_budget_breakdown.SOURCES`) are hidden with no row: the Budget panel itemizes them. An entry may name a family with one `*`; an exact name wins.
- **Generated, never hand-edited:** `gui/te_nation_generated.gui` (the filters `te_nation_hidden_filter`, `te_nation_list_<section>`, `te_nation_row_<row>`, and the type rows `te_nation_types_<section>`), `common/script_values/te_nation_generated_values.txt` (their `has_modifier` counts, and each type row's, group's and section's), `localization/english/te_nation_generated_l_english.yml` (each row's text and hover, splicing the type's name and `_desc`; organize_loc's `NATION_GENERATED`) and `gui/00_te_country_panel_information.gui`.
- **The country panel** (every country's, the player's and the AI's): `00_te_country_panel_information.gui` redefines vanilla's `country_panel_information_content` (gotcha #30), copied from `test_fixtures/vanilla_gui/country_panel.gui` with three `### MOD: Nation tab` blocks: the item takes `te_nation_hidden_filter`, the list `ignoreinvisible` and shows only while the country has more timed modifiers than `gui_country_hidden_modifier_count`, and under it a line counts the ones it leaves out ("Lasting modifiers not listed: 12"), with a goto into the window's Nation tab for the player's own country (2026-10-27 audit, NAT-1). The MODIFIERS header keeps vanilla's test, since the list or the line shows whenever the country has a modifier. Hidden isn't gone: breakdown tooltips still name each source. If the redefinition loses to vanilla's in game, the fallback is a full-file `country_panel.gui`.
- **Adding a permanent modifier:** one registry line, `python3 scripts/generators/gen_nation_tab.py`, commit its four outputs. `test_nation_tab.py` fails while a candidate has no line or two, a line places nothing, an output is stale, or a hidden name shares its display name with one the list keeps (the filter matches names). A field the tab hasn't seen before needs a type registry line too, and fails the same way until it has one.
- **Judgment calls for the owner** (each one line to move): the monetary bands, the tax code's interest-group views and the colonial programmes under Economy; the colonial empire's endings and the Imperial Federation and Mandate System under Economy; the nuclear taboo and the Foreign Cultural Benchmark (`cultural_hegemony_foreign_benchmark`, added to the country by the hegemony entry's pulse) under International; the covert effects and `gm_name_carrier_slot` kept in the list.
- **Play-test list:** `docs/testing/nation-tab-playtest.md`.

## Timeline Extended Window Tabs

Spec: `docs/superpowers/specs/2026-11-02-te-window-wide-mode-design.md` (§§ 9.1, 9.3). The window (`gui/te_systems_window.gui`) keeps its frame, its launcher and its root by hand. Everything else comes from one registry.

- **The registry** (`TABS` in `scripts/generators/gen_te_systems_window.py`): per tab, its key (the stored `te_systems_window_tab` value), its strip, its label and tooltips, its open and on-strip gates, the scripted GUI whose checklist a grayed tab shows, and its body type. Nation is first, and the fallback. `SR_MILESTONES` lists the Space Race's nine entries.
- **Generated, never hand-edited:** `gui/te_systems_window_generated.gui` holds the selection templates, the strips (`te_systems_window_strips_narrow`), the scroll area's column of tab mounts (`te_systems_window_tabs_narrow`) and the Space Race's per-milestone frames (`te_sr_window_milestones`). The generator is manual, not post-load, and `--check` reports a stale file.
- **The tab frame** (`te_system_tab_frame`, `gui/te_system_tab_widgets.gui`) has a block for each part: the header, the gate on a parent of the `GetPlayerJournalEntry` datacontext, the fixed 520 column, the content and Open Journal Entry. A system's body type fills them: `te_gm_tab_body`, `te_ce_tab_body` and `te_seabed_tab_body`, each in its system's file. Each body declares a layout block (`te_<system>_tab_layout`) for a wide mount to override. The Space Race's `te_sr_tab_body` is a plain column: the milestones, then Space Powers and Orbit, then How the Space Race Works.
- **The mirrored tabs** (2026-11-02, strips 2 and 3): the ten system tabs that live in vanilla panels, Banking, Tax Code and Budget Breakdown (Budget), Strategic Reserve and Global Warming (Market), Demographics (Population), Cultural Hegemony (Society), United Nations (Diplomacy), Nuclear Weapons and Covert Warfare (Military). Each host tab and the window's mount one body type (`te_banking_tab_body`, `te_tax_tab_body`, `te_st_res_tab_body`, `te_gw_tab_body`, `te_ch_tab_body`, `te_un_tab_body`, `te_nuclear_tab_body`, `te_covert_tab_body`, in each system's layout file), so the two can't drift. The host keeps its outer flowcontainer and anything that reads its panel: the Market panel fills Global Warming's `te_gw_tab_market_view` (its own market's view and another market's) and the Reserve's `te_st_res_tab_elsewhere` and `te_st_res_tab_gate` (the other-market note and the own-market test); the window shows the bodies' defaults, the player's own market. Budget Breakdown mounts `te_budget_breakdown_panel`, always open. Demographics mounts `te_demog_window_body`, the Population tab's sections less the strata incomes (they read `PopsOverviewPanel`), with the player's country as context. The registry reuses each host's gates and, where it fits the window, its tooltip; names are the entries'. Tax Code's draft and bill summaries sit in both frames' `fixed_bottom` (`te_systems_window_tax_footer`), as in Budget's.
- **Two frames:** the side panel (`te_systems_window_panel`, `default_block_window`) and the full screen (`te_systems_window_panel_wide`, on `te_fullscreen_block_window`, generated from vanilla's `fullscreen_block_window`). The client-side key `te_systems_window_wide` picks one, and a text button in each frame's `fixed_top` sets or clears it. The full-screen frame's strips sit side by side at their narrow width (`te_systems_window_strips_wide`), and its column is 1,620 wide (`te_systems_window_tabs_wide`). Each mount there holds the tab's wide layout (the `Tab`'s `wide`: `te_<system>_wide_sections` in its system's file, or for Demographics the Census Data window's `te_demog_browser_sections`), the narrow layout's sections in columns of 520 (`te_ui_columns_three` or `te_ui_columns_two`): it fills the body's layout block, or replaces the body for a tab that declares none (`layout=None`). While the full-screen frame draws, the HUD parts vanilla hides under its own full screens hide too (the outliner, the "Paused" button, the lens toolbar): `gui/00_te_fullscreen_hide.gui` redefines vanilla's three visibility templates with a term that is the window root's `visible` and the frame's, so it follows the window by every route that closes it (`test_te_fullscreen_hud.py`).
- **Adding a tab:** write its body type and its wide layout, add a `Tab` line and its loc (label, tooltip, locked line), run `python3 scripts/generators/gen_te_systems_window.py`, and commit the generated file. `test_te_systems_window.py` fails while that file is stale or a tab has no wide layout, and evaluates the tab selection for each stored value. `test_te_system_tab_bodies.py` checks the frame and the bodies, and that nothing a tab's body or wide layout reaches, through instances and base types, reads a host panel. The system's layout test holds the wide layout to the narrow one with `gui_test_helpers.assert_wide_matches_narrow` (`docs/guides/python_tools.md`).
