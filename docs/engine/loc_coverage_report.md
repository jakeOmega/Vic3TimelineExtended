entity's opening line:

## Scope notes

- Only flags **mod-introduced** entities (present in mod_parsers but not base_parsers). Vanilla overrides inherit vanilla loc and are skipped — the failure mode this audit catches is unlocalized net-new mod entities.
- Skips Scripted Effects/Triggers, On Actions (code-only), Script Values (mostly arithmetic). Add categories to `_REQUIREMENTS` if reports surface a gap.
- Skips entities whose opening-line `<name> = {` couldn't be located in mod source (inline-defined or relocated files) — preferred over misattributing file:line.
