A set does not count when it can only run with the variable already set: it sits in a block whose `limit` has `has_variable = X`, `exists = var:X` or a read of `var:X`, on the same object. The reset after a batch, `if = { limit = { var:x >= 6 } set_variable = { name = x value = 0 } }`, is the usual one. Nor does the flag form, `set_variable = x`, which stores no number. Only a `limit` in the set's own body is read: a guard held by a helper's caller, or inside a scripted trigger or an event's `trigger`, is not seen.

Fix: set the variable where its owner begins (`set_variable = { name = x value = 0 }`), or just before the change: `if = { limit = { NOT = { has_variable = x } } set_variable = { name = x value = 0 } }`.
