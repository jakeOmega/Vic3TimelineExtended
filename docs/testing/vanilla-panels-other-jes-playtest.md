# Additions to vanilla panels and the entries with no panel: play-test list

The 2026-10-27 GUI audit's slice VAN / JE (`docs/audits/gui_audit/vanilla_panels_other_jes.md`, issue #1212) passed the
offline gate only: `test_vanilla_panel_additions.py`, `test_tax_code_bypass.py`, the GUI lint and the audits. What
only the game can show is below. In-game checks don't gate a merge (CLAUDE.md, "In-game checks"); work through these
the next time the game is up.

## How to run

- **Deploy** per CLAUDE.md, "Play-testing unmerged work" (or from `main` once merged).
- **Where to look.** The state view's status tiles (a state of your own and one of another country's), the
  construction panel's Construction Market section, and the journal entries named in each row.
- **Logs.** Read `debug.log` first, then `error.log`. Search both for `states_panel.gui`, `construction_panel.gui`,
  `te_state_panel_widgets.gui`, `Failed to fetch variable` and the loc keys named below.
