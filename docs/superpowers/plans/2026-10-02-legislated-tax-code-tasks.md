> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement packages 1–5 of the [legislated tax code plan](2026-09-30-legislated-tax-code.md) behind a new campaign-setup game rule: a canonical enacted fiscal code applied through a carrier law and generated rate amendments, a month-exact scheduler, migration from vanilla tax laws, a draft → bill → approval → commencement lifecycle with an interest-group passage fallback, first policy obligations, and a Budget-tab / journal-entry UI.

**Architecture:** Canonical state lives in bounded country variables (`te_tax_*`). One collection writer derives native state (carrier-law amendments, taxed goods, relief modifiers, tariff levels, pinned tax level) from it. A global `on_monthly_pulse` dispatch runs the scheduler once per calendar month per country. A Python generator emits the repetitive per-index / per-good script. The UI is a fifth Budget tab plus a journal entry that compose the same widget types.

**Tech Stack:** Victoria 3 (1.14.5) Paradox script (`common/`, `events/`, `gui/`, `localization/`), Python 3.11/3.12 tooling and `unittest` structural tests.

2. **Rule-off campaigns changed by this branch:** any hook, INJECT, generator output or GUI gate that alters behaviour when `te_tax_code_on` is false. Task 2 and Task 9 tests assert the gates are present and positive.
3. **Opening the UI mutates state:** every GUI read goes through guarded script values; no sgui `is_shown`/`is_valid` or display value writes variables or sweeps the world. Task 7 and Task 8 tests assert display values contain no effects and no `every_`/`any_` world iterators.
4. **Loser-only variables resurrecting deleted provisions after a civil war:** tokens are never removed; the win repair rebuilds collection from the winner's variables only. Task 10 tests assert no `remove_variable` on canonical tokens and that both hooks are wired.
5. **A native control silently changing collections:** player GUI toggles outside Budget, `activate_law` of a vanilla tax law, AI tax-level changes. Task 9 tests count every gated site and every re-assert hook.
