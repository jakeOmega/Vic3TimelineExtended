# Colony people limit modules: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Slots go; crews limit a colony's modules; the Habitat is the one capped module; settlers become an open-ended amount drawn from every state and billed in Launch Capacity; Administrations cost authority; the panel shows crews needed against crews available.

**Architecture:** Most of the colony script is generated by `scripts/generators/gen_solar_sites.py` into `common/*/sr_sites_generated.txt`, `sr_sites_display_generated.txt`, `gui/journal_entry_widgets/sr_sites_generated_rows.gui` and `common/journal_entries/sr_sites_generated.txt`; the shared parts are hand-written in `common/scripted_effects/sr_colony_*_effects.txt`, `common/script_values/sr_colony_*_values.txt`, `common/scripted_guis/sr_colony_sguis.txt` and `gui/journal_entry_widgets/space_race_widget.gui`. Tests read the generated and hand-written text (`test_solar_sites.py` and kin).

**Tech Stack:** Paradox script (Victoria 3 1.15), Python 3.11/3.12 generators and unittest/pytest.

**Spec:** `docs/superpowers/specs/2026-11-22-colony-people-limit-modules-design.md`

## Global Constraints

- Never hand-edit a generated file: change `gen_solar_sites.py` and run `/home/jakef/src/Vic3TimelineExtended/.venv/bin/python scripts/generators/gen_solar_sites.py`; commit generator and output together.
- Worktree rules: no `POST /reload` (it regenerates the main checkout); use the main checkout's `.venv`; tests with `.venv/bin/python -m pytest <file> -q`.
- Brace files use tabs and one UTF-8 BOM; loc is American English; after loc edits run `python3 organize_loc.py` and `python3 scripts/check_loc_style.py --check`.
- `add_modifier`'s multiplier resolves against ROOT: apply from a pulse whose ROOT holds the `var:` (the country's monthly pulse for the Space Program building, as `sr_eb_apply_mix`).
- An authority cost is a positive `country_authority_cost_add`.
- No f-string reusing its own quote inside braces (Python 3.11).
- Figures from the spec, verbatim: crew 10,000 (`CREW_PER_LEVEL`), 5,000 with `artificial_intelligence`; Habitat share 0.5 + 0.1 a technology; 3 Launch Capacity a settler; settlers step n = 500 × 2^(n − 1); at most 1% of the country's people a month; 25 authority a staffed Administration level; AI Administration margin 50; AI settlers within `sr_mod_ai_fab_share` (5%) less the fabrication bill; destination score +1 a 10,000 people at cap.

## Review Focus

1. **A holder change shrinking a colony.** A cession to a holder with fewer Habitat technologies, or a break-away, must keep the room (`sr_site_hab_share_<key>` record); growth's `max = room` would otherwise cut people. Test in Task 2.
2. **Settlers past the room or the 1% cap.** An amount far above the free room or 1% of the people sends no more than either and bills only what was sent. Test in Task 7.
3. **Bill left on after settlers stop** (launches barred, Races Only, no colonies with room): the refresh removes `sr_settler_launches` and adds nothing at 0 units. Test in Task 8.
4. **A non-Habitat queue head priced like a Habitat.** `sr_mq_head_cost` and the lunar price test must charge `sr_module_points` for every type but the Habitat. Test in Task 3.
5. **Division by a missing base.** `sr_emig_lc_base` is never below the Earth Orbit line (500) with a Space Program; the units value guards a 0 base. Test in Task 8.
