##############################################
# INTERSTELLAR PROBE RESULT EVENTS (601-630)
#
# Each result is its own event with a unique image.
# Dispatched from the hidden space_race_events.60.
#
# Results describe one shared universe. The first nation whose probe returns a
# result discovers it (global record sr_probe_found_<id>, set by
# sr_record_probe_result in each event's immediate); a later nation drawing the
# same result gets the opening and closing lines of a confirmation instead of
# "unprecedented data", naming the first finder. Same rewards either way.
#
# Cat I: Dead Worlds & Data (results 1-8) → events 601-608
# Cat II: Astrophysical Wonders (results 9-15) → events 609-615
# Cat III: Biological Discovery (results 16-24) → events 616-624
# Cat IV: Intelligence & Tech-signatures (results 25-30) → events 625-630
#
# Every option grants its category's modifier through sr_grant_probe_data,
# which also records it (<modifier>_held) so a revolution's winner gets it
# back: "What a revolution's winner keeps" in space_race_effects.txt.
##############################################
