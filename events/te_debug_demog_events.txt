# ============================================================================
# DEMOGRAPHICS TEST CONSOLE — fired only from the console: `event te_debug_demog.1`
# ============================================================================
# Vic3's console has no `effect` command (that is CK3); `event <id>` is the way
# to run script by hand. Nothing in the mod fires this event. Every option writes
# to debug.log; the effects are in common/scripted_effects/te_debug_demog_effects.txt.
# debug.log rolls over at 512 KB: copy the lines out as they appear
# (docs/guides/scripting_best_practices.md, "Runtime Debugging with debug_log").
#
# What each option is for:
#   a    replay: step the capital's census one year now and log it (TE_DEMOG_REPLAY);
#        `scripts/analysis/demographics_harness.py replay debug.log` checks it against
#        the model. A second run in the same year steps again (the census year goes
#        back by one first) and folds this year's newborns into the over-150 pool:
#        use a save you can throw away, or re-seed after (c)
#   b    start or stop the census log: each 31 December a TE_DEMOG_CENSUS: line per
#        country of a million people or more (scripts/analysis/
#        demographics_observer_report.py reads them), and a TE_DEMOG_PULSE line at the
#        player's capital's yearly state pulse (one step per calendar year?)
#   c    re-seed this country's census from today's population, then take its census
#   d    benchmark (spec §14 Q9's late-game re-run): every state's step in the world,
#        three passes, between TE_DEMOG_BENCH lines; then, untimed, every census is
#        seeded again (the passes leave them wrong)
#   e    war dead (spec §14 Q4): the player's dead in each war, its monthly tally and
#        the states' pending dead (TE_DEMOG_WARDEAD)
#   f/g  skew check (spec §14 Q11): f logs the capital's pops (TE_DEMOG_SKEW) and adds
#        a 60-day +0.05 working-adult ratio modifier; g logs them again a month later
#   h-k  fast mode (te_demog_fast_effects.txt): demography, research and construction
#        at 4x (h), 6x (i) or 12x (j), for iterating on the model; k goes back to normal
#        speed. A test tool, never for play: the first switch re-seeds every census, and
#        the census year then runs on its own clock. Fire it on day 1, then `observe`.
#   l    the census's mortality and fertility modifier types as the capital and an
#        unincorporated state read them (TE_DEMOG_MODS), and phase 2 step 1's work figures,
#        working-adult families and participation inputs (TE_DEMOG_WORK)
#   m    the shock terms (probe P1): every devastated or polluted state's reads
#        (TE_DEMOG_SHOCK)
#   n    the census's rates (probe P3): the capital's births and deaths terms, the
#        on-top scales of its last step and its reads (TE_DEMOG_RATES)
#   o    the engine-scaling probe (Task 9 of the late-marriage plan): a script-only type on
#        the capital's state modifier at multiplier 0.62 (TE_DEMOG_PROBE), logged before and
#        a week after by the hidden te_debug_demog.2
#   q    the owner-change probe (the late-marriage plan, Stop B's I1): one of our states, alone
#        in its region, given to a neighbour and logged before, in on_state_owner_change and a
#        day after by the hidden te_debug_demog.4 (TE_DEMOG_PROBE_OWNER). It really changes
#        hands: throwaway games only.
#   p    call 3's carriers (phase 2 step 1): Punishment-Focused Criminal Justice if needed with Community Service,
#        Woman Soldiers at half strength and the Trade Unions pushed past loyal, all for 60 days; the capital's
#        TE_DEMOG_MODS and TE_DEMOG_WORK lines now, a day and a month later (the hidden te_debug_demog.3)
#   r    the workforce term and the pension setting (phase 2 step 2): the capital's TE_DEMOG_WF line (W, its target,
#        the lines on top, the game's own figure, the work deaths' split) and the country's TE_DEMOG_PENSION line
#   s    the pension setting's five-year term ends now (phase 2 step 2), so another position can be chosen at once
#   x    family policy in the census (phase 2 step 3b): the capital's Family Policy types, the policy term, the sex
#        ratio's add and the census's stored fertility terms (TE_DEMOG_FAMILY)
#   t    phase 2 step 4's figures: the capital's pool, conscription term, youth bulge and sex-balance terms beside the
#        state's reads of the four fields they move (TE_DEMOG_CONSEQ), and the country's (TE_DEMOG_CONSEQ_COUNTRY)
#   u    phase 3, the late game: the capital's eligibility, cover, ageing rate and pull, the market threshold, Living to
#        100, old age from, rho, the wealth slope and the mean ages (TE_DEMOG_LATE), and the country's (TE_DEMOG_LATE_COUNTRY)
#   v    phase 3's play-test cheat: our country researches the ageing ladder at once (mRNA Therapeutics, Personalized
#        Medicine, Genetic Engineering and Biological Immortality), so the late game starts at the next census. It
#        really researches them: throwaway games only
#   w    phase 3's event wave: opens te_debug_demog.80, a chooser that fires any of the ten wave events
#        (events/te_demog_wave_events.txt) on the player now, whatever its condition and its generation's hold, under
#        any rule (its options act as they would under Full; the census's levers in them need Full)
# Hidden, fired by script in every game: te_debug_demog.5 (the Primogeniture self-check) and .6, .7, .8 (phase 2 step
# 1's workforce self-checks; te_debug_demog_wf_selfchecks); under Full, .10 (the Family Policy measures' self-check,
# measure_country_types; te_debug_demog_ms_selfcheck_start) and .60 (the Planned Capital's, planned_capital_moved;
# te_debug_demog_pc_selfcheck_start). Each writes one TE_SELF_CHECK line a game.
# Hidden too: .40 and .41, calibration step 3's self-checks (te_debug_demog_step3_selfchecks), one line a game each.
# Phase 2 step 2's two (workforce_ratio_scale, workforce_follows_target) need no event: te_debug_demog_wf_term_checks
# writes them at a capital's census, before its workforce refresh.
# Hidden too: .30, phase 2 step 4's conscription_term_read (te_debug_demog_conscription_selfcheck_start), one line a
# game, only while conscription's effect applies.
#
# Phase 3's event wave: .80, the console's chooser (option w; visible), and the hidden .81, the self-check
# wave_timed_country_type's second half (te_debug_demog_wave_selfcheck_start, te_demog_wave_effects.txt), one line a
# game under Full.
# An option's tooltip walks its effects each time the open event renders it, testing
# the limits and writing nothing. Options a, c, d and e walk a census step, the walks
# or every state and war, and their tooltips wrote about 1,200 error lines a second
# while the event was open (2026-10-09). Each sets te_dg_dbg_click and does its work
# only under has_variable = te_dg_dbg_click: the tooltip pass never sets it, so it
# skips the work, and the event now logs nothing while open (confirmed 2026-10-09;
# docs/guides/scripting_best_practices.md, "An Option's Tooltip Walks Its Effects").
# ============================================================================

# The self-check wave_timed_country_type's second half (te_debug_demog_wave_selfcheck_start): once a game, under Full, a
# week after the first wave option put a census type on a timed country modifier, on the owner's capital. OK: the
# capital's sum of the type rose by the option's line plus any change in the measures' lines of that type (a script-only
# state type on a timed country modifier reaches the state). BROKEN with added 0: it doesn't, so the four wave options
# that carry census lines (Missing Girls' ban and payments, The Last Generation?'s licences and allowance) change no
# birth; put their census lines on untimed modifiers with an end date the yearly check removes
# (docs/testing/demographics-playtest.md, Self-checks). NO_VERDICT, and the check re-arms, when the expected change is
# under 0.01; none when the state changed hands within the week.
te_debug_demog.81 = {
	type = state_event
	hidden = yes

	immediate = {
		if = {
			limit = {
				has_variable = te_dg_wv_chk_before
				exists = owner
				owner = var:te_dg_wv_chk_owner
			}
			# kept on the state for the line (a debug_log line reads THIS.Var, not a local)
			set_variable = { name = te_dg_wv_chk_added value = te_demog_wave_chk_added }
			set_variable = { name = te_dg_wv_chk_expected value = te_demog_wave_chk_expected }
			set_local_variable = {
				name = te_dg_wv_chk_gap
				value = {
					value = var:te_dg_wv_chk_added
					subtract = var:te_dg_wv_chk_expected
				}
			}
			if = {
				limit = { local_var:te_dg_wv_chk_gap < 0 }
				change_local_variable = { name = te_dg_wv_chk_gap multiply = -1 }
			}
			set_local_variable = { name = te_dg_wv_chk_size value = var:te_dg_wv_chk_expected }
			if = {
				limit = { local_var:te_dg_wv_chk_size < 0 }
				change_local_variable = { name = te_dg_wv_chk_size multiply = -1 }
			}
			if = {
				limit = { local_var:te_dg_wv_chk_size < 0.01 }
				debug_log = "TE_SELF_CHECK NO_VERDICT wave_timed_country_type code=[THIS.Var('te_dg_wv_chk_code').GetValue|0] added=[THIS.Var('te_dg_wv_chk_added').GetValue|4] expected=[THIS.Var('te_dg_wv_chk_expected').GetValue|4] (a measure offset the line within the week; the check re-arms) date=[TimeKeeper.GetCurrentDate.GetString]"
				remove_global_variable = te_demog_wave_selfcheck_done
			}
			else_if = {
				limit = { local_var:te_dg_wv_chk_gap < 0.002 }
				debug_log = "TE_SELF_CHECK OK wave_timed_country_type code=[THIS.Var('te_dg_wv_chk_code').GetValue|0] added=[THIS.Var('te_dg_wv_chk_added').GetValue|4] expected=[THIS.Var('te_dg_wv_chk_expected').GetValue|4] date=[TimeKeeper.GetCurrentDate.GetString]"
			}
			else = {
				debug_log = "TE_SELF_CHECK BROKEN wave_timed_country_type code=[THIS.Var('te_dg_wv_chk_code').GetValue|0] added=[THIS.Var('te_dg_wv_chk_added').GetValue|4] expected=[THIS.Var('te_dg_wv_chk_expected').GetValue|4] (added 0: a script-only state type on a timed country modifier doesn't reach the state; put the wave's census lines on untimed modifiers removed by the yearly check) date=[TimeKeeper.GetCurrentDate.GetString]"
			}
			debug_log_scopes = yes
			remove_variable = te_dg_wv_chk_added
			remove_variable = te_dg_wv_chk_expected
		}
		if = {
			limit = { has_variable = te_dg_wv_chk_before }
			remove_variable = te_dg_wv_chk_before
			remove_variable = te_dg_wv_chk_code
			remove_variable = te_dg_wv_chk_line
			remove_variable = te_dg_wv_chk_m0
			remove_variable = te_dg_wv_chk_owner
		}
	}
}
